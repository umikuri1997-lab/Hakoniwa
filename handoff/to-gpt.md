# GPT へのたのみ

## いまのたのみ
10ある（H-1〜H-10）。上から1つずつする（1つおわったら、`from-gpt.md` に書いてPRにし、つぎへ進んでよい）。

どれも共通：
- いまはコードの仮の絵（ドット）で描いている物。3Dで組んで、マップチップにする絵を作る。
- ゲームのコード（`js/`）の描き方は、Claude がつなぐ。GPT は、絵（設計図と写した絵）を作るまで。チップに入れるのは、持ち主が「入れる」と言ってから。
- いまの仮の絵の大きさ・置き方は、書いてある関数を読んでたしかめる。仮の絵は1マス32点のゲームの点で描いてある（チップは1マス64ドット `g:64`）。
- できたら、いまの仮の絵（ゲームで写した物）とならべた絵を `handoff/files/H-<番号>/` に入れる。

### H-1 遊園地の遊具（風のステージ）
- 作る物：メリーゴーラウンド `merry`・コーヒーカップ `cup`・空中ブランコ `skyswing`（どれも2×2）、観覧車 `wheel`（3×2）。それぞれのこわれた絵 `merryb`・`cupb`・`skyswingb`・`wheelb`（同じ大きさ。色がさめて、かたむき、こわれた所がある）。
- いまの絵：`js/wind.js` の `drawRide`・`drawRide0`（足もとのまん中から `RIDEK` 1.5倍にのばしている）。チップは、のばさずに、その大きさで作る。
- 動く所：遊具はまわる（`rideAng`）。動かない所（台・柱・屋根）と、まわる所（メリーゴーラウンドの馬・コーヒーカップのカップ・空中ブランコの座席・観覧車の輪とゴンドラ）を分けて、まわる所はコマ（何コマでひとまわりかを書く）か、べつの部品の絵にする。観覧車のゴンドラは、輪がまわっても下を向いたまま。
- のる子の場所：`windRidePose`（のっているせいれいの場所）が、新しい絵の座席にあうように、座席の場所（足もとからのドット）を `from-gpt.md` に書く。
- お手本：ガゼボ・東屋（`items/gazebo.py`・`canopy.py`：屋根と柱）、ブランコ `items/swing.py`（`MOVE`・`fix`：動く部品と、手前にかさねる絵）、風車 `items/windmill.py`（回る羽）。
- 遊園地の色：明るくやわらかいパステル（いまの仮の絵のピンク・クリーム・ミント）。白い所は `flat` か場所ごとの色で（灰色にしない）。

### H-2 風のしかけ（風のステージ）
- 作る物：風穴 `kazaana`（石でかこんだ穴。風がふき出す）・ふさがった風穴 `kazaanab`（石の山でふさがった）、どちらも1×1。かざみ `kazami`（柱の上に、風の向きをさす矢の羽、1×1、4つの向き `kazami`・`kazami>1〜3`。0 手前・1 右・2 奥・3 左で、矢の先がその向き）。
- いまの絵：`js/wind.js` の `drawWindObj`。風穴から出る白い風のつぶはゲームで描くので、絵には入れない。
- かざみは、まっすぐ立てる（かたむけない）。

### H-3 水のステージの置き物
- 作る物：船着き場 `dock`（1×1、木の桟橋。水のとなりに建てる）・いかだ乗り場 `raft`（1×1、いかだと旗）・しずんだ宝箱 `mzchest`（1×1）・水門 `mzgate`／こわれた水門 `mzgateb`（1×1、石の柱と木の門）。おびきよせの石像 `lurestatue`（1×1、せいれいの形の石像。まっすぐ立てる）。
- いまの絵：`js/mizube.js` の P(...) で描いている所（`mzgate`・`mzchest`・`dock`・`raft`）と、`js/draw-objects.js` の `case'lurestatue'`。
- しずんだ宝箱は、水の中にあるとき（うすく見える）はゲームで描く。絵は、水が引いたあとの、地面に出た宝箱。
- 水門の開いた絵 `mzgate` の水の流れはゲームで描くので、絵には入れない。
- かえり道のあかり（`kaeribi`）は、もう行燈のチップで描いているので入れない。

### H-4 光と闇のせいれい（トモリ・ツキミ）
- いまは、水のせいれいの形を色がえしているだけ（`js/draw-spirits.js` の `SPART`、闇は `js/yami.js` の `SPC.dark`）。
- ほかの属性は、属性ごとの部品のチップ（`sp_<属性>:hood`・`hoodS`・`tip`・`tail` など、火は `ember`、風は `leaf`・`vine`）を持ち、`tools/art/spirit3d/build.py` が3Dの動きの絵を作る。光は `sp_light:*`、闇は `sp_dark:*` を作る。
- 形はまだきまっていない（形が自由な物）。**作る前に、光と闇それぞれ2〜3この形の案を絵にして `from-gpt.md` で持ち主に聞く**。設定は `STORY.md` の「さいごの章」：トモリは光のヌシ様（弱ったお日さま）が生んだ、まわりを照らす光のせいれい。ツキミは、ねむるせいれいのそばで見守る闇のせいれい。むかし、光と闇のせいれいはなかまだった。
- きまったら、ほかの属性と同じ部品をそろえて、`build.py` で動きの絵まで作る。

### H-5 風のヌシ様（風のステージ）
- 作る物：風のヌシ様。雲のつばさの、白い大きな鳥（`STORY.md` の「風のヌシ」）。ボーンを入れて動かす物。
- 使う所と、いまの絵：
  - さいごの朝に雲の海からのぼり、遊び場の上を飛ぶ。クリアのあとは、空をゆっくりまわる。いまの絵は `js/wind-story.js` の `windBird`（上から見た形・つばさを広げてはばたく、はばは約10マス）。
  - 雲の下で、つばさで島をささえている所と顔。いまの絵は `js/wind.js` の `wingDots`（つばさ）・`nushiFaceDots`（顔）・`drawWindScene`。
- 作る絵：とぶ（はばたき、何コマでひとはばたきかを書く）・雲の下でつばさを広げて止まっている・顔のアップ。見おろしの角度は、ほかのチップと同じ。
- つばさのかげでねむる影は、コワイノのチップ（`drawShade`）で描くので入れない。
- 白い所は、灰色にならないように（`flat` か場所ごとの色）。

### H-10 水のヌシ様と白い影（水のステージ）
- 作る物：
  - 水のヌシ様 `mzkame`：こうらに小さな池とハスをのせた、大きなかめ（`STORY.md` の水の土地・`IDEAS.md` の「水のステージできまったこと」）。置くのは1マス（ため池の底）だが、絵は3×2マスくらい。3まい：ため池の底でねむる（顔をこうらに入れ、大きな岩に見える。こうらの上にかれたハス）・目をさました（顔を出す）・夜明け（水にうかび、こうらの上のハスがピンクに咲く）。
  - 白い影（カナデ）：消えた水のせいれい。霧の中に立つ、白く、うすくすける、ずきんの形。ほかのせいれいと同じくらいの大きさ。立つ・水にのって下っていく（2〜4コマ）。
- いまの絵：`js/mizube-story.js` の `mzKameDraw`（かめ）・`mzKanadeDraw`（白い影）。白い影のうすさ（すけ方）と、まわりにちる光は、ゲームでかける・描くので、絵はふつうのこさで。
- かめは、かたむけない（こうらの上のハスは、まっすぐ上へ）。白い所は灰色にならないように（`flat` か場所ごとの色）。
- 水の中にしずんでいるときの、うすく見える絵は、ゲームで描く。
