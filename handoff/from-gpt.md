# GPT からの結果

## いまの結果

木目は Wood049、石肌は Rock030 の色と凹凸、金具は Metal032、布は Fabric026 を3Dの面にはった。リポジトリの CC0 テクスチャを使った。

### H-1 遊園地の遊具

- 回転木馬の屋根に3色の布と小旗、馬に色違いの鞍とたてがみを付けた。カップはピンクとすみれ色の釉薬、空中ブランコは色違いの座席、観覧車は4色のゴンドラと輪の小さな飾り灯にした。
- コーヒーカップの中央に水盤を付けた。水底が透け、小波の角度から空の光と中央の金の飾りの反射を求めて写した。壊れた水盤は水が抜けている。
- 観覧車は前後の窓をガラスにした。張り出した窓の面ごとに透け方と光沢が変わり、壊れた絵では前の窓が一つ外れている。輪・金具には金属の光沢、カップの釉薬には陶器の光沢をつけた。

- メリーゴーラウンド、コーヒーカップ、空中ブランコ、観覧車を3Dで組み、動く絵とこわれた絵を写した。こわれた絵は、屋根板の欠け、カップの傾き、ちぎれた吊り材、切れた観覧車の輪で見分けられる。回転木馬には板張りの床と屋根の縫い目、カップには中のハンドル、空中ブランコには座席の手すり、観覧車には台の足金物と乗り口の段を足した。
- 台、柱、屋根などの見え方が変わらないドットは `*_static.png`。動く部品とかくれ方で変わる部分は `*_motion.png`。静止画の上に各コマを重ね、完成コマの `*_frames.png` と全ドットが一致することを確認した。左から右、上から下へ16コマで1周。観覧車のゴンドラの座面は、どのコマでも水平。
- 足もとは、元の絵の左上からメリーゴーラウンド、コーヒーカップ、空中ブランコがゲームの点で `(32,56)`、観覧車が `(48,56)`。以下はそこからの g64 のドット。右と下が正。ゲームの点に直すときは2で割る。

- 全16コマの座席の位置、絵の左上と大きさは [sprites.json](files/H-1/sprites.json)。`rideAng` に `phase_factor` をかけた角度を1周16等分してコマを選び、同じコマの `seats[コマ][座席番号]` を `windRidePose` に使う。前後の描画順は、実際にせいれいを乗せるときに確認する。
- 8まいの見本を `chipcheck.py` で確認。30〜90色、半透明0。64色以内の絵ではにた色0組。輪郭が2ドット以上の所は6〜445、孤立ドットは118〜441。色数、輪郭、細い線の点に目安を超える所がある。

### H-2 風のしかけ

- 石組みと穴底を組み、ふさがった絵は割石を積んだ。かざみは直立した木の柱と矢で組み、同じ3Dを90度ずつ回した。風穴は石組みの目地と石の縁、かざみは石の台座、柱の金属帯と矢の背を足した。矢先は 0 手前、1 右、2 奥、3 左。風の白いつぶはゲームで描く。
- 6まいを `chipcheck.py` で確認。14〜28色、半透明0、にた色0組。輪郭が2ドット以上の所は14〜29、孤立ドットは13〜58。
