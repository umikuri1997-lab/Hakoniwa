# GPT からの結果

## いまの結果

木目は Wood049、石肌は Rock030 の色と凹凸、金具は Metal032、布は Fabric026 を3Dの面にはった。リポジトリの CC0 テクスチャを使った。

### H-1 遊園地の遊具

- 遊具のピンク、すみれ色、青緑、黄、だいだいを鮮やかにした。空中ブランコは黄みのある細い丸ひも2本を座席の留め具につないだ。回転に合わせて座席が外を向く。座席がついたひもは張り、切れたひもは先が曲がる。

- 回転木馬の屋根に3色の布と小旗、馬に色違いの鞍とたてがみを付けた。カップはピンクとすみれ色の釉薬、空中ブランコは色違いの座席、観覧車は4色のゴンドラと輪の小さな飾り灯にした。
- コーヒーカップの中央に水盤を付けた。水底が透け、小波の角度から空の光と中央の金の飾りの反射を求めて写した。壊れた水盤は水が抜けている。
- 観覧車は前後の窓をガラスにした。張り出した窓の面ごとに透け方と光沢が変わり、壊れた絵では前の窓が一つ外れている。輪・金具には金属の光沢、カップの釉薬には陶器の光沢をつけた。

- メリーゴーラウンド、コーヒーカップ、空中ブランコ、観覧車を3Dで組み、動く絵とこわれた絵を写した。こわれた絵は、屋根板の欠け、カップの傾き、ちぎれた吊り材、切れた観覧車の輪で見分けられる。回転木馬には板張りの床と屋根の縫い目、カップには中のハンドル、空中ブランコには座席の手すり、観覧車には台の足金物と乗り口の段を足した。
- 台、柱、屋根などの見え方が変わらないドットは `*_static.png`。動く部品とかくれ方で変わる部分は `*_motion.png`。静止画の上に各コマを重ね、完成コマの `*_frames.png` と全ドットが一致することを確認した。左から右、上から下へ16コマで1周。観覧車のゴンドラの座面は、どのコマでも水平。
- 足もとは、元の絵の左上からメリーゴーラウンド、コーヒーカップ、空中ブランコがゲームの点で `(32,56)`、観覧車が `(48,56)`。以下はそこからの g64 のドット。右と下が正。ゲームの点に直すときは2で割る。

| 遊具 | 0コマ目の座面の中心 `(x,y)` |
| --- | --- |
| メリーゴーラウンド | `(60,-105)`, `(-30,-66)`, `(-30,-144)` |
| コーヒーカップ | `(45,-78)`, `(-45,-78)` |
| 空中ブランコ | `(77,-137)`, `(-38,-87)`, `(-38,-186)` |
| 観覧車 | `(99,-186)`, `(0,-91)`, `(-99,-186)`, `(0,-280)` |

- 全16コマの座席の位置、絵の左上と大きさは [sprites.json](files/H-1/sprites.json)。`rideAng` に `phase_factor` をかけた角度を1周16等分してコマを選び、同じコマの `seats[コマ][座席番号]` を `windRidePose` に使う。前後の描画順は、実際にせいれいを乗せるときに確認する。
- 8まいの見本を `chipcheck.py` で確認。35〜100色、半透明0。64色以内の絵ではにた色0組。輪郭が2ドット以上の所は4〜397、孤立ドットは152〜438。色数、輪郭、細い線の点に目安を超える所がある。

### H-2 風のしかけ

- 石組みと穴底を組み、ふさがった絵は割石を積んだ。かざみは直立した木の柱と矢で組み、同じ3Dを90度ずつ回した。風穴は石組みの目地と石の縁、かざみは石の台座、柱の金属帯と矢の背を足した。矢を鮮やかな青緑に、軸を赤銅色にした。矢先は 0 手前、1 右、2 奥、3 左。風の白いつぶはゲームで描く。
- 6まいを `chipcheck.py` で確認。14〜28色、半透明0、にた色0組。輪郭が2ドット以上の所は14〜35、孤立ドットは13〜58。
- [仮の絵との比較](files/H-2/cmp_x4.png) ・ [位置と大きさ](files/H-2/sprites.json) ・ [風のしかけの設計図](../tools/art/handoff3d/wind_objects.py)

### H-3 水のステージの置き物

- 船着き場、いかだ乗り場、地面に出た宝箱、水門、こわれた水門を3Dから写した。水門は石柱の間で木戸を上げ、こわれた絵は折れた板を残した。桟橋の留め具、いかだの丸太の小口と年輪、宝箱の板の継ぎ目と鋲、水門の石の笠と巻き上げ金具を足した。宝箱が水の中にあるときの色と、水門を通る水はゲームで描く。
- 5まいを `chipcheck.py` で確認。11〜25色、半透明0、にた色0組。輪郭が2ドット以上の所は0〜35、孤立ドットは4〜61。
- [仮の絵との比較](files/H-3/cmp_x4.png) ・ [位置と大きさ](files/H-3/sprites.json) ・ [水辺の設計図](../tools/art/handoff3d/water_objects.py)
- おびきよせの石像の形を選んでほしい。**1** 仮の絵と同じ四角い台と頭巾で直立。**2** 丸みのある頭巾で直立。**3** 石像は保留。

### H-4 光と闇のせいれい

[トモリとツキミの形の案](files/H-4/shape-options.png)。今のトモリとツキミが形を借りている、水の精霊の正面モデルを使った。顔と体のドットと位置をそろえた。頭巾としっぽの組み合わせを、それぞれ1つずつ選んでほしい。

- トモリ **1** ともしびの頭巾と、上へ伸びる光のしっぽ。**2** 朝日のひだのある頭巾と、短い光のしっぽ。
- ツキミ **1** 三日月の頭巾と、丸く巻くしっぽ。**2** 丸い頭巾と、下へたれるしっぽ。
- 形が決まったら、`sp_light:*`・`sp_dark:*` の部品をそろえ、`tools/art/spirit3d/build.py` で動きの絵を作る。

H-1〜H-3 の絵は1マス64ドット。仮の絵はゲームの描画関数を同じ縮尺で呼び出して比較した。ゲームのマップでの確認とチップへの登録は、絵の確認のあと。
