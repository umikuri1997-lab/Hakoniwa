# GPT からの結果

## いまの結果

木目は Wood049、石肌は Rock030 の色と凹凸、金具は Metal032、布は Fabric026 を3Dの面にはった。リポジトリの CC0 テクスチャを使った。

### H-1 遊園地の遊具

- 持ち主の見本に合わせ、明るい木、クリーム、淡い水色にそろえた。4種とも丸い板張りの台、手前の階段、柵、水色の布飾り、旗を組んだ。幕板や看板の青い葉模様も3Dの面に付けた。
- メリーゴーラウンドは波形の幕板、しまの屋根、鞍つきの馬3頭とランタン。空中ブランコは同じ屋根とランタン、2本のひもで吊った水色の椅子6席。
- コーヒーカップは青い釉薬の内側と受け皿を持つカップ3つ。奥にカップの看板と小旗、ランタンを吊るしたアーチを立てた。観覧車は木の二重の輪と、青い屋根・ガラス窓のゴンドラ8室。ゴンドラは輪が回っても座面が水平。
- `*_static.png` が静止部分、`*_motion.png` が動きやかくれ方で変わる部分。16コマを左から右、上から下へ並べた。各コマを静止部分と重ね、`*_frames.png` と全ドットが一致することを確認した。
- 足もとの基準は仮の絵と同じ。メリーゴーラウンド、コーヒーカップ、空中ブランコはゲームの点で `(32,56)`、観覧車は `(48,56)`。絵の取りつけ位置と全16コマの乗る位置は g64 のドットで [sprites.json](files/H-1/sprites.json) に記録した。
- 絵の席数は見本に合わせた。乗る位置の数は今のゲームと同じで、メリーゴーラウンド3、コーヒーカップ2、空中ブランコ3、観覧車4。カップは手前から始まる2席、ブランコと観覧車は1つおきの席に合わせた。
- カメラを29度にして、見本に近い正面寄りの見え方で写した。前後の描画順は、実際にせいれいを乗せるときに確認する。
- 8まいを `chipcheck.py` で確認。26〜49色、半透明0。にた色0〜12組。輪郭が2ドット以上の所は59〜265、孤立ドットは264〜540。
- [仮の絵との比較](files/H-1/cmp_x4.png) ・ [遊具の設計図](../tools/art/handoff3d/rides.py)

### H-2 風のしかけ

- 石組みと穴底を組み、ふさがった絵は割石を積んだ。かざみは直立した木の柱と矢で組み、同じ3Dを90度ずつ回した。風穴は石組みの目地と石の縁、かざみは石の台座、柱の金属帯と矢の背を足した。矢を明るいミント、軸をいちごミルク色にした。日中の明るさで写した。矢先は 0 手前、1 右、2 奥、3 左。風の白いつぶはゲームで描く。
- 6まいを `chipcheck.py` で確認。14〜28色、半透明0。にた色0〜1組。輪郭が2ドット以上の所は14〜29、孤立ドットは13〜58。
