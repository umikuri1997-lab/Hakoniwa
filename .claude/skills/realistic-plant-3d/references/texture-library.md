# 植物用テクスチャライブラリ V5

`assets/textures/manifest.json` が全素材の索引。`preview.jpg` は色見本。各素材は独自に手続き生成した近似で、実物を撮影した画像ではない。対象の植物・品種・季節・成長段階を実物資料で確認し、色や葉脈を変更する。葉の輪郭や鋸歯・花の巻き込みはテクスチャではなくメッシュで作る。

## 収録素材（22セット、各512×512 PNG 3枚）
- 葉8：leaf_broad（広葉）、leaf_rose（バラ向け羽状脈）、leaf_olive（オリーブ向け）、leaf_cabbage（キャベツ向け）、leaf_maple（秋色の広葉の色素材。掌状脈は別途作り直す）、leaf_underside（葉裏）、leaf_grass（イネ科向け平行脈）、leaf_lily（ユリ向け平行脈）。
- 花弁6：petal_rose、petal_lily、petal_hydrangea、petal_sunflower、petal_pansy、petal_morning_glory。色・細い筋のベース。パンジーの斑紋、アサガオの放射模様等は対象の花全体のUV・花弁別マスクに応じて修正する。個別種の正確な模様とは限らない。
- 樹皮4：bark_oak、bark_birch、bark_cedar、bark_olive。樹皮の裂け目、繊維、横向きの皮目などの近似。
- 茎2：stem_green、stem_woody。
- 実2：fruit_tomato、fruit_blueberry。

## マップの設定
- `basecolor.png`：sRGB。焼き込み影なし。Principled BSDFのBase Colorへ。
- `normal.png`：Non-Color、接空間OpenGL（+Y）。Normal Mapノードを経由してNormalへ。通常は控えめな強さ（葉・花弁0.15～0.35、樹皮0.35～0.7を開始値）で、参考写真と合わせる。
- `roughness.png`：Non-Color。白ほど粗い。Metallicは0。葉の光沢は均一にしない。葉・花弁の透過は必要なら別途薄葉の散乱を設定。GLBにそのまま転送されないシェーダー効果は明記。
- 葉・花弁は長方形UVに対応した表面素材。PNGに透明輪郭は含まれない。葉カードの場合は対象種の輪郭から別途アルファマスクを作る。葉メッシュのU=0～1は左から右、V=0は付け根、V=1は先端。画像の下が付け根。中心脈をメッシュの中心線と一致させる。左右非対称の葉でもUVの軸を維持。花弁は根元から先へ同じ規約で貼る。複数の花弁がつながった漏斗花冠は花冠専用UVへ再設計。
- 幹・茎の円筒UVはUを周方向、Vを長手方向に設定。周期的に生成した樹皮・茎・実のマップは繰り返し貼り付けを想定。貼り付け後に継ぎ目・伸びを目視確認する。縮尺は幹径、樹皮の幅、節間で調整する。

## 制作手順
1. 形態参照に合う素材を選択。種名の一致だけで適用しない。該当しない場合は新規作成する。
2. `scripts/blender_texture_material.py` の make_material をBlender内で使用、または同じノードを作る。画像はパックし、既存シーンには新規マテリアルのみ追加。
3. 葉裏専用メッシュ/マテリアルを使う場合は法線・UVと両面表示を確認。GLB用の粗さはglTFのGチャンネルへ正しく出力し、必要ならエクスポーターでパック。金属度Bは0。GLBに画像を埋め込み、再読み込みで確認する。トゥーン指定時は色差を抑え、法線を弱くする。テクスチャ不要の指定は優先。
4. クレイ表示で形態を検証した後、テクスチャ付きの近接・遠景を確認。照明で影を足したり、ノイズや強い光沢で形状の欠点を隠さない。葉脈の向き・色の飽和・素材の繰り返し・サイズ・裏面を検査する。
5. 必要なファイルを保存・パック。別PCに移しても欠落しないようにする。

## 再生成
`python scripts/generate_textures.py --size 1024 --output /path/to/textures`。numpyとPillowが必要。種固有の葉脈や色は生成コードを変更する。元の22素材は512pxで同梱。高解像度版は必要な場合のみ生成する。葉脈などの正確な種同定を保証しない。外部写真の転用なし。Blender上での適用とGLB出力後の表示は別途検証する。
