# Blender実装・検証手順

## 実行環境
- Blenderのバージョンと実行可否を確認。ローカル実行、接続済みMCP、実行ツールなど、実際に使える手段だけを使う。
- Blenderがなくても、モデル生成コードを作成する。ユーザーが実行できるよう、BlenderのScripting画面でファイルを開き Run Script を押す方法を記す。必要ならコマンドライン実行例 `blender --background --python generate_plant.py` を提示する。
- 出力ディレクトリ、対象名、スケール、乱数シード、品質設定はスクリプト先頭などに集約。出力パスは絶対固定にせず設定可能にする。

## 推奨構造
1. 種固有の形態パラメータ（高さ、枝径、分岐、葉序、葉形、色など）。
2. 曲線・メッシュ用の共通関数。主幹と枝には曲線に沿ったテーパー付き断面、葉には格子状の曲面メッシュを使う。
3. 骨格生成。節位置・接線・枝の局所座標・半径を記録。
4. 葉、花、実の取り付け。親要素と局所座標を共有する。
5. マテリアル、UV、コレクション、名前、原点の整理。
6. 保存、エクスポート、プレビュー、検証。

## 葉メッシュの実装
中心線 C(t)、幅 W(t)、中心線に沿った局所横方向 B(t)、表面法線 N(t) を用いる。t=0 を葉基部、t=1 を葉先とし、横位置 u を -1〜1 とする。

`P(t,u) = C(t) + B(t) * W(t) * u + N(t) * H(t,u)`

W は半幅、H は断面の反り・主脈周辺の起伏など。必要に応じ左右別の幅、葉縁形状、ねじれを指定する。実際の葉形に基づいて調整する。
- 局所座標系は接線と参照軸から作り、平行に近い場合は代替軸を選ぶ。曲線に沿ってフレームが急反転しないようにする。
- 先端・基部で幅がゼロになる場合は重複頂点を避けて三角形の端部を作る。面の向き、UV、法線を確認する。
- 葉の厚さは用途に応じて薄い両面メッシュまたは厚みのあるメッシュで表現。単純に全葉へ同じSolidify値を使わない。
- 葉脈は重要な部分だけ幾何形状で作り、必要に応じて色・法線・粗さのテクスチャに分担させる。

## 質感・最適化
- Principled BSDFを基本に、葉の色、粗さ、適切な透過・散乱表現を調整する。使用Blender版で利用できるソケット名を確認する。
- 木肌は枝の方向に沿う質感、葉は部位と成長段階の色差を使う。過度なノイズ、過度な光沢、プラスチック感を避ける。
- 葉が多い樹木などは複数の形状バリエーションをインスタンスとして再利用。必要な場合のみ実体化。オブジェクト数・メモリ・描画負荷を監視する。
- GLB用には互換性のあるPBRマテリアルを用意し、手続き型シェーダーやGeometry Nodes等がそのまま他環境で再現されると仮定しない。必要に応じてベイク、評価済みメッシュへの変換、インスタンス実体化を行う。
- Blender内ではZ上向きで制作。GLBでは標準の座標変換を使用し、二重変換しない。

## 検証
- `.blend` 保存と必要なテクスチャのパック・同梱を確認する。元ファイルの上書きはしない。
- 実ポリゴン数は必要に応じて評価済みメッシュの三角形数を確認。インスタンスを含む数とベースメッシュの数は区別する。
- メッシュの空・不正な頂点・ゼロ面積・重複面・逆法線・不要な交差・UVを確認する。葉カードなど意図した開放面は欠陥として扱わない。
- カメラ・照明は検証用コレクションに分離し、モデル単体の出力には含めない。
- 正面、側面、背面、斜め、上面と必要な接写をレンダリング。実際に画像を閲覧できる場合に目視チェックする。
- GLB等を出力したら可能な範囲で再インポートし、サイズ、向き、葉の表裏、材質、テクスチャ、欠落した部品を確認する。
- 実施していないテストについて成功を報告しない。
