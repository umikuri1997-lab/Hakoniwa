# V9 ゲーム用の花・草花：持ち主との検証で決まった作り方

Hakoniwa の3D試作（three.js・トゥーン・見おろし35度）で、ばらを何度も作りなおして決まった事。実装は `proto3d/make_flowers.py`（`rose()`・`petal_card_texture()`・`leaf_card_texture()`・`Plant.rimmed()`）と `proto3d/main.js`（花・葉のカードの材質）。ほかの種にも、この順番と数字のめやすで当てる。種ごとの形態の調べ方（G0〜G6）は V7・V8 のまま。

## 1. 作る前
- 参考の絵・写真をもらったら、作る前に形の特ちょうを書き出す（丸い／とがる・厚み・せの高さ・つまり方・花の深さ）。自分の作り方に絵を合わせない。
- 代表1株で、作る→Blender のクレイ8方向と材質（`scripts/render_review_blender.py`）→ゲームの画面（同じ距離）→直す、を回してから、ほかの種へ。
- ゲームの画面での見え方を最後の判定にする。Blender できれいでも、ゲームのトゥーン（かげ2だん）では面の向きの差が出ないことがある。

## 2. 花びら
- **枚数は少なく**：ばらの満開で4段17まい（5・5・4・3）＋まん中の折りこんだ花びら1つ、つぼみ5まい。31まい以上は、ゲームの距離では見分けられず重い。
- **こまかさはあらく**：1まい たて7×よこ6。形のなめらかさは、面の向き（法線）と絵でおぎなう。
- **ふちの形はアルファ抜き**：花びらの面は、ふつうの曲面（両面にしない1まい）。ふちのなみ・先のまん中の小さなくぼみ・小さな切れこみ・つけ根のすぼみは、アルファ抜きの絵（4とおりを2×2にならべた1まい）でくりぬく。三角形をふやして形を作らない。
  - 絵は白に近い明るさのむら。色（つけ根はこく・先は明るく・内の段ほどこく・花ごとに少しちがう）は点の色。
  - 絵の各ますのまわりにすきまをのこす（ぼかしで、となりの形がまざらない）。UV はます内に合わせる。
- **厚み**：面をふたえにしない。アルファ抜きのときは、ノーマルマップで、ふちのきわ（約18点）を下げて厚みに見せる。アルファ抜きでないときは、ふちだけ帯（`Plant.rimmed`）。帯の厚みは、花のはばの約2%（ばら 0.004マス）。0.009マスは厚すぎた。
- **深さ**：外の段はひらきすぎない（ひらき0.55まで）・高さ1.25倍。横から見て、お皿のように平たくしない。
- **そり返りは外の段だけ、ひかえめに**：先の3割から、外へ花びらの半径の0.1、下へ高さの0.22。0.55／0.9（スカートのように広がる）や 0.22／0.5（まだ強い）はやりすぎ。内の段は立ってまきこむ。
- **光沢**：花びらのつやは、広くやわらかく（つやの小ささ7・強さ0.1）、つやに花びらの色をまぜる（0.85）。白い点のつやはプラスチックに見える。

## 3. 葉
- **カード**：複葉（葉柄・じく・小さな葉5まい）を1まいのアルファ抜きの絵にして、たて5×よこ2の板（三角形20）にはる。じくにそってたれ、まん中で少し折れる。向き・たれ・ねじれは1まいずつかえる。カードは軽いので、1株16まいくらいにふやす。
- **絵**：スキルの `assets/textures/leaf_rose/basecolor.png` を、小さな葉のじくにそって写す（まん中のすじ＝たての中心）。ぎざぎざは先へ向く歯。左右のはしで切れないよう、小さな葉の長さを絵のはばに合わせる。
- **ノーマルマップで厚み**：小さな葉ごとに、ふちのきわで急に下がるふくらみ（高さ 小さな葉の長さの約5%・`(1−a³)^0.5`）＋まん中のすじのくぼみ＋スキルの葉脈ノーマル（小さな葉の向きにまわす）。ふくらみは、ぎざぎざのない輪郭で計算する（ぎざぎざで計算すると横すじが出る）。

## 4. ゲームの材質（three.js）
- 花びら・葉のカード：`map`（アルファ）・`normalMap`・`alphaTest 0.5`・`alphaToCoverage`（MSAA があるとき）・両面描画。
- トゥーン（かげ2だん）では、ノーマルマップの向きだけかえても見た目がかわらない。**ノーマルマップ前の面の向きをとっておき、その差で明るさをかえる**（`tnGeoN`）。
- 花には輪郭線（背面法）をつけない。つけると細い所がきたなく見える。

## 5. 重さのめやす（ばら1株）
- 前：花びら31まい（12×10）＋立体の複葉 → 約4.6万三角形。
- いま：花びら17まい（7×6）・アルファ抜き → 花びら約3,700＋くき・がく約900＋葉のカード320 → **約4,900三角形**。
- スマホでの実測は、まだしていない（はかったら、ここに書く）。

## 6. まだ決まっていない事・つぎに試す事
- アルファ抜きのふちが、近くで少しギザギザ。絵の解像度・`alphaToCoverage`・ふちのぼかしの組み合わせを決める。
- とおくでアルファ抜きの葉がうすくなるか（ミップマップでの欠け）。
- ほかの9しゅるい（チューリップ・ひまわり・ゆり・あじさい・あさがお・コスモス・ラベンダー・デイジー・パンジー）への当てはめ。種ごとに花びらの絵（輪郭）とノーマルを作る。

## 7. サルビア（持ち主に「ぜんぜんだめ。構造を考えて」と言われて作りなおした）
- **まず本物の写真を見て、構造を書き出す**。見られないときは、つなぎ先を申請してでも見る（NC State Extension の写真・plantasyhongos の接写を見た）。向き・数だけをいじって近づけようとしない。
- 構造：葉はぎっしりこんもり（花のない短い枝もふくめる）・緑のはだかのくきを見せない・穂のじくは赤・節ごとに花2つ向かい合い90度ずつまわる・がくはふっくらした赤い鐘（長さとはばが近い）・花はがくから太めのつつがつき出て先が少し下へ・穂の先はつぼみのかたまり・下の花ほど大きい。
- だめだった形：細い針のようなつつ（花がとげに見える）・小さながく・花を横へ広げる・節の間がひらく。
- 1株 約5,500三角形（花の穂4本＋葉のカード55まい）。
- くきは、重力でしなる形にする（持ち主がきめた）：根もとはまっすぐ立ち、先の花の重さで、上ほど外へまがる（はりの曲がり t²(3−t)/2）。長いくきほど、よくしなる。言われたからといって、ジグザグや横へのまがりなど、理由のないまげ方を足さない（不自然になる）。
- 花畑（持ち主がきめた）：1マスに1株の植え方で、となりの株とつながるように、株はマスいっぱいに広げる（くき・葉の根もとを、マスのまん中から0.1〜0.3マスにちらす）。置くときは、株ごとに、ずれ（±0.14マス）・向き・大きさ（0.86〜1.14）・せの高さ（0.88〜1.14）・色のこさ（0.86〜1.06）をかえる（main.js の FLVAR）。
- 葉のカードを、同じ形・同じ絵・同じ間かくでならべない（持ち主に「機械的すぎ」と言われた）。絵は4とおり（2×2）にして葉ごとにえらんでまわす・形（だ円・ふちのなみの本数と高さ・そり・たれ）・大きさ・かたむき・色むらを葉ごとにかえる。水にうく葉は、水面から少しうかせる（重なると水の色がまざる）。
- ゲームだけの植物は、形のもとにする本物の植物をボタンで聞いて（持ち主がきめた）、その写真で構造を書き出し、色と見た目はゲームの絵に合わせる（ねばり草＝モウセンゴケ・ヨルボシの草むら＝ハナニラ）。
- 見え方は、ひかえめ（持ち主がえらんだ「3D感がありすぎる」の直し）：葉のノーマルマップ0.8・花びら0.5・でこぼこの明るさ0.35・かげのこさ−0.24・さかいのぼかし0.12・ハイライトなし・ふちの光0.22・花びらのつや0.03（main.js の LOOK 'b'）。
