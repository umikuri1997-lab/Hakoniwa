## 制作ゲート（全植物共通、同じコードを修正する）

G0: 参照画像を実際に読み、輪郭、高さ/幅、茎径/高さ、葉長/幅、花径/高さ、節数、花序、葉序、付着位置を記録。数値根拠がない場合は推定であることを明記。AI参考画だけで種固有の値を断定しない。
G1: 茎・枝・葉柄・花柄の骨格と粗い輪郭を表示。全体比率と付着位置が合わなければ詳細を作らない。
G2: 葉1枚、花1輪、枝1本などの主要部品をクレイで拡大。滑らかさ、葉縁、重なりを確認。花弁の厚み/曲率を材質でごまかさない。
G3: 全体のクレイを固定8視点（前後左右、上、斜め前左右、斜め後）で確認。花・葉を最低1枚ずつ拡大。参考と同じ角度、倍率、投影で並べる。違いを具体的に記録、パラメータとコードを更新し同じ視点を再出力。必要な回数反復（少なくとも一度の実画像評価と問題があれば再評価）。
G4: PBR素材・UV・表裏・色・粗さ。クレイにない問題が現れたらテクスチャを外し原因を分離する。ゲーム向けは形態リアル＋質感トゥーンを独立設定する。
G5: GLB書出し後に `scripts/audit_glb.py` で数値・構造チェック。Khronos validatorも使用できる場合は実行。ゲームエンジンや独立したglTFビューアで再読込、正面/背面/俯瞰と実プレイ距離のスクリーンショット。Blender内の見た目だけで合格させない。
G6: 高品質版を保存後、必要ならLOD、バッチ、インスタンス、マテリアル統合。遠景と近景の差を確認。画質を落とす変更はユーザー指定・実測に基づく。試作のモデルを量産用にしない。

各ゲートに pass / fail / not_run と画像名、確認結果、次の修正点を記録。not_run は pass ではない。数値検査は美しさ・植物学的正確さ・自己交差を保証しない。目視不能ならその旨を納品時に明示する。`examples/review-v7.json` に結果を記録。

## 種ごとの実装分岐
- 樹木：まず樹冠の外形と枝の成長方向。幹径・樹高・枝先径・枝の量が矛盾しないように設計。種の枝ぶりに合うなら L-system、空間占有、または両者を選択。空間占有では樹冠内の目標点に対し近傍枝先を伸ばし、到達点を除きながら枝を生成する。全樹種に単一の規則を強制しない。枝先での葉密度・空隙を確認。モデル化の詳細は別途実装する（同梱の汎用コードは完全なL-system/空間占有エンジンではない）。
- 花：花弁の数だけでなく長幅比、幅の最大位置、基部、先端、中心線の反り、横断面のカップ、巻き、波打ち、厚み、隣接花弁との重なりを独立パラメータ化。合弁花は連続曲面、複合花序は小花の付着構造をモデル化。バラは品種と開花度に応じて内外の曲率・スケール・配列を変える。V6の試作の固定層をそのまま全品種に使わない。
- 草・農作物：葉長や節間の差を成長位置と関連づける。苗、展開、成熟、結実を器官単位で変更。複葉の葉軸と小葉を別々に扱う。

## 症状から修正する（断定せず切り分け）
| 症状 | 確認 | 修正候補 |
|---|---|---|
| 折り紙状の花弁 | クレイ、ワイヤー、頂点法線、輪郭 | 曲率連続、分割、面の向き、頂点法線を修正。細分化だけで解決としない |
| 白筋・ちらつき | テクスチャなし、角度変更、面の重なり、法線、アルファ | 同一面の重複、貫通、過剰な鏡面、法線異常、透明描画順を個別に検査 |
| 葉が棒に見える | 真上と側面、葉柄接点 | 幅の変化、カップ、曲がり、接点、葉序を修正 |
| 茎が太く直線的 | 寸法比、節、曲線の接線 | 滑らかな曲線、テーパー、枝の接点・太さを再設計 |
| 花が同じ方向 | 上面と全体の投影 | 開花段階、枝接線に沿った自然な向き、個体差 |
| ゲームだけ質感が違う | GLB再読込、照明、色空間、法線、裏面、画像埋込 | 対象ランタイムで再検証。PBR・トゥーン表現差を調整 |

## 実行例
`python scripts/audit_glb.py model.glb --report audit.json --require-images`（テクスチャ指定時。全メッシュにUVが必要な仕様なら `--require-uv` も追加、予算指定時は `--max-triangles N`）。画像が入っているだけでは、実際に貼られたかは保証しない。マテリアルの参照と実画像を確認。
`blender -b --factory-startup --python-exit-code 1 -P scripts/render_review_blender.py -- model.glb review_dir`
V6のバラ試作に対する実測：83,252三角形、37メッシュノード、画像0枚。試作は接地原点や実素材・ゲーム用軽量化の合格を保証しない。
