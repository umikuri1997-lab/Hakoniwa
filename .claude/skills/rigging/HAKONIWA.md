# はこにわで骨を入れるとき（Blender をつかわず、Python で点を動かして3Dから写す）

はこにわの3Dの絵（洞窟のバケモノ `tools/art/cave/bake_rig.py`・飼う生き物 `tools/art/animals/ani_rig.py`・小さな生き物 `tools/art/critter3d/crit_rig.py`・コワイノ `tools/art/kowaino3d/kw_skel.py`）に骨を入れる・直すときの手順。お手本は `bake_rig.py`。

1. 骨の場所は、はかってきめる：高さごとの断面（x・y・z、前うしろの y も）で、手足のまん中の線をしらべ、関節（かた・ひじ・また・ひざ・首）をからだのまがる所に置く。正面と横の図に、骨の線と重みの色をかさねて見る。
2. 骨は親子のならび：root → 背骨 → 頭、背骨 → さこつ（clav）→ 上うで → 下うで、root → もも → すね。かたにのった物（かたの肉・かざり）は、さこつにつける（上うでにつけると、うでを上げたとき、かたがもちあがる）。
3. 重みは、骨までのまっすぐなきょりではなく、メッシュの面の上の道のり（Blender のボーンヒートのように）。まっすぐなきょりだと、からだのそばにたれたうでに、胴の重みがまじったり、すきまをこえて重みがとぶ。
   - 骨のたね：その骨にいちばん近く、ほかの骨よりはっきり近い点。上うでのたねは、かたの関節より下だけ。
   - 1つの点は4本まで・合計1。関節のさかいは、となりの点どうしで少しならす（まん中に 1/0 のさかいを作らない）。
   - UV のつなぎ目で同じ場所に2つある点は、1つにまとめて同じ重みにする（べつの重みだと、まげたときつなぎ目がひらく）。
   - たねのない、はなれた部品（目など）は、まん中にいちばん近い骨にまるごと。
4. べつべつの部品でできた体（あやつり人形のよう）は、部品ごとに1本の骨にまるごとつける（まぜると部品がのびる）。ただし、いくつもの骨にまたがる部品（胴と上うでがつながった部品など）は、なだらかなまま。
5. ポーズは骨ごとの回転（FK）で、子は親についていく。形のきまっていない物（ゼリー・ねばねば）は、まん中の柱のくさり＋まわりのへりの骨で、のびちぢみ（体積をたもつ：たてに s なら横は 1/√s）と、つけねから先へおくれてつたわる波で動かす。
6. たしかめ：うでを上げる・しゃがむ・ふりおろすなど、いちばん大きなポーズで、のびる所・とぶ所がないか、正面と横で見る（スキルの Deformation Test Poses）。数で見るときは、その部位の点が、どの骨の重みをどれだけもっているか出す。
