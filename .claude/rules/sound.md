# 音

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。音量・秒数はコードと `tools/sound/` が本物。たしかめは `tools/tests/` の `tap-sound`・`footstep`・`sound-priority`・`day-chime` など。

## 効果音・UIの音・足音
- 録音の音の出はじめ・曲のビートをはかるときは librosa（`librosa.onset.onset_detect`・`librosa.beat.beat_track`）。ゲームの中では動かさない。ffmpeg で mp3 を書き出すときは、ファイルに書く（パイプ `-` に書くと、読みこむと長さがかわる）。
- 効果音は、こちらで作らない（持ち主がきめた）。音は、本物の録音・持ち主がくれた音・効果音ラボなどの、できている音からえらぶ（切る・大きさをそろえるだけ。オシレーターやノイズで音を組みたてない。作るスクリプトも足さない）。前からある作った音は、そのまま。
- UIの音は、やわらかく小さく近い音（ASMRのよう）：木をそっとたたく音と、こすれる音。ボタンは、もらった音。ピーという電子音（square）を、新しいUIの音に使わない。
- UIの手ざわりの音は、本物の録音（Kenney の CC0。`tools/sound/ui_asmr.py` で、切る・低い音と高い音をけずる・大きさをそろえる）を、鳴らすたびにべつの録音・少しちがう高さで鳴らす（`playU`）。音のさがし先：Openverse（`python3 tools/sound/openverse.py "<ことば>" --license cc0`。使う前に、もとのページでライセンスをたしかめる）。freesound は機械からのアクセスをことわる。OpenGameArt はとどく（CC0 でも、説明に as3sfxr・sfxr とある物は作った音なので、本物の声のかわりにしない）。Kenney は、アセットのページをクッキーつきで開いてから、`download-link/<data-download-id>` を同じクッキー・Referer・ブラウザの User-Agent でよび、かえってきた url を同じようにおとす。小さな生き物のかわいい声は、人の声で作った声（OpenGameArt「80 CC0 creature SFX」）を高くしたほうが、持ち主にえらばれた。
- 「みる」でタップした地面・床（物のない所）は、その場所の足音の録音。畑・土の音も足音の土の録音。
- 「みる」でタップした物の音は材質で分ける（木・石・金物・布・植物・畑と地面・水・草原の御神木と切り株（太い木）・神殿と台座は石。家具は `BL` の `mat`）。音は本物の録音を `playU` で鳴らし、読みこむ前だけ作った音。コワイノ・クモの巣・生き物・置く場所も同じ。物の音が鳴ったタップでは、画面がひらく音・葉の音をかさねない。
- せいれいどうしのおしゃべりは、会話の声を、話す子の声の高さで短く切って、かわりばんこに小さく鳴らす（マップの場所の音と同じく左右・遠いほど小さく。会話の画面の声が出ているあいだは鳴らさない）。
- せいれいがよろこぶ音は、カリンバを高くしたオルゴールの「ちりりん」。なべの料理の音は、ぐつぐつにえる音。どちらも持ち主がえらんだ CC0 の録音（`tools/sound/joy_pot`、出どころは `credits.json`）。収穫・木の実やたけのこをとるときは、はじめにガサゴソ、とりおわったら、かれ葉がこすれる本物の録音（持ち主がえらんだ）。
- ひろった物の音：せいれいが落とし物・たねをひろったときと、図鑑のアイコンをタップしたときは、ピロンという音ではなく、その物の材質の録音（「みる」でタップしたときと同じ）。素材は 木・枝・竹→木、石・鉱石→石、空き缶・延べ棒→金物、布・わた毛→布、草→植物、食べ物→植物（魚は水）。きのこをタップは「ぷにっ」、ちょうの鳴き声は持ち主の羽音。ボタンでない所のタップは、木をそっとたたく音（キャンバス・ボタン・onclick のある物は鳴らさない）。同じ音は 0.07 秒以内に2回鳴らない（`lastSfx`）ので、テストで続けて鳴らすときは `lastSfx` を消す。
- 作業の手もとの音（`work-fx.js` の `WBEAT`）：畑づくり・たね・苗・収穫・草むしり・クモの巣も、動きの決まった所で鳴る（`draw-spirits.js` の `workBeat` をよぶ行動の一覧にも入れる）。はたおり機は録音（すーっ・ごとん）。水やりは、動き1回ごとではなく、持ち主の水の音の3秒ぶんを、おわる0.4秒まえに、2乗の和が一定になる形で重ねてつづける（1回ごとに鳴らすと、とぎれる）。見張り台の弓は、うつときに、ひきしぼる音（持ち主の音）。
- せいれいの足音（`audio.js`）：歩く3Dの動きの、足がつくコマに合わせて、足もとの地面の音（草・土と道・木の床と橋・石・ラグ・冬の雪・雨の日（あらしも）の外の草地・土・道はぬれた地面（家の中・橋・木と石の床や道はふつう）・浅瀬は水の音）を、とても小さく。描くときの時刻（`now/1000+id*1.7`）と同じ時刻で、これから `FOOTLOOK` 秒のうちに足がつくなら、その時刻に予約して鳴らす（道のりで鳴らさない）。近い子から1回に2歩まで。寝ている子・止まっている子は鳴らさない。コワイノも歩きの絵の2コマごとに、ひくく・とても小さく（大きいほどひくい）。ハシゴは、手をかけるたびにハシゴの音（段差のよじのぼりは鳴らさない）。録音は、草・土・木・石・雪・ぬれた地面が持ち主の録音（`tools/sound/src/foot/`、`footstep_rec.py` で1歩ずつ切る）、ラグは Kenney の CC0、ハシゴは持ち主の木のきしみ（`owner_ladder_chou.py`）。`footTick(now)` に時刻をわたせる。
- すべる音（雨の水たまり・すべる水たまりの罠で、せいれい・コワイノがすべる）は、持ち主がくれた効果音ラボの音から「シャッ」を2回ぶん切った物（`owner_slip.py`）。持ち主の音（弓・水やり・畑をたがやす・キラッ）は `owner_sfx4.py`、ハシゴ・ちょうの羽音は `owner_ladder_chou.py`（もとは `tools/sound/src/owner_*.mp3`。切る・大きさをそろえるだけ）。
- 設定の音のクレジット（出どころ）は、ボタンでひらくべつのポップアップ（`CREDIT_TXT`）。音を足したら、ここにも書く。音量のバーは彫りこんだみぞ・こげ色の中身・小さな板のつまみ（草原は木の色）。
- 音の優先順位（`audio.js`）：足音・作業の手もとの音・食べる音・水やり・箱のゴソゴソ・おしゃべり・あいさつの声・足もとの音は「うしろの音」の出口（`lowG`）へ通す（マップの場所で鳴らすときは `sfxLow`、じかにつなぐ所は `lowG||sfxG`）。大事な音（たっせい・ハンコ・なかま・コワイノに当たる・たおす・まもりの光・せいれいの攻撃・オオカゲ）が鳴ると、うしろの音と場所の音を半分にして、0.6秒でもどす。うしろの音は同時に8こまで：いっぱいなら、画面のまん中に近い音だけ入れかえる（もとの大きさでくらべると、小さいコワイノの足音が先に消える）。うしろの音を足したら、この出口へ通す。
- 音のテストで、音を鳴らせるようにするために画面のまん中（450,350）をクリックすると、まん中の御神木の画面がひらいて村が止まる。クリックのあとで `closeSheet()`。うしろの音をつづけて鳴らすテストは、`LOWL.length=0` で前の音をかたづける。
- マップの音（`sfxAt`）は、画面の左右から聞こえ、遠いほど高い音がへる。拡大すると近く聞こえる。家の中を映す（屋根をはずした家が画面のまん中・ふだんの拡大より大きい）と、環境音がこもる。

## 場面の音・曲・環境音
- 大きな場面（なかまが来る・オオカゲの登場・御神木が育つ）の前は、曲と環境音をしずかにして間をつくる。
- 曲（BGM）は、オープニング（タイトル・マップえらび・プロローグ）と大会と火山のおまつりの日だけ。遊んでいるあいだは曲を鳴らさない（持ち主がきめた）。大会は、持ち主がえらんで送る曲（`tools/sound/cup_music.py`、もとの mp3 はリポジトリに入れない。動く大会は MusMus「BGM-141」で、音のクレジットに「BGM:MusMus」。のんびりした大会は魔王魂「fantasy05」、おまつりは魔王魂「ethnic09」）を、「3・2・1・どん！」から大会のあいだと表彰台でくりかえす。長い曲は `SAMPLES` に入れない（はじめにぜんぶ読みこむと1曲で約70MB）：`CUPSONG` に書き、鳴らすときだけ audio の要素で少しずつ読む。タイトルでは、はじめてさわったとき（どこでも）から鳴らす（ブラウザは、さわるまで音を出させない）。
- 「マップを読みこみ中…」の画面だけは、読みこみ中の曲（OpenGameArt「JRPG Piano」CC0、`tools/sound/load_music.py`）をくりかえし、おわったら1秒で消す（持ち主がえらんだ）。ボスが出たときなどの効果音・環境音はそのまま。昼・夜・ボスの曲のデータは、のこしてある。
- 朝6時（魔王魂「orchestra03」）・夜12時（魔王魂「healing11b」）に、曲のはじめ20秒をさいごを小さくして切った物（`tools/sound/maou_chime.py`。曲のファイルは魔王魂の決まりでリポジトリに入れない）を、1回だけ鳴らす（はいりは `CHIMEIN` 秒、おわりは `CHIMEOUT` 秒かけて、いつ消えたかわからないくらいに小さくする）。
- iPhone は、さわったとき（touchend・click）の中で音を1つ鳴らさないと、タイマーであとから鳴らす音（曲）が出ない。pointerdown では音がひらかない。さわったときに、だまった短い音を鳴らす（`audioUnlock`）。
- 環境音（`tools/sound/season_amb.py`、効果音ラボの録音）：朝5時〜7時半は朝の音（どの季節も）。昼は春・夏はそれぞれの音、秋・冬は鳥の声。夜は夏の夜の音、ほかは虫の声（夕方17.5〜20時だけ、その場でつくる虫の声。大きさ0.5）。雨の日は雨の音だけ。朝と夕方にゆっくり入れかわる。会話の文字の速さは話す人ごと。
- 朝の体そうのあいだは、体そうしている子みんなの声（のばした声。近い子から `TAISON` 人。みんな同じ音。それぞれの声の高さ・ハモりは、持ち主がやめた。何人かのときは、子ごとに高さを ±12セント・こもり方を少しずつかえて合唱のように重ねる。まったく同じだと1人に聞こえる）で、子ごとにちょっとずつずらして、小さく、体そうの曲のように（上がって下がる形のくりかえし・4拍ずつの頭を強く・音をきびきび切る・声をやさしくゆらす。持ち主がきめた）、拍のはっきりした曲をくりかえす。
- 焚き火・たいまつのそばの場所の音は、焚き火の録音。料理の火の音は、持ち主がくれたパチパチの音（`owner_fire.py`）。

## 戦いの音
- せいれいの攻撃の音は、持ち主がえらんだ本物の録音（`tools/sound/atk_rec.py`。火はもらった音）。
- コワイノに当たった音は「ぽふっ」（Kenney の録音、当たって見える時刻に）。コワイノがせいれいをたたいた音も「ぽふっ」、たおした音は「さらさら」。持ち主が「コワイノの音」のページできめた。
