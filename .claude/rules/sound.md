# 音

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。音量・秒数はコードと `tools/sound/` が本物。たしかめは `tools/tests/` の `tap-sound`・`footstep`・`sound-priority`・`day-chime` など。

## 効果音・UIの音・足音
- 音を直すときは、候補の録音をいくつか作り、聞きくらべのページ（Artifact）にして、持ち主に聞いてえらんでもらう（持ち主がきめた）。文章で、どんな音にするかをたずねない。
- 録音の音の出はじめ・曲のビートをはかるときは librosa（`librosa.onset.onset_detect`・`librosa.beat.beat_track`）。ゲームの中では動かさない。ffmpeg で mp3 を書き出すときは、ファイルに書く（パイプ `-` に書くと、読みこむと長さがかわる）。
- 効果音は、こちらで作らない（持ち主がきめた）。音は、本物の録音・持ち主がくれた音・効果音ラボなどの、できている音からえらぶ（切る・大きさをそろえるだけ。オシレーターやノイズで音を組みたてない。作るスクリプトも足さない）。前からある作った音は、そのまま。
- UIの音は、やわらかく小さく近い音（ASMRのよう）：木をそっとたたく音と、こすれる音。ボタンは、もらった音。ピーという電子音（square）を、新しいUIの音に使わない。
- 木の床・橋の足音は、持ち主が聞きくらべてえらんだ CC0 の録音（子どもが木の床を歩く音。`footstep_rec.py`）。
- 「みる」でタップした地面・床（物のない所）は、その場所の足音の録音。畑・土の音も足音の土の録音。
- 「みる」でタップした物の音は材質で分ける（木・石・金物・布・植物・畑と地面・水・草原の御神木と切り株（太い木）・神殿と台座は石。家具は `BL` の `mat`）。音は本物の録音を `playU` で鳴らし、読みこむ前だけ作った音。コワイノ・クモの巣・生き物・置く場所も同じ。物の音が鳴ったタップでは、画面がひらく音・葉の音をかさねない。
- せいれいどうしのおしゃべりは、会話の声を、話す子の声の高さで短く切って、かわりばんこに小さく鳴らす（マップの場所の音と同じく左右・遠いほど小さく。会話の画面の声が出ているあいだは鳴らさない）。
- せいれいがよろこぶ音は、カリンバを高くしたオルゴールの「ちりりん」。なべの料理の音は、ぐつぐつにえる音。どちらも持ち主がえらんだ CC0 の録音（`tools/sound/joy_pot`、出どころは `credits.json`）。うけとった（おくりものの画面）は、おもちゃの鉄琴の録音（「ちん・ちーん」）、たっせい・村レベルアップ・あたらしいレシピなど `level` の音は、qubodup の「Level Up」の録音（同じ音）、はじめて置いた家具とスポットができた場面（光の線・家具がはねる・光の柱の3か所とも）はチャイムの「きらーん」、作業台・料理の「できた」は、あわがはじける「ぽん」（`tools/sound/reward_rec.py`。持ち主がサンプルページの候補からえらんだ）。収穫・木の実やたけのこをとるときは、はじめにガサゴソ、とりおわったら、かれ葉がこすれる本物の録音（持ち主がえらんだ）。
- キラリン系の音（うけとった・たっせい・はじめて置いた・流れ星・よろこぶ・ひらめき/レベルアップ・カミサマが来た）は、ゲームの中で鳴る大きさを、ボタンの音と同じ -35 LUFS（400ミリ秒ごとの大きさの、いちばん大きい所）にそろえた（持ち主がえらんだ）。これより大きくしない。新しいキラリン系も同じ大きさにする。
- ブロックをこわす音：土は、ほる音の「キーン」を切った録音（`digSoil`）、石とれんがは石をほる音だけ（`blkStone`）（持ち主がえらんだ）。もとの `dig` は、うしろに高いひびきがのこる。
- 音の優先順位（`audio.js`）：足音・作業の手もとの音・食べる音・水やり・箱のゴソゴソ・おしゃべり・あいさつの声・足もとの音は「うしろの音」の出口（`lowG`）へ通す（マップの場所で鳴らすときは `sfxLow`、じかにつなぐ所は `lowG||sfxG`）。大事な音（たっせい・ハンコ・なかま・コワイノに当たる・たおす・まもりの光・せいれいの攻撃・オオカゲ）が鳴ると、うしろの音と場所の音を半分にして、0.6秒でもどす。うしろの音は同時に8こまで：いっぱいなら、画面のまん中に近い音だけ入れかえる（もとの大きさでくらべると、小さいコワイノの足音が先に消える）。うしろの音を足したら、この出口へ通す。

## 場面の音・曲・環境音
- 大きな場面（なかまが来る・オオカゲの登場・御神木が育つ）の前は、曲と環境音をしずかにして間をつくる。

## 戦いの音
- せいれいの攻撃の音は、持ち主がえらんだ本物の録音（`tools/sound/atk_rec.py`。火はもらった音）。
- コワイノに当たった音は「ぽふっ」（Kenney の録音、当たって見える時刻に）。コワイノがせいれいをたたいた音も「ぽふっ」、たおした音は「さらさら」。持ち主が「コワイノの音」のページできめた。

## まとめ（細かい決まりは `tools/sound/` とコードを見る）
- 曲（BGM）は、オープニング・大会・火山のおまつりの日だけ。遊んでいるあいだと、マップの読みこみ中は曲を鳴らさない（持ち主がきめた）。読みこみの画面は2つある：ふつうの「読みこみ中」（`STLD`）と、プロローグのあとの「読みこみ中…%」（`#pro` の中・`PROLD`）。止めるときは、両方を止める。長い曲は `SAMPLES` に入れない（`CUPSONG` で少しずつ読む）。iPhone は、さわったとき（touchend・click）の中で音を1つ鳴らさないと曲が出ない（`audioUnlock`）。
- 知らせ（`toast`）の「ちりりん」は、大事な知らせだけ（`TOASTBIG`：たっせい・なかま・夜を守った・ステージの節目・誕生日・行事がはじまった・カミサマが来た。持ち主がきめた）。ひろった・もらった・建った・作った・見つけた などは音なし。大事な知らせを足したら `TOASTBIG` に足す。こわしたブロックをひろった知らせは出さない。
- 上の数（パワー・せいれい・食料・素材）がふえた音は、タブの「ぱたっ」の録音（`count`）。マップの読みこみ中と、村が出てから1.5秒（はじめて数が入るとき）は鳴らさない（持ち主がきめた。`LDEND`）。
- ひろった物・タップした物の音は、材質の録音（`playU`）。ピロンという音にしない。せいれいが拾った知らせ（`toast` の4つめ `mute`）は、よい知らせでも、ちりりんを鳴らさない（持ち主がえらんだ）。作業の手もとの音は `WBEAT` の動きの決まった所で鳴らし、`workBeat` をよぶ行動の一覧にも入れる。足音は、描いた歩く絵の足がつく所（歩いた道のり `WLKD` と今の速さ）に合わせて予約して鳴らす（絵のコマと同じものさしで。時計で鳴らすと、絵とずれる）。うしろの音（足音・作業・おしゃべり）は `lowG` へ通す。 作業の音は、絵をかくたびによばれるので、話している・止まっている子（`onHold`）と `paused()` では鳴らさない（つなげて鳴らす音は、そのとき止める）。
- 音を足したら、設定の音のクレジット（`CREDIT_TXT`）にも書く。持ち主がくれた音・CC の録音の出どころは `tools/sound/` の `credits.json`・`CREDITS.txt`。音のテストでは、音を鳴らせるようにするクリックのあと `closeSheet()` と `lastSfx` を消す。
- 同じときに鳴る知らせの音は、かさねない。「うけとった」は、たっせいの音（`lvSfxOn`）が鳴っているあいだは鳴らさない（持ち主がえらんだ）。
