# 画面の文・セリフ・説明の書き方

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。

## 説明の文
- アイテムの説明は短く、そのアイテムが何かと効果（壁ならじょうぶさ）だけを書く。それが何かを説明する文（「川や池にかける木の橋」「壁にかけるふくろ」「火山のふもとの守り」など）は、けさない。見た目のくわしい説明や、同じことのくりかえしなど、しつこい説明はしない。
- ひでんのしょ・しくみの説明に、1つずつの家具の名前やちがい（「つぼは1マス」「ろうそく・ランタン・フロアランプは〜」「いす・ソファ…など」）を書かない。「家の中に置くあかり」「かざり」のように、しゅるいで書く。ほかに家具の名前を書いている所を見つけたら、けす前に聞く。
- クエストの説明に、おつげの名前（「木をあつめる」など）や、ほかの手だて（「伐採場でもふえる」）を書かない。クエストが出てから何日、のようなメタな書き方をしない（オオカゲは「オオカゲが来るまで：あと〇日」を進みぐあいに出す）。説明しすぎていないか、気になる所は、直す前に聞く。
- ステータスの説明に、「〇〇で遊ぶとのびる」「火のせいれいがいちばん強い」のような、のばし方・くらべを書かない。それが何かだけ（「歩く速さ。」）。
- 画面の説明に、「〇〇のせいれいがとると+1」のような、だれがやると何がふえるかの注意書きを足さない（冗長）。
- 説明に、ほかの物・ほかの子・ふつうの物とのくらべを書かない（「ふつうの灯りは0.8倍」「ほかの子は30」「ふつうの水べより」「2倍（25%→50%）」など）。その物の効果の数字だけを書く。「家の壁にはならない」「1マス歩く時間」「（オオカゲは3分）」「（小数点以下は切りすて）」「（1つの家で2つまで）」「Lv3では〜」「せいれいが建てる」「家の住み心地で〜倍」、置き場所（「横向きの家の壁にかける」「段差の下に置く」「池の上に植える」など）のような、ことわり書き・例外・数の上限・計算のこまかい注意も書かない。
- 説明に、くらべ・レア度の言葉がないかは `tools/tests/text-rules.cjs` がさがす（セリフ・日記・手紙のファイルはのぞく）。くらべでない文（「ふつうの「コワイノ」」など）は、そのテストの `OK` に足す。
- 特性・家具・建物などの効果の説明は、効果だけを書く（物語やいきさつは書かない）。効果は、どれも数字で書く（「歩く速さ1.25倍」「木材+1」など）。「速い」「へりにくい」のような数字のない書き方にしない。
- 特性は、その属性の子が使う物だけをつける（しゅうかく上手は木。料理じょうずはなくした）。
- 章のはじめからいる子（ホムラ。新しい章でも、はじめの1人）の特技は「ねばりづよい」（スタミナ+10・つかれのとれる速さ2倍）。フタバだけは、その上の「だいちのちから」（`daichi.js`：みどりでもちこたえて消えない）。ほかの子には出さない。

## ことば・呼び名・書き方
- 画面に出す文章は、ひらがなを多めのやさしい言葉で。
- 画面の文（見出し・説明・ひでんのしょ・図鑑・クエストの説明・知らせ）では、せいれいを「子」と書かない（「立つ子」「寝た子」→「立つせいれい」「寝たせいれい」）。文を足したら、`子` でさがしてたしかめる。登場人物のセリフの中の「子」（「どんな子かなあ」「子らの笑い声」など）は、そのままでよい。
- 風のせいれいの性格は1つ（キザで自由人）。名前などで2つの言いかたに分けない（`elemKey` は風を `wind` だけ）。火は、あねご（ホムラ・火山の一部の子）とあにき（ホノ・草原の子）の2つ。
- ゲームの中（セリフ・説明・知らせ）では「火の子」「木の子」のような「〇の子」と言わない。「火のせいれい」「木のせいれい」「水のせいれい」と言う（このファイルやコードのメモの中は、みじかく「火の子」と書いてよい）。
- 絵文字は使わない（新しいふきだし・知らせ・説明・このファイルの文にも）。思い出のメモは `memo(印,文)` の2つをわたし、印はドットのアイコンの名前（`PXI`）。前のセーブ・前からのコードの絵文字の印は、出すときにアイコンにかえる。画面に、印をそのまま文字で出さない。
- 画面の文での呼び名は「まもりの光」（「守りの光」「守り神の光」と書かない）。
- 家具・建物の効果が重ならない（いくつ置いても1つぶん）ときは、説明の効果のうしろに「（重複なし）」を書く。スポットの効果には書かない。
- 「（重複なし）」と、火山の守護の台座の「守護の力をとりもどす台座。ヌシ様が帰ってくる。」は、いる（けさない）。
- 画面に出す文に、（）の注意書き・ことわり・おぎない（「（朝になったら）」「（4マス）」「（レア）」「（タップで説明）」「（いちばん上は15）」など）を書かない。（）は、数・名前・いまの状態を出すときだけ（「素材（3/50）」「直す（石材3）」「カーテン（緑）」「つかれ（回復中）」）。
- レア度（「レア！」「激レア」など）は、画面に書かない。
- カミサマにパワーをわたして何かをもらうとき（道具・レシピ・強化・建てる・買う など）は、パワーの音（`sfx('power')`）。まもりの光・こもれびのまもりは、それぞれの音のまま。
- 通知・警告は短く。「〇〇が足りません」のように事実だけ書き、「依頼ボードでせいれいにたのもう」のような案内は足さない。

## 会話・セリフ
- 草原のメインの会話は、短く。同じことのくりかえし・あいづちだけの行は入れない。
- セリフに「わかる！」（あいづち）のようなギャル語・はやり言葉を使わない。あいづちは「うん」など。
