# クエスト・お話・会話

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。

## クエスト・イベント
- 村を切りかえるときは `resetVillageTransient` で会話・訪問待ちを整理し、`endClap` で拍手も終わらせる。村の状態をさわる遅延処理は、元の `S` と `VILLAGE_SESSION` が同じときだけ動かす（`villageTimeout`）。聞き終えていない会話は元の村の `pendTalk` に残す。
- クリアのあとに、評価の画面を自動で出さない。点・ランクは出さない。村のふりかえり・クリアまでの記録（`reflect.js`、`S.clearRec`）は、思い出帳の「この村のおわりに」から何度でも開ける。再会のあと30秒（`reunionCalm`・`calmNow`）は、レベルアップ・うけとった・スポットの知らせをまち、そのあと「思い出帳にのこした」を1回だけ知らせる（`S.flags.rfNote`）。
- 草原の最後の防衛は、最後の依頼の会話を聞いてから3日後以降、ヌシのかけらを御神木に2つ届けたら始まる（`clearConds`。人数・パワーなどのじょうけんは入れない）。始まった防衛・再挑戦は巻きもどさない。
- 最後の防衛は、せいれいが5人・フタバがいる・御神木があるときだけ始まる（`finalCheck`）。止まっているときは、その理由を目標の進みぐあいに出す（`grassEndingGoal` の `why`。`finalCheck` と同じ条件にする）。
- クエストの発生とクリアは昼だけ（夜は23時〜6時）。
- 「芽のそばのごはん」（`warmMeal`）の依頼の会話は、燃やさない火のつぎの日の17時から（`warmMealReady`・`S.flags.warmDay`。朝から晩まで芽のそばにいたのを見てから）。
- 会話の中で、つぎへ送れない見せる動き（`SACRED_AWAY`：芽が出る・芽をのぞきこむ）は、セリフを読んだら会話のわくと立ち絵をしまい、動きがおわったら、もどす（`dlgAway`、`#dialog.away`）。何も出ずに「つぎへ」がおせないだけの待ちを作らない。
- オオカゲの前の夕方の会話は、はじめての1回だけ4行。2回めからは、ひとことだけ（`eveAgain`）。
- 何回も出る会話（オオカゲの前の夕方・追いはらった朝・もどったときのひとことなど）は、いくつか用意して、ぜんぶ出しおわるまで同じ物を出さない（`pickFresh`）。同じセリフをくりかえさない。
- サブクエストのおねがいの会話は、聞きおえたら受けたことにする（会話のとちゅうでメインの目標ができても、`subTalk` の `offer`）。
- 大きなかげのあと（`S.flags.kgMark`）は、そのマスと左右・手前に物がない所に出す（`kgOpen`）。あとから草・茂みなどでかくれたら、空いた所へうつす。
- 物を見にいく予定（`QUEST_VISITS`）のあいだは、サブクエストのふきだしを出さない。サブクエストの見にいく予定（partKey が `<ステージ>:sub:<k>:`）は、そのサブクエストを受けているあいだだけ残す（`partVisitStale`）。メインの目標の名前で消すと、毎回入れなおして、ふきだしがずっと出なくなる。
- オオカゲが来るかの表示と夕方の会話（`bossDays`・`bossTonight`）は、来る判定（`waveFor`・全滅のあとは5人 `S.wipe`）と同じ条件にする。来る日にそろっていなくて持ちこした分（`S.bossOwed`）は、そろって3日たった夜に来る。
- おみおくりの前（`unb`）の子は呼びもどせない。おみおくりができなくなる道（お墓をこわす・棺をはこぶ子が消える）では、`unb` を消して、おみおくりがすんだことにする。お墓も棺もないのに `unb` がのこった子（まわりに空きがなくて、お墓を置けなかった など）は、朝に `unbFix` で消す。新しい子の「！」が出たままでも、消えたキーキャラの呼びもどしを先にする（`summonMorning`）。
- 消えたキーキャラは、神殿から1日に1人ずつ、先に消えた子から呼びもどす。先に待っている子がいれば「次の朝」と言わない（`backWhen`）。
- 会話がおわってすぐに、べつの会話をつづけて出さない。おわってから3秒まって、つぎの会話があれば出す（`DLGWAIT`・`dlgGap`。同じ会話の `after` でつづける物はそのまま）。タップで始める会話はまたずにすぐ出す（`DLGTAP`）。同じ会話は、出ているあいだ・まっているあいだに、かさねて出さない（何回タップしても1回）。
- ムービーや会話は、最後まで見てから「見た」にする。途中でゲームをとじたら、はじめからやり直す。
- 章のはじめの場面（草原の夢・着いてからの会話 `INTROS`）は、はじめてでも場面ごとにスキップできる（会話の行に `skip:1`、`dlgSkipBtn`）。スキップは、さいごまで見たのと同じにおわらせる（`after` をよぶ。「見た」・思い出帳にも出る）。
- はじめて遊ぶ人（どの土地もまだ遊んでいない `lastPlayed`）は、タイトルの「はじめる」から土地をえらぶ画面を通らず、草原の `newGame(0)` へ。夢の場面の前の待ち（花をあむ動き）は、タップですぐ会話へ（`tapOr`）。場面転換の白・黒のフェードは `SHIFTMS`。草原のはじめのベッドの目標は1つのまま、進みぐあいに、いまの手順だけを番号つきで出す（`bedStep`）。たしかめは `tools/tests/first-30.cjs`。
- 思い出帳の「はじまりの草原へ」（`grass:intro`、`prepareGrassIntroReplay`）は、`newGame` と同じ村のはじめ（霧・切り株・雑草）で、花かんむりの夢 → 着いてからの会話。カミサマの話（プロローグ）は入れない（火山の「火山のふもとの村へ」と同じ）。
- お供えで手に入る家具は、レシピにもクエスト報酬にも出さない。
- 精霊のセリフでは「最後の夜」と言わない（ユーザーにとっての言い方で、精霊には関係ないため）。
- せいれいは「ヨルノオオカゲ」の名前を知らない（だれも教えていない）。セリフでは「あの大きな影」などと言い、名前は画面の名札・目標・知らせだけに出す。
- 精霊など物語の登場人物に、メタ発言をさせない（「タップ」「メニュー」「『おく』で」「村レベル」「〇マス」など、画面や操作の言葉）。操作の説明は、ヒントや案内の文に書く。
- 1章（草原）で説明したこと（会話での説明・操作の案内）は、2章（火山）からの章ではくりかえさない。新しい章でも同じ。クエストは `skip`、会話・案内は `WD===0` のときだけ出す。
- 目標が止まる条件を足したら、その理由を目標の進みぐあいに出す（切り株が家の中 `fieldPrepNeed`・最後のかけらへ行けない `shardBlocked`・クリアのあとヌシ様の話の前 `nextStageGoal`）。たしかめは `tools/tests/softlock.cjs`。
- 古い iPhone（iOS 15.3 まで）・古い Android にない書き方（`Object.hasOwn`・`Array.prototype.at`・`crypto.randomUUID`・正規表現のうしろ読み）は使わない（さいごの1つは `lastOf`）。
- 霧が晴れても、大きな知らせ・カメラの演出は出さない（持ち主がきめた）。遊んでいるあいだに晴れたマスは、その場でうすれて消える（`FOGT`。マップを作っているあいだは、うすれずに晴れる）。思い出の場面（`MEMRUN`・`NOSAVE`）の一時の花などでは晴らさない。
- 草原の新しい属性の初回召喚は、対応するメインクエストを受けてから（`storySummonOK`）。召喚候補と実行時の両方で確認する。既にいる属性の追加や復活はそのまま。
- 古いセーブの読みかえは、`js/save.js` の `MIGRATIONS` のうしろに1つ足す（セーブの版の番号 `S.mig`。新しいゲームは `SAVE_VER` からはじまるので走らない）。`S.flags` の印で1回だけにする読みかえ（`continueGame` の中の前からの物）は、もう足さない。たしかめは `tools/tests/save-ver.cjs`。
- メインクエストを途中に足したら、古いセーブのクエストの番号（`S.quest`・`S.qStory`）を、読みこむときにずらす（`MIGRATIONS` に足す）。
- 草原のサブクエストは、順番の決まった物（`checkSub` の `scheduled`）は条件がそろえば出す。ほかはランダムのデイリー（`subDaily`）：1日に3つまで（`DAILYN`・`S.dailyDay`）、受けているデイリーも3つまで。話しかけていないおねがいは、つぎの朝にほかの物にかわる。同じ子のおねがいは、1つずつ。デイリーは、メインの会話や順番の決まったサブクエストがあっても出す。デイリーのふきだしは、ほかのふきだしといっしょに出す。
- 草原のサブクエストを、メインの目標がおわってから出すときは `SUB_MAIN_AFTER`（いくつかなら配列で、ぜんぶ。「畑を10にしよう」`farm10` は `farm6` と、ホノが来る `fire` のあと）。
- 草原のなかまのあとのメインクエスト：火は「芽のそばのごはん」（`warmMeal`：切り株のそばに食卓を置き、フタバがそこで食べる `warmEat`）、水は「ハスのそばの水あび」（`aoFish`：ハスを咲かせ、ハスのそばの水べで3人が水あび `aoBath`）、風は「空からのながめ」（`kite`、たこあげ `stageKite`）。オオカゲのあとは「こもれびのまもり」（`guardLearn`：依頼の会話でおぼえ、夜に火のせいれいを守るとクリア。ピンクの会話 `e06` は、メインをもうすぎた古いセーブだけ `guardSevOld`）。足したときの読みかえは `migrateStory3Ins`（名前で）。
- お話の道（`js/route.js`）：草原は、土のあと、火・水・風の3つの話（`ROUTE_ARCS`：むかえる・御神木の調べ・そのあとの話）の順を、その話の目標になったときにえらぶ（`routePop`。`S.flags.route`、新しいゲームは []、前のセーブはないので、いまのならび）。オオカゲの話（`ROUTE_BOSS`）は2つめのあと。こもれびのまもり・オオカゲとたたかうのは火のせいれいなので、火は1つめか2つめ（1つめが水か風なら2つめは火）。`QUESTS1` をその順にならべかえる（`routeApply`、`S.quest` は番号のまま）。御神木は、何番めの調べかで、芽・一枚目の葉・ヌシ様の声（`routePos`・`routeOut`・`routeVoice`、`sacredStage` は調べの数）。会話の中の、前のなかま・木のようすは、何番めかでかえる（`routeWaterTalk` など）。火・水・風の話に会話を足すときは、どの順でもおかしくないかたしかめる。たしかめは `tools/tests/route.cjs`。
- カミサマとの交換・おつげの出し方は、草原のサブクエスト（`SUBQ` の `trade`・`oracle`、いものたねのあと）。交換の依頼はカミサマが話す（`who:GOD`、カミサマに黄色い吹き出し・タップで会話）。交換をおえて店をとじたら、その場でお礼の会話をして、カミサマが旅立つ（`godLeave`）。交換をしないまま火のせいれいをむかえたら、旅立ちの会話（`GOD_FAREWELL`、どちらでも同じ文）を1回して旅立ち、交換のサブクエストはとりやめ（`godFarewellTick`）。古いセーブは `migrateTutSub`（`S.flags.tutSub1`）で名前で読みかえる。それより前の読みかえは、交換・おつげが入っていたならび（`QUESTS1_V3`）の番号を使う。
- なかまが村に物を置いてひとこと話すしくみ（`VGIFT`）はなくした。もどさない。
- オオカゲは、追いはらえなかったら、3日後にまた来る（`bossNight`）。はじめて追いはらったあとは5日ごと。
- ボスが来ることは、前もってわかるようにする。オオカゲの目標は、ほかの小さな目標の進みぐあいといっしょに、来るまでの日数をいつも出す（`stepQuest` の `tail`）。ヌシのかけらの2つめは、ささげる前に、影の群れがやってくることをたしかめる（`shardWarnAsk`。ゲームの外の言い方にしない）。
- メインクエストは、前のなかまが来てから何日か待たせない（つぎのクエストは、すぐ出してよい）。
- 水のせいれいの案内役をえらんだら、2人が村をまわりおわるまで（`S.tour`）、つぎのメインの会話・集まりを出さない（`tourPair`。目標の欄には、あんないしていることを出す）。あんないの2人は、お話を待つ・もどる・おしゃべりなどをやめて、すぐあんないをはじめ（`TOURQUIT`）、あんないのあいだは、だれもつぎのお話を待って立ちどまらない（`storyContinues`）。
- メインの会話は、セリフのある子（その場にいる子）がみんな集まってから話す（`storyLineCast`）。
- お話・調べ・お礼にいる子が、お墓・旅に出ていて村にいないときは、ほかの子も切り株・話す場所へ集まらない（`qMissing`・`fieldCastFull`）。そろってから集まる。
- 御神木のそばの立つ所（`storySlotCells`）は少ない（切り株のまわりいがいは物を置ける）。うまっていたら、もう少しはなれた所に立つ（`storyWaitStand` の広いさがし方）。立つ所がないままにすると、メインの会話が止まる。歩ける花（`kind:'plant'`）の上は、広いさがし方でだけ立てる（御神木を花畑でかこむ村で止まった）。
- 集まる子の定位置（`storySlots`・`introSlots`）は、きめたあと作りなおさない。定位置が物でふさがった・行けなくなったら、そばの空いた所に立たせる（定位置を待ちつづけると、ほかの子も止まったままになる）。10分止まっていた行き先（`avoidJ`）は `startAct` でひとやすみにかわるので、これもさけ、切り株に近い空いた所（`storySlotCells` の順）をえらぶ。
- 場所が決まっていないメインの会話：ひとりで話すなら集めない（ふつうに暮らしたまま話しかけられる）。みんなで話すなら、話す子の近くの空いた場所に集まる（`storyOpenSpot`）。集まる子は、ひとりずつずらした定位置に立つ（`storySlots`。となりどうしは少しさける）。御神木の場面は、切り株のすぐそば（切り株のうしろの列には立たない）。
- メインの会話を待つときの向き：待つ場所に物（切り株・家具・足あとなど）があれば、そちらを向く。何もない場所なら、正面（手前）を向く（`storywait` の `a.front`）。
- お話によばれた子は、仕事・遊び・荷物はそのままで、すぐ向かい、おしゃべりをはじめない（`storyCalled`・`fieldActorReady`。おなかがすいた子・ごはんを持っている子だけ先に食べる）。つぎのお話・調べの段階がすぐつづくときは、解散せずにその場で待つ（`storyContinues`、ゲームの1時間まで。夜・コワイノ・空腹でやめる）。集まるときの案内は、何人も集まるなら「みんなが」。メインの会話・調べに向かっているあいだは、ピンクの会話を出さない（`mainGathering`）。
- レシピをえらんでひらく（`js/lvpick.js`）：村レベルが上がるたびに1回、えらべる物（`LVPICK`：家具・かざり・遊び・看板など。お話でつかう物と家の材料は入れない）から3つまで出し、1つえらんでおぼえる（`S.lvPick`、`lvPickWait` の物は `checkLevel`・`lvOK`・`learnedIn` でおぼえない）。えらばなかった物は、つぎにまた出る。フリーモードは、えらばずにおぼえる。前のセーブは `S.flags.lvPick1`。お話でつかう物を足したら `LVPICK` から出す。たしかめは `tools/tests/lvpick.cjs`。
- 村のゆめボード（`js/yume.js`、依頼ボードの「ゆめ」、どのステージでもはじめから）：自分でえらんだやりこみ目標（`YUME`：村づくり・地形づくり・せいれい・あつめる。数は実数）を3つまで（`YUMEMAX`）かかげる（`S.yume`）。2秒に1回たしかめ（`yumeTick`、`stepWorld` のはじめ）、たっせいしたら、むずかしさでパワー50・100・200（`YUMEPT`）、むずかしい目標は設計図（出ないときはパワー100）・思い出帳・紙ふぶき。目標を足したら `YUME` に。たしかめは `tools/tests/yume.cjs`。
- 「ものひろいの日」の落とし物は、村の中の、せいれいが歩いて行ける空いた所に落とす（`monoDrops`）。
- 植える芽（`sprout`）は、せいれいが歩いて行ける所だけに置ける（`plantReach`）。池・川の上（ハス）は、行ける岸から水の中をおよいでとどく所ならどこでも（`plantWet`。せいれいは水に入って植え、水の中ではおよぐ絵）。行けない所に置けると、植える予定の10この枠がうまったままになる。
- 世界の設定（ヌシ様・コワイノの正体・さいごの章）は `STORY.md` にある。セリフや図鑑を書くときは読んで、くいちがわないようにする。
- ひろった物（落とし物・つり・霧の宝箱。レシピとヌシのかけらはのぞく）は、もちものに直接入れない。せいれいが頭の上につんで箱へはこび（`r.citem`・`addItem`・`sitem`）、しまったときに入れて知らせる（`stowItem`）。やすらぎの砂・灰・たねは、しまう家具、ほかはおそなえ箱（なければ、しまう家具）。しまう箱がひとつもないときだけ、そのまま入れる。
- はたおり機・粉ひき小屋・炉へ入れる物と、おたきあげの素材も、頭の上につんではこぶ（`carryIcons` の `r.ppk`・`r.spk`・`r.otaki`）。
- 依頼ボードでできた物も、作ったせいれいが頭の上につんで、おそなえ箱（なければ箱）へはこび、しまったときに入れる（`craftCarry`・`r.cmade`、しまったときの知らせ `madeStow`。「ひろった」とは言わない）。1回の依頼でできた分（木の矢10本・柵10こなど）は、ひとまとめで1つ（`'set:'+id`・`setId`・`setN`）。頭がいっぱいなら、その場に落とし（`d.made`・`tap`）、はこぶ。箱がひとつもないときだけ、すぐ入れる。たしかめは `tools/tests/craft-carry.cjs`。
- 御神木のまわり：物は4×4と切り株のまわり1マスでことわる。切り株の絵の下の2×2（`SACREDBASE`）は、だれも通れない（`STUMPB`）。道・床は、この2×2だけことわる（育った木の絵が道にかかってよい）。切り株の4×4が空いているかの判定（`sacredRootFits`）も、同じ決まりにする（ちがうと、置けた道で「木のまわりにある物を、先に片づけよう」のまま止まる）。「切り株のそば」は木のマスから6マスまで（`FIELD_NEAR_R`）。
- 御神木の出番（`FIELD_PLAY`）のごほうびは物にしない。村のせいれいみんなのたのしさ+10と、木のようすのひとこと（`bonus.word`）。
- 古い家のあと（小屋）は3しゅるい（`RUIN_KINDS`：納屋6×4・台所5×4・物置4×4）。大きさと、はじめからある、こわれた家具（むかしの使いみちがわかる物）がちがう。家具はスポットにならない組み合わせにする。壁が1つは、こわれたあともなく、なくなっている（`ruinGap`。直すだけでは家にならない。前のセーブは `S.flags.ruinGap1`）。しゅるいのない前のセーブの小屋は、晴れるときに入るしゅるいをえらぶ（入らなければ5×4のまま）。
- 古い家のあとが家にもどったら、近くのせいれいが中のおくへ歩いて行き、わすれ物を見つけて話してからわたす（`f.find`・`ruinFindTick`。昼・コワイノなし・会話なしのときだけ、行ける子がいなければあとで）。
- 霧のエリアの1つに、そのまま住めるお屋敷（12×9、部屋3つ、`fogF` の `mansion`）。場所は霧を作るときに1回だけきめ（古いセーブは `S.flags.mansion1`）、晴れたときに建てる（`fogMansionBuild`）。

## ストーリークエストの実装ルール
- 草原のメインの目標は、はじめ（神殿〜カミサマが旅立つ「交換」「おつげ」まで）は1つずつ。そのあとは、小さな目標をまとめた形（`stepQuest`）。`steps` の小さな目標がぜんぶできたらクリアで、どれからしてもよい。会話は、依頼の会話とお礼の会話を1回ずつ。小さな目標の名前は `parts` に入り、`qAt`・`qDone`・`qNow`・`questIndexOf` でさがせる。目標の一覧には、小さな目標ごとに、できた・まだを出す。
- 御神木の調べは、1つの依頼の中でつづけて調べる（`fieldParts`。いまの調べは `fieldActiveId`）。
- 目標のならびをかえたら、古いセーブは番号ではなく名前で読みかえる（まとめたときは `S.flags.qmerge1`・`migrateQuestMerge`、まとめる前のならび `QUESTS1_V1`）。聞いていない会話でもらえた物は、読みかえるときにわたす。
- はじめの目標を1つずつにもどしたときは `S.flags.qsplit1`・`migrateQuestSplit`（まとめていたころのならびは `questsV2`・`QS_SPLIT`）。まとめた目標のとちゅうのセーブは、まとめた会話を聞いていれば中の会話をとばし、できている目標をとばして、はじめのできていない目標へ（`questSplitResolve`。カミサマの旅立ちのお礼はとばさない）。
- 新しい話・進行変更を作るときは、先に `STORY.md` と前後の会話・条件・実際の仕様を照合する。各人物がその時点で知っていること、復活・消失・建物の呼び名をそろえる。
- 各クエストは「きっかけ → 依頼の会話 → 引き受ける → 現地の行動・演出 → 結果の会話 → 完了 → 次の話」の流れを定義する。調査が複数なら段階を分け、必要な話を読まずに次へ進ませない。
- 前にした収集・建設の数を増やすだけの話にしない。仲間の属性・性格・行動によって新しい発見や変化が起き、その結果が次の目的につながるようにする。伏線だけの会話を重ねない。
- 開始・行動・完了の条件は共通の判定を使い、吹き出し・タップ・自動進行・ロード後の再開のどこからでも同じ順番を守る。会話中や連続タップで同じ場面・報酬を重ねない。
- 物語の調査・世話は、その依頼で行った行動を専用の進行として記録する。以前の所持数・設置数だけで新しい調査を終わらせない。既存物で条件を満たせる依頼は、文面と判定を合わせる。
- 会話の開始や演出の開始だけで、既読・調査完了・報酬・次の段階を確定しない。その段階の必要な動作と会話が終わってから、一度だけ確定する。中断時は確定済みの段階を保ち、未完了の場面から再開する。
- 青い吹き出しはメインの依頼・会話の印であり、一律に停止・現地待機させる条件にしない。各場面で「作業を止める必要」「指定場所で待つ必要」「村の時間を止める必要」をそれぞれ判断し、必要な対象と期間だけを指定する。指定がなければ普段の行動を続ける。
- 現地待機が必要な場面だけ、対象の話者を指定場所へ歩かせ、到着後に待機させる。その待機中は空腹と楽しさを減らさない。食事・睡眠・荷運びなどを無理に切らず、済んでから向かわせる。
- 現地待機を指定した場面では、夜や敵の接近で待機を解除する。未読なら安全な昼に再集合し、話が終わったら元の場所へ歩いて戻り、普段の行動を再開する。
- 必須の話者・任意の話者を明示する。必須の子が不在なら開始せず、任意の子が不在ならその子の行だけを省く。空の会話や、いない子が話す会話を渡さない。
- 集合先は通れて重ならない場所を確保し、必要な全員が到着してから話す。時間切れで遠くのまま会話を始めない。道の閉塞・食事中・人物不在など、待つ理由を実際の状態に合わせて案内する。
- セリフにある「座る・触れる・渡す・振り向く・守る」は、ゲーム内の人物・物にも実際の動作を付ける。背中向きの腕は頭より奥に描き、向き・立つ位置・物との距離を確認する。
- 演出は「歩み寄り → 視線・構え → 動作 → 結果 → 反応と余韻」の順に組む。粒子・音・光は動作と変化の瞬間に合わせる。大事な動作が終わる前には次のセリフへ送れないようにし、固定の長い待ち時間だけで間を作らない。
- 演出の動作とカメラは実時間で進め、ゲーム速度や一時停止で速さを変えない。村の時間の停止は演出上必要な場面だけに指定し、その間は空腹なども進めず、完了・中断で必ず解除する。精霊の作業停止や現地待機を指定しても、それだけで村の時間は止めない。
- カメラは必要な人物・手元・対象を映し、会話欄・立ち絵・操作欄に隠さない。意味のある切り替わりでゆっくり移動し、画面回転でも構図を取り直す。終了・中断では演出前の視点へ戻せるようにする。
- メインの必須会話は、任意のピンク会話の待ち時間や見逃し扱いで進まなくならないようにする。別の話との割り込み・順番は、既存の会話待ちのしくみで整理する。
- 会話・お礼を待っているときの理由は、上の目標の欄と目標の一覧で同じ文（`mainTalkWaitText`）。夜は「お話は、朝になってから」、調べは「朝を待とう」。
- 目標の見出し・進みぐあい・やり方は現在の段階に合わせる。夜は朝を待つことを案内し、目標の一覧から、必要な会話・調査の場所へ行けるようにする。操作や数値の説明はセリフではなく目標の説明へ置く。
- 村の切り替え・ロード・人物の不在・対象の消失で、専用の集合・姿勢・カメラ・予約を解除する。遅延処理・アニメーション・会話完了処理は、元の村とセッション・場面が続いているときだけ反映する。
- クエストの追加・並び替えでは、旧セーブの現在の依頼・報告待ち・既読・調査段階を移行する。二度読み込んでもずれず、他の章とフリーモードへ影響しないことを確認する。
- 思い出帳には本編と同じ会話・動作を使い、その場面に必要な人物・物・敵・時間帯を再現する。再生用の一時データだけを変更し、本編の進行と保存には触れない。
- 検証では通常の通しプレイに加え、夜・人物不在・道の閉塞・連続タップ・会話途中の終了・村切り替え・旧セーブ再開を確認する。動作や間を飛ばさず完走するブラウザ検証と、スマホ相当の縦横画面の目視確認を行い、実機で未確認のことは明記する。

## クエストと精霊
- なかまを迎えたあとの追加メインクエストは、前にした建設・収集・設置の数を増やすだけの依頼にしない。なかまの力で物語が進む内容にし、土・火・水・風の子のあとにそれぞれ2つ置く。
- クエストの文面と、クリア条件は一致させる。文面にない行動でクリアしたり、文面の行動をしたのにクリアしない、を作らない。
- どれでもいい物は、物の名前をならべずに種類で書く（「あかりを3つ」「かざりを3つ」「好きな遊び道具」）。条件も、その種類ぜんぶで数える（`LIGHTQ`・`DECOQ`・`TOYS4`・`INDL`）。「〇〇も数に入る」「△△するのは木のせいれい」「□□までしか入らない」のような、ことわり書き・よけいな説明は、クエストの説明（`how`）にも書かない。
- 会話で操作を説明しない（せいれいにもカミサマにも言わせない。「あんない」の行も、会話のあとのポップアップも出さない）。操作は、クエストの説明（`how`）に書く。
- キーキャラが消えたときの会話（`deathTalk`）は、`gvOnce` で「聞こえるかの？」をカミサマのはじめの行だけにする。
- せいれいが消えたとき、なかよし（`bestMate`）が村にいれば、その子が話す（`deathTalkMate`：おどろき → 思い出 → かなしみ、のあとに、もどってこられるか・自然にかえるかの説明だけ）。思い出は、プレイヤーがさいごまで見た2人の会話（なかよしの雑談の `mem`・なかよし30の会話 `BOND_MEM`・`BOND_MEMG`）、なければ2人でさいごにしたこと（`S.bondDid`）。棺をはこぶのは、なかよし → いなければ章のはじめからいる子（`buryWho`）。行けないまま `BURYWAIT` たったら、ほかの子。
- 消えたあとのしくみは `bond.js` の「消えたあと」：さいごのひとこと（`lastWord`。会話のはじめの行）・思い出帳の「いなくなったなかま」（`S.gone`）・しょんぼり（`r.grief`）・お墓まいり（`goMourn`・`mourn`：消えた場所 `e.j` のそばに、消えた子の属性の花 `MOURNFL` を植える。水はハス、水がなければゆり）・雑談（`CHATS` の `gone`、`@G`）・にている子（`simNote`）・よみがえったときの再会（`reunionLines`：さいごのひとこと・見た会話にこたえる、なかよしの雑談の `back`。会話のあと `reunionJoy`）・よみがえったあとの日常（お墓まいりの花を2人で見にいき、お礼の花を植える `revisitTick`・`rvisit`・`revisitTalk`。`RE_DAYS` 日、いっしょに遊ぶ・ごはん・となりのベッド `reWith`）。けんかと仲なおり（`S.qr`・`qrTick`：なかよしの2人が朝にたまにけんか、つぎの日の昼に好きな物を持ってあやまる `qmake`・`qwait`。仲なおりは思い出 `S.qMem`）。セリフで、ほかの子の言った言葉（「ごめんね」など）を「」で引用しない（`chatTone` で話す子の言いかたにかわる）。おなかがもうすぐからっぽの子は、ふらふら歩く。`CHATS` は番号がセーブに入るので、うしろに足すだけ。
- 御神木・切り株の雑談（`CHATS`）は、木の育ちぐあい（`sacredStage`）の条件（`ok`）をつける。
- カミサマは、気持ちのある人物として話す（よろこぶ・心配する・ほめる）。物の数・時刻・「置いてみい」「パワー1」などの操作は言わせない。遠くから話すときの「聞こえるかの？」（`GVOICE`）は、会話の中でカミサマがはじめて話す行にだけつける（とちゅうでわりこませない）。
- 見せ場のクエスト（家具を置く等）でおいた物には、依頼した精霊がちゃんと見にくる・遊びにくる。
- 精霊ごとの好みの遊び場（土は砂場、木はブランコ、水は噴水など）は、ほかより選ばれやすくする。
- 夜の見張り・戦いの終わりかたなど、精霊の動きの決まりは、勝手に変えず、聞いてから変える。
- 火の子がねらうのは、なかまをまもるときだけ（`foeGuard`：火の子でないせいれいの3マス以内・だれかのいる家・柵や建物をこわしているコワイノ・火の子をたたいているコワイノ `foeHitsFire`。オオカゲなどは火の子のとどかない所からたたくので、たたかれたら近よる）。自分のまわりのコワイノは、攻撃がとどくときだけ。にげるコワイノはおいかけない（村の外へひっぱられない）。
- 火の子は、むれ（ねらうコワイノのまわり2マスに3びき以上、`foeMobbed`）にはとびこまない。もう攻撃がとどく子・なかまをたたいている子（`foeHitting`）・火の子をたたいている子（`foeHitsFire`）・柵や壁や建物をこわしている子（`foeBreaking`）・箱や畑からぬすんでいる子（`foeStealing`）は、むれでもねらい、先にねらう（`pickFoe`・`foesNow`）。
- 火の子の夜の見回りは、家のまわり3マスだけ（家の中はのぞく。灯り・柵の中は見ない）。家がなければ、ほかの子のまわり → 自分だけなら神殿のまわり（`patrolMask`）。

## 見た目
- 会話の身ぶり（`dlgGesture`、`dialog.js`）：話す子は、セリフの印（`#tilt` 首をかしげる・`#giggle` くすくす・`#heart` 胸に手・`#shy` もじもじ・`#proud` えっへん・`#point` 指さす・`#show` 見せる・`#give` わたす・`#crown` 花かんむり、ほかは `DLGANIM`）の3Dの身ぶりをして、あいてのほうを向く。聞く子は、話の動きに合わせて少しずつずれて反応する（`LISTENR`）。仕事・遊び・場面の姿勢の子にはつけない（`dlgFree`）。会話がとじたら消す（`dlgGestEnd`）。物をわたすセリフには `#give`（つぎの行の子がうけとる `stageHandOver`、うけとるまでつぎへ送らない）。見せる・わたす物は `#crown`・`#stone`・`#hstone`・`#water`（手に持つ絵 `drawHandItem`・姿勢の `handItem`）。2人でする動き（`DLGPAIR`：`#pinky`・`#squeeze`・`#yubikiri`・`#lean`・`#soil`・`#dance`・`#lie`）は、会話のおわりまでつづく（`pair`）。手・かたがふれる動きだけ、ひと足よる（`DLGTOUCH`・`dlgStep`・姿勢の `step`）。`#yawn` は聞く子にうつる。`#point tree` は近くの木を指さす。ヌシ様をなでるのは、ヌシ様の行の `#pet`（`nushiPet`）。せいれいは手が短く、上げた手は頭巾にかくれるので、身ぶりは顔の横・胸の前で見せる。
- 花かんむり（`drawCrown`：ゲームのドットの、つながった葉の輪と十字の花）：頭にのせる（`r.crown`＝もらった `callDay`、つぎの朝6時まで。思い出の場面の子は `crownT`）・手に持つ（姿勢の `crownHand`、あむとちゅうは `crownN`）。あむ（`weave`、合図 `weave:<人>`）。夢の場面（`dreamCue`）・なかよしの雑談・e21・花まつり（おどる `dance`）で使う。
- 会話の文字のうごき（`LOOKS` の `fx`）：`#joy` はなみうつ（wave）、`#scared`・`#danger`・`#alarm` はふるえる（shake）。うごくのは `big` をかさねた行（`#joy big|`）だけ。大事な場面（オオカゲが来る・むかう・最後の防衛・はじめて追いはらう・火山の山場・再会など）にだけつけ、多くしない（持ち主がきめた）。1字ずつの箱にする（`dlgSet`）。

## 道・床の絵
- なかまのお迎えで集まっているあいだは、紹介待ちの `NEWQ` を残し、紹介画面を開く時刻だけを待たせる。先に待ちを消すと、紹介の前に次のクエストが進む。
- なかまのお迎えは、だれも集まらない。新しい子のまわり8マス（`WELCOMER`）にいる起きている子だけが、その場でそちらを向いて、はねて拍手する（`welcomeNear`）。それを見せてから紹介の画面。
- 調べをタップしたとき、予定のある子（食事中など）がいても、とりやめない。予定がおわった子から、じゅんに木のそばへ来て待ち（`fieldgather`・`tryFieldGather`。ほかの予定には移らない）、みんながそろったらはじまる。
- 御神木の調べ（`sacred-play.js`）：切り株を1回タップすると、その話の調べは最後まで自動で続く（`tryFieldAuto`、会話のあと3秒あける）。依頼ごとに1つ、調べの前に切り株のそばへ作る物がある（`FIELD_PREP`：土は設計図「根もとのものおき」・火は設計図「たき火のひろば」・水は井戸・風は風車・さいごはベンチ）。なかまの準備は、小さな物を置くだけにしない（建物・設計図など、手のかかる物を1つずつ。持ち主がきめた）。設計図の準備（`bp`）は、依頼を聞くとわたし（`fieldBpGive`）、切り株のそばにしか置けず（`fieldBpNear`）、できあがったとき数える（`fieldBpDone`）。お話の設計図（`BPS` の `story`）は、ふつうにはもらえない。切り株のそば（`FIELD_NEAR_R`）にある物を、その調べの物として記録して数える（置いたとき `fieldBuildNote`。依頼の前からある物も `fieldBuildAdopt` で数に入れる）。できたら、その調べの最初の子が作った物のそばへ見にいく（`fieldBuiltCell`）。調べの段階のあいだ・つづく調べのあいだは、解散せずに木のそばで待つ（`fieldwait`・`fieldWaitKeep`）。作る物を待つとき・夜・コワイノ・空腹・調べの終わり・ゲームの1時間で解散する。話ごとに1回、守り神の出番（指でする操作、`FIELD_PLAY`）があり、そのあいだは村の時間を止める。操作の説明は出番のヒントに出し、セリフでは言わない。地図の場所を見なくてよい出番は、わくつきのポップアップの中で（`FIELD_PLAY` の `pop` が見出し。切り株の絵は村と同じ）。意味のわからない操作（ただ当てるだけ等）の出番は作らない。1つの仲間の調べは1つの依頼の中でつづけ、依頼を分けない。
- 御神木のなかまの依頼は2場面：依頼の会話のあと、切り株のそばに物を作る（`FIELD_PREP`）→ 1回だけ集まって、話す（`pre`）→ 守り神の出番 → 動き → 木が育つ・ひかる（`stree:bud`・`leaf`・`glow`）と、みじかい反応（`lines`）。1つの依頼に調べは1つ（古いセーブは `S.flags.fieldMerge1`・`migrateFieldMerge` で名前で読みかえ）。
- 調べのために置いた物を、ひっこしミトンでうつしたら、記録のマスもうつす（`fieldBuildMove`）。
- 御神木の調べの準備（`FIELD_PREP`）は、話のはじめの調べにだけ置き、依頼の会話の中で、その物がなぜいるかをことばで言う。調べと調べのあいだに準備をはさまない（はさむと解散する）。

- メイン会話のうち、昼の現地待機が必要な場面は `story-wait.js` で扱う。到着後の待機中は空腹を減らさない。夜・敵の接近で解除し、未読なら朝に再集合、会話後は元の場所へ歩いて戻って普段の行動に復帰する。

- 現地待機を指定したメイン会話の到着後の待機中は、空腹・楽しさ・つかれを減らさない。移動・夜・待機の解除後は普段どおり。上の目標の欄をタップすると、いつも目標の一覧を開く。会話・調査の場所がある目標は、一覧の中の「お話・調査の場所へ」でカメラを移す。
