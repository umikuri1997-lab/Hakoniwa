# 村・家・家具・マップ・レシピ

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。

## 村・家・家具
- 神殿は「おく」で建てない。どのステージ（これからのステージも。フリーモードはのぞく）でも、はじめから、こわれた神殿（`statueb`）がある（`templeRuinPlace`：まん中の道の北のはしの先。水などで置けなければ、そのよこ）。「しらべる」でタップすると、せいれいが直して神殿になる（`templeRuinTap`）。古いセーブは `S.flags.ruinTemple1`。神殿・こわれた神殿・おそなえ箱の絵は3Dから写した絵（`tools/art/furn3d/items/temple.py` が共通の設計図。`statue.py`・`statueb.py`・`obox.py`）。
- 依頼ボード（`board`）は神殿から2つ右・3つ右の2×1マス（`sz:[2,1]`。右のマスは `part`）。神殿のすぐ右のマスは神殿の絵の下なので、神殿の `part`（神殿のあと `templeRuinCells` の6マス）。マスは絵のある所にそろえる（ずれると、絵の上を歩く）。前のセーブは `S.flags.board3`（`boardShift`）。絵は3Dから写した絵（`tools/art/furn3d/items/board.py`、144×117・g64、ax −11・ay −55）。タップは絵のわく（`input.js` の `BOARD`）。前のセーブは `S.flags.board2x1`（`boardMigrate`：右どなりの物はもちものへ）。はられた依頼の数（はじめ3まい・広げたあと5まい、`boardMax`）だけ、紙の絵を板にかさねる（`boardNotes`・`BNOTE`：コードで描く、1マス64ドットの整数のドット。紙は14×18、赤いピンつき）。
- 朽ちた壁：家の壁（`DECAYW`。石の塀・ドアはのぞく）は、じょうぶさが半分以下（`decayed`）だと朽ちた壁。家の壁にならない（`findHouses`）。絵はふつうの壁にひびをかさねる（`drawCrack`、チップ `crack#0〜5`・たて `crack:v#0〜5`。となりと同じ柄にしない、なければコードの仮の絵）。直すともどる。コワイノにたたかれて朽ちたら `decayCheck`。
- クモの巣（`S.web`：マス→0左の角・1右の角）：家の中の1つで住み心地−5（`WEBCOMF`）。プレイヤーはこわせない。「しらべる」でタップ（`webTap`→`S.webq`）すると、せいれいがはらう（`sweep`）。毎朝、家ごとに10%で1つ（3つまで、`webMorning`）。チップ `web#0・1`。
- お屋敷は右上のエリア（`MANSION_AREA`）。場所をきめるとき、まわりの段差を低くそろえる（`fogFlatten`）。晴れると、朽ちた壁・なくなった壁・こわれた家具・クモの巣のボロボロのお屋敷。
- 村レベルの上限は、ストーリークリア前が10、クリア後が15。
- 家は「家の壁」と「ドア」だけで囲んだものだけ。石の塀・柵・ほかの種類の塀がまざっても家にならない。
- カーテンは、家の上がわの壁の「窓」にだけかけられる。窓はそのまま残り、窓の上にカーテンがかかる。窓のない壁・ほかの向きの窓には、警告を出してかけない。
- ベッドの絵は、もらった絵をトリミングして使う。横のベッド（`bed>1`・`yorubed>1`）は、よこを1マス（64ドット）にちぢめてある（`bed>1` は、その1.2倍の77×58、下のはしはマスの下のまま）（たて横の比はかえてよいと言われた）。たてのベッド（`bed`・`yorubed`）は、もらった絵の1.2倍（60×77）で、下のはしはマスの下のまま上へはみ出す。寝る子の位置（`BEDHX`・`BEDHY`・`BEDVY`）は、ベッドの絵に合わせる。
- 村の鐘（`bell`、2×2、Lv12）：朝に、教会の鐘の音（`SAMPLES.bell`、`bellRing`：間をあけて3回、少しずつ小さく）を鳴らしてゆれる（`BELLRING`、`bell#1`）、村のせいれいのたのしさ+15（いくつあっても1回）。行燈（`andon`、火山Lv7、あかり）：暗くなると、あかりのついた絵 `andon#on`。
- 花壇のふち（`bedge`、草原Lv8）：床の上の別の層（`S.edge`：マス→id、1×1、`canEdge`）。花・雑草が生えているマスにも置けて、花より手前に描く。花壇のふちどうしだけつながる（`CONN` の `s`）。つなげると外わくだけ（`drawBedge`：となりにふちがない向きにだけ丸太を1本。うしろ・横は花より奥、手前の丸太は花より手前）。物をこわしたあと、もう1回タップでふちをはずす。古いセーブの `S.obj` のふちは、読みこむとき `S.edge` へ。露天ぶろ（`onsen`、火山Lv9、2×2）：まわりから何人でも入れ、火の子も入る。入りおわると、つかれ−30・たのしさ+10。村の看板（Lv11。草原は木 `signw`、火山は石 `signs`）：属性の力+10%（いくつあっても1回、`recount`）。
- すてき度（`suteki`）：かざり1つ2点・花1本1点・道10マスで1点・スポット1しゅるい3点。★（`SUTEKI_STAR` 10・25・45・70・100）の数で、せいれいのたのしさのへりかた（`SUTEKI_FUN`：★0で1倍〜★5で0.8倍）。村のようすに出す。
- 屋根の色は、村レベル13から、家をタップした画面でえらぶ（もとの色・赤・青・緑・こげ茶。`S.roofCol`、ひし形の屋根の色 `iqRoofTone`）。
- ブランコは横・縦の2つの向き（`ROTS` の 2、縦は `swing>1`）。縦は横から見るので、座面は支点のまわりに左右へゆれ（`PARTMV` の rot・`SWROT`）、乗る子は横を向く（`toyPose0`・`SWPV`・`SWLEN`）。横木・手前の柱は、座面・ロープと乗る子の上に重ねる（parts の `fix`・`drawChipFix`）。前のセーブの反転は `S.flags.swingRot2` で横にもどす。
- 3Dから写す動く部品（`MOVE`）は、本体のうち動く部品より手前の所を、奥行きでえらんで `fix` の絵にする。動く部品をいつも本体の上に描くと、うしろにあるはずの所が前に見える（縦のブランコでおきた）。
- 作業する向きがきまっている家具（`WORKF`：はたおり機・粉ひき小屋・調理台・流し台・かまど・作業台・炉）は4つの向き（`ROTS` 4、絵は3Dから写した `id>1`・`id>2`、左は右の反転）。作業するマスは、その向きの前（`workCells`：2×2は前の2マス、作業台は台のマス `wbCells` の b の前）。せいれいはそのマスに立って家具のほうを向き（`workStand`・`ovenStand`・`wbenchStand`）、どのマスも歩けないと作業しない（`workOK`）。置くときは、作業するマスを水色（ふさがっていたら赤）で出す。前のセーブで前がふさがった物は数えるだけ（`workBlockedList`・`WORKBLOCKED`、うごかさない）。かまどの前の反転（`ROTS` 1）は `S.flags.ovenRot4` で前向きに。かまどの上の道具・材料（`CKTOP`）は前向きだけ。作業台の絵（`wbench`・`>1`・`>2`）は、3Dで写した位置より10ドット上（`WBUP`）：写しなおしたら ay を−10 する。作る子も同じだけ上に立つ（台のマスは右・下向きでは `part` なので `anc` で見る）。台のうしろに立つ向き（2）だけは、台のほうへよせる（`WBBACK`）。たしかめは `tools/tests/work-front.cjs`。
- キャビネット・本棚・かざり棚・まき棚は、前・右・左の3つの向き（`ROTS` の 3。右は `id>1` の絵、左はその反転。うしろ向きはない）。
- つかうせいれい（`S.useOwn`・`useOwner`・`useFor`、家具の画面の `useOwnSec`）：いす・ベンチ・遊び家具・おふろ・料理の家具（`OWNABLE`）は、ベッド・見張り台と同じく、きめたせいれいだけが使う（いない子のは、だれでも）。家具をえらぶ所（`goMeal`・`benchSpot`・`goPlay`・`bondInvite`・`goBathe`・料理）で `useFor` を見る。
- すわったせいれいの位置のずれは `SEATOFF`（`village.js`：家具→向き→[よこ,たて]、ゲームの点）。持ち主が「すわる位置」のページ（https://claude.ai/artifact/VHUjJv2LKEW6axM4HAUWmk）できめた数（1マス64のドット）を÷2して入れる。ページの絵は `tools/seat/seatview.cjs`（ゲームの描き方で作る）→ `tools/seat/build_page.py`。すわる家具の絵をかえたら、作りなおして公開しなおす。
- いす・ソファにすわったせいれいは、かげを出さない（`drawRes0` の `seated`）。ひじかけいす・ソファのひじかけは、せいれいより下（手前にかさねる `.front` に入れない）。「すわる位置」のページのはじめの数は、いまの `SEATOFF`（`seatview.cjs` は、ずれなしで写して、×2 を `init` に）。
- ベッドは住み心地を上げない。置きすぎの「きゅうくつ」の減点だけが残る。
- 家の画面の住み心地（見出し・星・数）をタップすると、計算のくわしい中身（`comfyPop`：何で何点か。`houseComfort` がかえす `why`）。住み心地の計算をかえたら、`why` と `comfyPop` も直す。
- お供えで手に入る家具は、レシピ・クエスト報酬・セーブデータのレシピに残さない。
- 石碑（`stele`）は、名前・絵・セリフをノームの石像にした（id はセーブのためそのまま。効果はかえない）。絵のお手本とプロンプトは `tools/art/gnome/`。
- 家具・建物の「パワー」「素材」は別々の実数。片方を変えても、もう片方は変えない（変えるように言われたときだけ変える）。
- ひでんのしょの項目は、出会うまで、ドットの「？」のマーク（`qmarkify`・`PXI.qmark`。字の「？？？」や絵文字にしない）（`MANMET`・`manMet`。いちど出会ったら `S.flags.man` におぼえる。フリーモードはぜんぶ出す）。出会うのがあとになる項目を足したら、`MANMET` にも足す。

## マップ
- マップは108×108マス。まん中の72×72（`OFF`=18マス内がわ）が前からの土地。
- 敷地はない。マップのどこにでも置ける・こわせる。
- 緑のマス（`REV`）が広がるのは、木や草花を生やしたとき（`kind:'plant'`・御神木・自然の木や実）だけ。広がるのは、植えた木はまわり2マス、花はまわり1マス（持ち主がきめた）。家具・建物・道・畑・神殿では広がらない（`revRadius`）。せいれいが、みんなの合計で時計の3時間（`STAYG` 180分）いたマス（歩いて通るのも入る。かくれている子・水はのぞく）も、そのマスとまわり1マスが緑になる（`stayTick`・`S.stay`→`S.grn`）。草原のさいごの条件に、みどりのマスは入れない。
- 村（`VILL`）は、家・置いた物（自然の物・雑草はのぞく）・ラグ・屋根のまわり3マス（`recount` で作る）。夜ににげる所は、村の中だけ。池・川では水の力はふえない。属性の力・みどりのマスは、マップぜんぶでかぞえる。
- せいれいがこわがるのは、コワイノが自分の3マス以内か、自分のいる家に来たとき（`hostileNow(r)`）。火の子は、だれかの3マス以内・だれかのいる家に来たコワイノと、塀・壁・建物をこうげきしているコワイノとたたかう（`nearRes`・`e.hitT`）。火の子は、うしろ（北）のコワイノとたたかうときは、うしろを向く（`r.fback`）。柵・塀・ドア・建物をこわしているコワイノがいれば、火の子はそちらを先にねらう（`foesNow`）。
- 説明に書く「分」は、時計の分（コードの時間の数字÷1.5、`DAYLEN`）。遊び家具の `dur`・罠の `stun`・見張り台の `cd` は、時計の1.5倍の数字。
- ヨルノオオカゲの攻撃の間かくは12分（1回が重いぶん、間かくを広くした）。
- 歩けないマス（`walk`：水・霧・切り株の根もと `STUMPB`・カミサマの立つマス `GODJ`。`GODJ` は `stepWorld` で毎回きめ、カミサマがいないときは −1）をふやしたら、コワイノの道さがし（`bfs0`・`bfsE`）でも通れないようにする。道さがしで通れるのに `walk` で歩けないと、その道を歩けずに止まる。
- コワイノは、マップの南のはし（いちばん下の行）の、村まで歩いて行ける所から来る（`spawnSpot`・`spawnReach`。川や木でかこまれて村へ行けない所には出さない）。ふしぎな種は、まん中の72×72の中の、村でない所。オオカゲの登場では、画面がマップのはしをこえてもよせて、オオカゲの全身を、名前と説明の下に見せる（`bossEntrance`・`BOSSCAM`）。
- 地形（`genLand`）：川（`genRiver`）のあとに段差（`genHeights`）。どちらも人の作った物（`landMade`）の所はかえない。古いセーブは1回だけ作りなおす（`S.flags.land2`）。
  - ステージごとに、ちがう場所とわかる地形にする（同じような配置にしない）。
  - 川：草原は北のはしから南のはしへ、火山は西のはしから東のはしへ（南がわを横切る）。まん中から26〜30マスはなれて流れる。支流が1本。浅瀬（`ground` 2）は、本流3か所・支流1か所。浅瀬は歩ける（2倍ゆっくり）が、物は置けない。絵は、水の底の砂がすける色・小さな石・さざなみ（`drawFords`、仮の絵）。
  - 橋（`bridge`、建物）：水の上にだけかけられる。タップした水から向こう岸まで、まっすぐかける（よこ・たての短いほう、10マスまで。`bridgeSpan`）。パワー・素材はマスの数ぶん。上は歩ける（`walk`・`wetJ`）。絵はもらった絵（`tools/art/tlb`）：よこ `bridge:h*`・たて `bridge:v*` の、はし（S・E）・まん中（M、1マスでくりかえす）・1マスの橋（1）。
  - 段差：なめらかなノイズから0〜3だん。草原は大きくゆるやかな丘（3だんは少ない）、火山はこまかくけわしく、北（火口がわ）ほど高い。古いセーブは `S.flags.land4` で、火山の南北の川を地面にもどして東西の川にし、段差を作りなおした。まん中も外と同じ（はじめからある物のマスとまわり1マス・こわれた神殿と御神木の置き場・はじめのせいれいの立つ所だけ平ら。持ち主がきめた。前のセーブの地形はかえない）。水・浅瀬のとなりは低いまま。2マス以内との差は1だんまで（段と段のあいだの平らな所は2マス以上。がけが2だんつづけて見えないように）。古いセーブの段の高さは、`S.flags.land3` で1回作りなおした。
- 草原の本編は霧の中の土地（`fog.js`）：16エリアのうち、はじめはまん中の4つだけ晴れ（`S.fog`：エリアの印）。霧は1マスずつ晴れる：晴れた所のみどりのマス（水はのぞく）のまわり3マス（`FOG_R`）の霧が晴れ（`fogAfterRecount`、晴れたマスは `S.fogc`：6マスで1字）、エリアの9わり（`FOG_AREA_DONE`）が晴れたら、のこりも晴れて「晴れたエリア」になる（`fogAreaDone`：もりのこだま）。見つける物は、そのマスがぜんぶ晴れるまで霧の中で、ぜんぶ晴れたら出る（`fogItemOut`・`f.out`。古い家のあと・お屋敷はそこで建つ）。霧の中は置けない・歩けない（`walk`・`wetJ`・`canPlace`）、コワイノは晴れた所の南のはし（`fogSouth`）から。霧のエリアに見つける物1つ（`S.fogF`：古い家のあと3・宝箱4・ヌシ様のあしあと3・泉2）。霧は小さな絵（`FOGC`）を1回作ってうつすだけ。古いセーブは `S.flags.fog1` で1回、村・置いた物のあるエリアは晴れ。火山・フリー・思い出帳は霧なし（`newGame` でだけ `fogInit`）。
- 霧の中の手がかり（`drawFogHints`）：晴れた所から6マス（`FOG_HINTR`、`fogHintNear`）の、まだ霧の中の見つける物の所に、しゅるいごとのしるし（お屋敷は屋根の先と煙突・泉はきらめき・あしあとは青い光のつぶ・宝箱は影・古い家のあとは、くずれた屋根の影）を霧の上に出す。あしあとをたどる依頼のあいだは、その印だけ。
- もりのこだま（`kodama.js`。見つけたら、ポップアップ `SPOT_POPS` の `kd`、アイコン `PXI.kodama`）：16エリアに3こずつ（草原は晴れたエリア、ほかはそのまま。思い出帳はなし）。ゆれる草むら・ふしぎな切り株（タップでせいれいが見にいく）・欠けた石の輪（タップで石材1こをはこぶ `kdsget`・`kdput`、`kdRsv` でとっておく）・1本たりない花の輪（すきまに同じ花が咲くと見にいく `kdHanaCheck`）。見つけたらパワー+5と小さな物（`KDLOOT`、頭の上につんで箱へ）、10・20・30・40こで設計図（もらえないときは `S.kdOwe`、朝にわたす）。輪の石・花は見た目だけの物（`kdishi`・`kdhana`。本物の花にすると、みどりのマスがふえて霧が早く晴れる）。こわせない。マップのまん中から12マス（`KDMID`）には置かない（はじめに建てる所）。置くのは、晴れて `recount` がおわってから（霧が晴れたすぐは、道さがしが前のまま）。置けなかった分は朝にまた。たしかめは `tools/tests/kodama.cjs`。
- 72×72の古いセーブは、読みこむときに `expandMap` で広げる。マスの番号（`y*W+x`）や x,y を持つセーブの項目をふやしたら、`expandMap` の読みかえにも足す。

## コワイノのレシピ
- コワイノのレシピにする物は、`BL` に `kwr:1` をつけて、`KWR` に足す。どのステージでもおぼえたまま（`kwrSync`）。
- よぞらのドア（`yozoradoor`）：コワイノのレシピ。ふつうのドアと同じはたらき（`HOME_DOORS`）。ドアかどうかを見る所は `HOME_DOORS.has` を使い、`'door'` だけをくらべない。正面は、ふつうのドアと同じ枠（壁ごとの色）の中に、もらった絵の板を28×28でおさめた絵（`<壁>.yozoradoor#h0〜3`）。もらった板の絵（40×47。持ち主が調整ずみ）を、そのまま枠の内がわ28×28にのばして入れる（ほかの手はくわえない）。開いたコマは、しまったドアをちょうつがい側へよこにせまく（ノブはせまくしない）。たて置きと上の断面は、ふつうのドアの部品の色をおきかえた絵。

## レシピとステージ
- おぼえたレシピ（村レベル・クエスト・ひらめき）は、前のステージでおぼえた物だけ、あとのステージでも使える（`recSync`、ステージべつのセーブとはべつにしまう）。いまのステージ・この先のステージでおぼえた物は、使えない。おなじレシピを2回おぼえさせない（ほかのステージでおぼえた物は、レベルアップの知らせに出さない）。
- おぼえたレシピは、どのステージでおぼえたかもしまう（`GREC`：id→ステージ、`hakoniwa-rec-v2`）。ステージを「はじめから」にしても、おぼえたレシピはわすれない。
- 守り神の光（まもりの光）は範囲わざ（`glCast`→`glHit`）。地図のどこをタップしても、そこに落ちる（コワイノをタップしたら、そのコワイノに）。範囲（GUP の `rng`：タップしたマス → まわり1〜4マス、ななめも）のコワイノにダメージ・とめる、木や岩には素材（`natHit`）。ダメージ・とめる・ゲージ・素材は、光が地面にとどいてから（`GLFX`。当たる前に結果を出さない）。近くのせいれいは、おどろいた顔でぴょん（`SHOCKU`・`JUMP`）。まわりの生き物も、おどろいてにげる（飼う生き物はぴょんとはねて、かこいの中で光からはなれる `aniScare`・小さな生き物は画面の外へ `critScare`）。昼も夜も。守り神の光をえらんでいるあいだは、しらべる・おく・こわすはしない（下のバーはどれも光らせない）。しらべる・おく・こわすをおすと、えらぶのをやめる（`setMode`・`dockSync`）。フタバの「やってみて」は、はじめての夜のあとのサブクエスト（`lighttry`、木か岩から素材を1こ落とすとクリア）。
- ヨルノオオカゲが来た夜、フタバのこもれびのまもりが強くなる場面（`guardPowerUp`、e15）：「みんなを守るから！」のあと会話をとじ、時間を止めて（`SCENEHOLD`）、祈る → 葉の輪がひろがる → まわりのみんなに葉のまもり、を見せてから、のこりの会話。会話の行は `[話す人,セリフ,合図]` か `[話す人,セリフ,0,合図]` の両方があるので、合図はどちらの位置も見る。
- こもれびのまもりを受けつぐのは、草原をクリアしてつぎの土地へ出発するお見送り（`depart`）の中（守り神がつぎの土地へ行くとわかってから）。場面（`guardInherit`）：フタバの「ぼくの力、もっていって」のあと会話をとじ、村の時間を止めて（`SCENEHOLD`）、祈る → 葉 → 光が守り神へながれる → みんなに葉のまもり、を実時間で見せてから、のこりの会話。
- 守り神の枝（メニューの「むらのちから」の木の右、`GUP`・`GUPC`・`S.gup`）：まもりの光のチャージ・威力・とめる時間・範囲（攻撃のわざ）は5段まで（範囲は4段：1マス・まわり1〜4マス）、こもれびのまもり・葉のかべは10段まで、パワーで強くする（段階ごとのパワーは GUP の `c`、攻撃のわざは `GUPC5`）。前の10段のセーブは `S.flags.gup5` で5段にして、こえた分のパワーをもどす。ステージごとで、ほかのステージには引きつがない。まもりの光のチャージは村レベルではかわらない（古いセーブは `S.flags.gup1`・`gupMigrate` で、前のチャージより長くならない段階に）。
- 守り神の「こもれびのまもり」（`S.flags.areaSkill`）は、草原でおぼえたら、ほかのステージでも使える（`syncTools`）。
- 会話・サブクエスト・ひらめきでおぼえる物（家具でない物も）は、`RLOCK` に入れる。入れないと、はじめから作れてしまう。
- そのステージで手に入らない素材（草原：竹・くるくる草・ちりちり草）を使う物は、そのステージでは村レベルでおぼえない（`NOMAT`・`matHere`）。
- そのステージからおぼえる物は `BL` に `w`（草原0・火山1）を書く。そのステージだけで作れる物（丸太の塀・そのドア・大門は草原、竹の物は火山）は `STAGEONLY`。どちらも、ほかのステージでおぼえていれば作れる。
- 草原の2つめの塀は丸太の塀（村レベル6。丸太の塀のドアは村レベル6、丸太の大門は村レベル9）。カミサマの像は村レベル5でおぼえる（`LEVELUP_ITEMS`。家具も、村レベルでおぼえる物はここに入れる）。石の塀・石の塀のドア・石の大門・石畳・レンガ道・レンガ床・レンガの壁・石とレンガの階段は火山から（火山はレンガが先、石の塀・ドアはLv8、石の大門はLv10。石はレンガよりじょうぶ）。草原では、かわりに木の道と木の階段。

## ドア
- ドアは、通る子がいるときだけ開く（ドアのマスにいる子か、歩いていて、つぎの2マスのうちにドアを通る子）。近くで休む・遊ぶ・横を通るだけでは開かない。開け閉めは `stepLooks`、描くときは `doorOp` で読むだけ。
- ドアが開いたコマ（`door#h1〜h3` など）の、開いた所（ドアのおく）は透過にする。黒や暗い色でぬらない（床・地面が見える）。ドアの絵を作りなおすときも、前のコマのおくの色をそのまま使わない。
- たて置きのドア：上と下の壁は、柱を立てず、断面のままドアの横の見切りまでつづける（`drawConn` の `doorVert`。断面と見切りのあいだに線を出さない）。ドアのマスは、細い断面の線（`<壁>.door#v0〜3`）。この形は持ち主がえらんだ形なので、かえるときは聞く。
- ふつうのドアは、しまっているときも開いているときも、上・左・右・下（しきい）の4方向に枠がある。枠のはばは2ドット（しきいも2ドット）。ドアの板は、枠の内がわ（28×28）に入れる。枠の色は、となりの壁の柱の色（`<壁>.door#h0〜3`、壁のえらび方は上の断面と同じ）。
- ドア・よぞらのドア・窓の木の所は、つけた壁の柱の木の色にした、壁ごとの絵（`<壁>.door#h0〜3`・`<壁>.yozoradoor#h0〜3`・`<壁>.window`）。しっくい・レンガは木の壁の柱の色、よぞらの壁はダークチェリー。ガラス・金具・取っ手の色はかえない。
- ふつうのドアの板は、もらった木のドアの絵（板だけ・40×43）を28×28（g64で56×56）に入れた絵。開いたコマは、ちょうつがい側へよこにちぢめ（56・42・28・14ドット）、ノブはちぢめない・色もかえない。ログハウスのドア枠は、柱の色ではなく、ドアの板（丸太色）の色合いにそろえる。
- ふつうのドアの絵（枠・板）を作りなおしたら、よぞらのドア（枠はふつうのドアの絵から作る）も作りなおし、どちらも画面で、しまった所・開いた所を大きくして見る。開いたドアのおくには、床だけが見える（しきいの上 y+30 まで床をのばす）。
- 柵・塀のドア（柵のドア・丸太の塀のドア・大門・石の塀のドア）の向き（よこ・たて）は、となりの柵・塀だけで決める。ドアどうしはつながらない（`drawDoorChip` の `isF`）。家のドアも同じで、向きは、となりの家の壁だけで決める（`drawDoorChip`・`doorVert` の `isW`）。
- 腰壁の板の色は、その壁の柱の色に合わせる。フローリング（`floor`）の色も、木の壁の柱の色に合わせる。

## カミサマの道具

## 段差（高さ）
- 高さは−2〜8だん（`S.hi`、`hiAt(j)`、`HMIN`・`HMAX`。はじめの地形は0〜3だん）。立てる物の足もとをずらす高さは `liftOf(j)`（地面より下は0。`hiAt(j)*LIFT` と書かない）、画面の高さは `isoLv(j)*IQL`。地面より下の穴は `drawPits`（マスの中に、おくの石のかべと暗い底）。穴が水（池・川）にとなりあうと、つながった穴ぜんぶが池になる（`pitFlood`）。地面より下をほると石材。階段・ハシゴは穴に置けない。マップには、はじめから段差がある（`genHeights`）。マスごとのセーブの項目なので、`expandMap` にも足してある。
- 木（`TREES`）のまわり2マス（5×5、`TREER`）・岩と大岩（`HIROCK`）のまわり1マス（3×3、`ROCKR`。半径は `hiRad`）は、その物のマスより高くしない（木の絵が段差にかくれて切れる）。ベリーの茂み・竹・たけのこ（`FLATR`）のまわり1マス（3×3）は、その物と同じ高さ（高くも低くもしない `flatNear`。たけのこは、まわりが同じ高さの所にだけ生える `flatAt`。はじめの地形は `treeHighFix` でならし、ならせなければ、けす）。かたちの筆でつむときはことわる（`treeNextHigh`）。はじめの地形も、作ったあと（霧・お屋敷で高さがかわったあとも）`treeHighFix`：まわり2マスに高い所のある枯れ木はけし、生きた木は、まわり2マスを木の高さにならして、その外を2マスに1だんずつ上げる（段々。急に下げない）。
- のぼるのは1だんずつ（2だん以上は `cliffUp` で通れない）。高い所から低い所へは、何だんでもとびおりられ、2だん以上とびおりるとダメージ（`js/fall.js`：2だんで50、1だんごとに+50 `FALLDMG`。せいれいはおなか（0にはしない）、コワイノは体力 `hurtEn`）。せいれいの道さがしは、ほかに道があればとびおりをさける（`FALLCOST`）。道さがしを足すときは、むきのある `cliffUp(from,to)` を使う（さかさにさがすときは逆に。`spawnReach` の `bfsE` の `rev`）。飼う生き物のかこいは、いままでどおり `cliff2`。たしかめは `tools/tests/fall.cjs`。階段・坂は、ちょうど1だんちがう所に置き、置いた地面の高さだけ上に描く。
- 高いマスの上の物・せいれい・コワイノは、足もと（`objFoot`・`ptFoot`）を段の高さ（`IQL`）だけ上にして立てる。タップは、見えている高い段のマスをえらぶ（`liftW`・`tapAt`）。べつのキャンバスに描く物（夜のコワイノのふちどり `GLW` など）も、`ctx.getTransform()` で同じ高さにする（カメラだけで描くと、段差の上でずれる）。
- 重なり順：段差・物・せいれいは、ぜんぶ足もとの x+y の順（`render` の D、段差は `isoTile`・`icFace`、階段は `icStairDD`）。
- 段差は、どれもブロックの見え方（持ち主がきめた）：上の面は、その段の地面のひし形（`igTile`）、手前のとなり（左下・右下）が低い所だけ、1だんずつ壁のタイル（`icFace`：土は `cliff:block`、上にブロックがつづくだんは帯のない `cliff:blockm`、石のブロックは `cubeTex` を、ドットのまん中の点で面へ写す）。左の面は少し明るく（`ICLF`）、右の面はこく（`ICRT`）。上が草地なら、壁のタイルの上の行に草がたれる。ブロックには輪郭線を引かない（持ち主がきめた）。地面の絵とブロックの絵には、明るさを高さとみたノーマルマップで、左上からの光とかげを読みこむときに1回やきこむ（`nmBake`、強さ `NMK`・`NMS`。水・道・床・家具にはかけない）。
- せいれいが運ぶ物のアイコンは、上へ積む。いちばん下のアイコンの位置は、数がふえても下げない（せいれいがかくれないように）。
- 画面の上の素材は、種類が多いので総量だけ（`matN`）。木を切る・岩をほるときの進みぐあいは、木・岩の上の「のこり」のバーだけ（せいれいの足もとのバーは出さない）。バーとせいれいのふきだしが重なるときは、ふきだしをバーの上へ。修理・料理のバー（その場所に出すバー）は、話したそうなふきだしが出ていても出す。畑・木の実などでせいれいが作業しているあいだは、そのマスの育ちぐあいのバーを出さない（`workOn`。進みぐあいのバーを二重にしない）。パワー・せいれい・食料・素材は、1列にまとめる。
- ほる・つむは、守り神のどうぐ「かたちの筆」（「おく」の「どうぐ」。ヌシ様が土地に形を描いた筆。草原の本編は、神殿を直したあと、カミサマにもらう：サブクエスト `fude`・`S.flags.fude`。ほかの土地・フリーモード・カミサマが旅立ったあとのセーブは、はじめから `fudeHas`。`selStamp` の `'pick'`、`build.js` の `pickDown`・`pickTick`・`pickUp`）：タップ（`PICKTAP` より短く）で、下の列（`PICKB`・`PICKSEL`）でえらんだブロックを1だんつむ（光の線がブロックの形を描く `fudeFx`）。長おしで、マイクラのように、ブロックの面にひびが10だんで広がり（`drawPickCrack`・`crackPts`。光・ビームは出さない。持ち主がきめた）、たたくたびにブロックの材質の音とかけら（`CUBECOL`）、ほる（`pickMs`：土1秒・レンガと木のブロック1.5秒・石のブロックと地面より下2秒）。「こわす」でタップしても、物のない高い段を1だんほれる（`removeAt0` のさいご）。ブロックのアイコンは、マイクラのような、ななめから見た立方体（`cubeIcon`）。とちゅうではなすと、ほらない。1本指でなぞると画面がうごく。パワーはいらない。せいれいにたのむことはしない（持ち主がきめた。前のセーブの建てる所 `TERRA` は、そのままできあがる）。ほると、そのだんのブロックが落ちる（`terraTop`：土は土のブロック `SOIL`＝`blk_soil`・地面より下は石のブロック。その場に落ち、せいれいがもちものへはこぶ）。音はブロックの材質ごとに大きく（`brk_`・`put_`、`CUBEMAT`）。前のセーブの素材「土」（`tsuchi`）は、読みこむたび土のブロックへ（`soilMigrate`）。土のブロックのアイコンは `tools/art/tsuchi/tsuchi_icon.py`。階段のうしろの高いマスは、ほれない。だんさスコップはなくした（前のセーブは `S.flags.dig2`、パワー1000をぜんぶの土地で1回だけもどす `hakoniwa-dig2`）。水路は水のステージで。つむブロックは、その土地の地面の物だけ（持ち主がきめた。いまはどの土地も土と石：`PICKB`。石のブロック `CUBES` は依頼ボードの「ブロック」で10こずつ）。レンガ・木のブロックはなくした（`CUBEOLD`。前のセーブは `S.flags.blk2`・`blockMig`：つんだ物は石のブロックに、もちもの・落とし物は素材にもどす）。マスごとのだんのブロックは `S.vx`（`cubeAt`・`vxSet`、''は土。`expandMap` にも入れた）。絵は `cubeTex`（石はもらったテクスチャ、土はコードのドット）を、壁のタイルにする（`icFace`）。たしかめは `tools/tests/dig-stack.cjs`。
- 段差（1だんちがい）は、せいれいはゆっくりよじのぼる・おりる（1マス歩く5倍の時間、両手を上げる動き `climb`、高さは少しずつかわる。`CLIMB`。正面のがけをよじのぼるときは、うしろ向き）。コワイノは飛びこえる（3倍の時間）。階段・坂を通れば、ふつうに歩ける（`jumpEdge`）。せいれいの道は、かかる時間がいちばん短い道（`roadSearch`：段差をよじのぼる5倍・ハシゴ2倍・浅瀬2倍・道や床の速さ）。道の重みと、じっさいの歩く速さ（`jf`・`FSPD`）は、いつも同じにする。2マス以上の物は、段差をまたいで置けない。物をおいたときの緑の広がりは、段差をこえない。
- 階段は、段差の下の低い地面に置く。がけの正面は1マスと数えるので、手前向きは地面に1マス（がけの正面とあわせて2マスに見える）、ほかの向きは1×2（本体のマスと、その先の 'part'）。本体のうしろが高いマス。段差をけずってから置けば段差にうまり、けずらなければ段差から飛び出す（ビルダーズ・あつ森のように）。どの向きも6段（段の高さ LIFT/7）。向きは、置くときにえらべる（`S.rot`）。えらばなければ自動。
- ハシゴ（`LADDERS`：木のハシゴ・竹のハシゴ、建物、村レベル3）：段差の下の低い地面に置く1マス。絵は、ななめにしない。正面のハシゴは、まっすぐ立てて、がけの正面だけ（下のマスにはみ出さない）。横向き（がけの左右）は、がけに立てかけたハシゴを真上から見た形：がけのふちにそった、ほぼ一本の短い線（両はしにレールの頭）。うしろか左右のマスが、ちょうど1だん高い所（`ladderDir`）。上り下り（ハシゴのマスと、その上の高いマスのあいだの1歩だけ）は歩く速さ×0.5（`onLadder`）、よじのぼる動き。ハシゴのマスに横から入るのは、ふつうに歩く。正面のハシゴは、うしろ向き。絵はもらった絵（`tools/art/tlb`。正面 `<id>:front`、よこ `<id>:sideL/R`）。
- 坂（`SLOPES`）も階段と同じ置き方・同じ動き（`STAIRS` にふくめる）。段のない、ひとつづきの面。土で作れるのは坂（土の坂）だけ、木・石・レンガは階段だけ。
- 建てている場所の足場（`site`）は、大きさごとに3Dから写したチップ（`site:s1`・`s2`・`s2d`・`s2t`・`s3`、設計図 `tools/art/furn3d/items/sitecommon.py`）。建物の大きさで `siteKey` がえらぶ。足場が出る建物に新しい大きさを足したら、その大きさの設計図とチップも足す。足場の上に、できあがる物の絵をうすく出す（`siteGhost`：建てるほどこく。階段・ハシゴ・橋・だんさはのぞく）。設計図のまだの家具・建物・花の部品も、うすい絵（`bpGhostDraw`）。
- 階段は建物（`BUILDS`）：「おく」の建てるからえらび、せいれいが建てる。
