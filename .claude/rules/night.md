# 夜・守り・戦い

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。数字（%・倍・秒）はコードが本物。たしかめは `tools/tests/` の `sortie`・`pace`・`waves`・`defense*`・`feel-hit` など。

## 見張り台と木の矢
- 夜（火の子が見回りをはじめるのと同じとき）、火の子いがいのせいれい（属性のじゅんばんはなし）が見張り台に1人ずつ（Lv8からは2人まで）立つ（とってきたごはんは、食べてから行く。ハシゴを、うしろ向きによじのぼる動きで少しずつのぼる。おりるときは、のぼる前の場所へ。行ける見張り台がなければ、しばらく起こさない）。コワイノがぜんぶいなくなったら、見張り台の子はおりて寝にいく。見張り台は、せいれいが上に立っているときだけうつ。上の子は、つかれない。うつときは、上の子が弓を引いてはなす動き。まっているときは、弓をもった腕を下げ、ふつうの顔。夜、コワイノがいるのに、どの見張り台にもせいれいが向かっていないと「見張り台にせいれいがいません」と1回知らせる（見張り台が多くて人が足りないとき・朝おりたあとは知らせない）。上に立つ子がいることは、見張り台をもらう会話と、ひでんのしょに書く。見張り台の上に、木の矢の本数をいつも出す（夜の暗さより上）。見張り台の上の子は、上に描いた所でタップする（本体をタップすると見張り台の画面）。上の子は、見張り台がこわれるまで攻撃されない（半分よりのぼったら）。この子は、コワイノが来るとこわがる（おどろいた顔）が、泣かない。
- 出撃（`fighter`、せいれいの `r.sortie`）：草原のサブクエスト（メインの「こもれびのまもり」のあと、アオが「わたしもたたかいたい」）を受けると（ほかのステージへも）、せいれいの画面で出撃する・しないをえらべる（6時〜23時だけ。夜はかえられない）。火のせいれいと、こもれびのまもりをおぼえたフタバ（サブクエストの前でもえらべる）は、はじめ出撃する・ほかは、しない。出撃した火のせいれいでない子は、火の子と同じ夜の動き（見回り・近くのコワイノをねらう・おなか250より下でにげる）で、近接のダメージはその子の攻撃力（`SORTIE`。水 ダメージなしで止める）。出撃しない火のせいれいは、見張り台に立つ（`WPEL.fire`：威力0.5倍・矢を1回に2本・延焼）。火の子にかぎった夜の判定を足すときは `elem==='fire'` でなく `fighter(r)` を使う。
- 見張り台に立つ子の属性で、うち方がかわる（`WPEL`・説明 `WPTXT`）：木はそのまま、土は威力が大きく・うつ速さがおそい、風は射程が長く・威力が小さい、水は矢をつかわず、あたったコワイノを止める（オオカゲなどは半分、ダメージなし）。立つ子は、ベッドと同じく、見張り台の画面できめられる（きまった子がいないときは、だれでも）。カミサマにもらった見張り台も、こわすと素材がもどる。
- こもれびのまもりは、出撃しているフタバだけが使い（見張り台・家の中からは使わない）、フタバのまわり3マスで、ねらわれている、たたかう子（`fighter`）を1人守る（遠くにはとどかない）。おぼえる会話で、フタバは前に出ると言い、出撃する。最後の夜は、フタバはかならず出撃し、守る子のまわり3マスの子もまもる。最後の夜の会話も、フタバが前に出る内容にする（「うしろにいる」と言わせない）。
- コワイノがねらう順番：近くのせいれい（歩いて行ける子）→ 見張り台の上のせいれい（見張り台をこわしにいく。柵・塀の中の見張り台は、柵の中のせいれいのあと）→ 柵の中のせいれい → 家の中のせいれい。
- 見張り台どうしは、あいだを5マスあけないと置けない（たて・よこ・ななめ。建てている途中の物・ひっこしミトンも同じ）。
- 見張り台の強化は10段階（Lv5からはやすらぎの砂もいる）。絵は段階ごとに1まい（3Dの設計図 `tools/art/furn3d/items/watch.py`）。段階ごとに材料がじょうぶになる（木 → 石の台座・鉄の帯 → 石の土台・板かべ・胸壁）。旗・星・屋根はつけない（持ち主がきめた）。Lv5から夜にあかり（あかりとして数える：`LIGHTS`・`LITP`・`LIGHTQ`）。Lv8から2人立てる。
- 見張り台は木の矢を放つ。1発で木の矢1本。木の矢がないとうたない（そのとき1回だけ「見張り台の木の矢がありません」）。木の矢は依頼ボードの「ワナ」でつくる（`kind:'ammo'`。置く物ではない）。はじめの見張り台といっしょに、カミサマが20本くれる。守護の台座は光の矢のまま。かなものの矢（依頼ボードの「ワナ」）：見張り台の威力+1。あれば木の矢より先に使う。ホノのサブクエスト（はじめてオオカゲを追いはらったあと）でおぼえる。
- 見張り台は、とどくコワイノがいる矢のうち、威力の大きい矢から使う（射程の短い強い矢がとどかなくても、ほかの矢でうつ）。射程の円は、上に立つ子の属性・霧の夜を入れた、うつ所と同じ射程。矢をふやしたら `AMMO` に入る。
- 夜のコワイノをぜんぶ追いはらって、さいごの子が倒れおわったら、起きている子がよろこぶ（1晩1回）。

## コワイノの数・夜の来かた・守り
- コワイノの数は、せいれいの人数×1〜2倍（倍率はその日ごとにきまる小数。答えの小数点以下はきりすて。平均レベルはたさない）。夜12時に上限でけずらない。しゅるいも平均レベルでまじる。お話の進みは、オオカゲを追いはらったあとの数だけ。
- できごとの間（`pace.js`）：朝（あらしをきめる前）に、きのうのきびしさの点（こわされた物・おなかが250より少なくなった子・あらし・夜の変化・オオカゲ）。多い日は、きょうとあしたの夜は夜の変化なし・あらしもきめない。0点が3日つづいたら、その日だけ霧の夜・あらしが出やすい。夜の変化・あらしの決まり方をかえたら、ここも見る。
- 防衛の夜の変化（日ごとにしまう）：霧の夜（見張り台のとどく所が半分・うすい霧の絵）、群れの夜（コワイノが南のはしの1か所から来る。群れの夜のあとしばらくは群れにしない）、1しゅるいだけの夜（夜12時に上限でけずったあとで入れかえる。お話のコワイノはそのまま）：ワナクイのうたげ（数は半分）・かげのどろぼう市・かげのうしお（コカゲだけ、来る間かくが半分）。ワナクイ・カゲドロボウの夜は、ふつうの夜で会ってから。同じ夜に2つはない。オオカゲの夜・おだやかな夜・5日目より前（夜4回より前）にはない。夕方に知らせ、`#dayLbl` に出す。
- 草原の夜の来かた（`waves.js`。はじめてオオカゲを追いはらったあとの、ふつうの夜だけ）：5つの小さな波（目標の欄に出す。3つの波では、火のせいれい1人の村で手が足りなくなった）・先ぶれのハヤカゲ（村に入ると帰る。たおすと、まだ来ていない本隊が2わりへる）・東か西からも来る夜（夜20時に知らせる）。守りの草：ねばり草・ほたるの草むら（あかり。はじめて光に入ったコワイノを1晩1回止める）は、サブクエストでおぼえる。ほたるの草むらは、依頼ボードで作るあかりのクエスト（`LIGHTQ`）には数えない（クエストの文とあわない）。
- 守りのしくみ（`defense.js`）：見張り台は段差1だんごとに射程が伸び、Lv5で強化の道、合図の太鼓でうつ間かくが短くなる。天気の夜（雨・風の強い日・あらし。夜に知らせは出さない、持ち主がきめた）。ヨロイカゲ（`hurtEn` の `dt` が arrow なら半分、fire・poison・burn は2倍。ダメージを出す所は `dt` をつける）・ヒカリカゲ。コワイノの絵をほかの種類からかりるときは `EN` の `art`。持ち主がことわった物：守り神の目印・波のあいまの修理・朝のおくりもの（もう出さない）。コワイノの弱点（`hurtEn` の `o.el` に攻撃したせいれいの属性）・ベテランの見張り台・かげの巣・オオカゲの段階・葉のかべ（`GATE_IDS` に入れてせいれいだけ通す）・わざの枠3つ。落とし穴の罠（土のせいれいがほりなおす）・季節のコワイノ・守りつづけた夜（日の欄は、たてのアイコンと晩の数だけ）。
- 満月・新月：8日ごとにめぐる（日の番号を8でわって0が満月・4が新月）。ほかの夜の変化とかさなる。夜（20時〜朝6時）だけ、`#dayLbl` の天気のかわりに月のアイコンと名前。コワイノの歩く速さ（満月はおそく・新月は速く、オオカゲもふくめてぜんぶ）と夜の暗さ（満月は明るく・新月は暗い）。
- おびきよせの石像（水のステージ Lv6）：まわり7マスのコワイノ（オオカゲなどの大きいコワイノ・カゲドロボウ・ワナクイはのぞく）は、せいれい・見張り台・柵・家より先に像をこわしにいく。こわれたら `S.broken` に入り、直せる。

## 戦いの数字と手ざわり
- 戦いの数字は、ダメージの数字に小数点が出ないように、前の数の10倍の整数（パワーバランスは前のまま）：はたらく速さ・移動速度・スタミナは20がふつう、コワイノの体力（コカゲ100）・攻撃力（火のせいれいLv1で10）・見張り台・矢・罠・まもりの光・そうびの威力は10がひとつぶん。おなかも10倍のあと半分。新しい数字も、この大きさの整数で書く。
- コワイノへのダメージは、かならず `hurtEn`（`night.js`）を通す（`e.hp-=` とじかに書かない）。ダメージはぶれる（テストで数をたしかめるときは `o.exact`）。整数にまるめ、数字・火花・のけぞりを出す。倍（つかれ・見張り台に立つ子の属性・そうびの光）がかかる所は、その結果を `Math.round`（出る数字と、じっさいにへる量を同じにする）。
- 戦いの見た目（`night.js` の「戦いの手ざわり」：ダメージの数字・火花・のけぞり・ふみこみ）は、実時間でうごく見た目だけ。ダメージの計算・コワイノの動きはかえない。時刻はセーブにのこさない（WeakMap）。数字は5×7のドット、夜の暗さより上に描く。
- 火のせいれいの攻撃は、ふりはじめてから `HIT_LAG` あとに当たって見える（斬撃の絵・音・数字・のけぞりを、その時刻に合わせる）。矢は `SHOT_LAG`。たおれるコワイノは、当たってから `KO_HOLD` のあいだ白く止まって、たおれる。止まる長さはダメージで3つ（ふつう・大きなダメージ・守り神のわざ）。止まっているあいだ、受けた側が左右にふるえ、たたかれたせいれいも白く光る。たおしたときの音・+パワー・知らせは、白く止まりおわってから（上のパワーの数も、それまでふやさない）。
- 画面のゆれは `shakeScreen(lv)` の3段だけ（'s' 小・'m' 中・'l' 大。大はオオカゲの登場とたおしたときだけ）。小さいゆれで大きいゆれを上書きしない。うごきをへらす設定では、ゆらさない。ゆらす所を足すときも、これを通す（`#cv` に class をじかにつけない）。
- 木・岩は、たたくたびに、たたかれた向きへゆれる（木くず・石のかけらも毎回）。まもりの光でこわしたときも、せいれいと同じ手ごたえ。
- こわすは、置くときの着地・上がる音をしない。こわした物がうきあがって消え、つづけてこわすほど録音の高さが下がる。置けない・こわせない所は、知らせといっしょに、そのマスの物と点線のわくが横にふるえて「こつん」（`canPlace`・`removeAt` の外がわで、本体は `canPlace0`・`removeAt0`）。
