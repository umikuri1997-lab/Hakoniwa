# 夜・守り・戦い

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。

## 見張り台と木の矢
- 夜（火の子が見回りをはじめるのと同じとき）、火の子いがいのせいれい（属性のじゅんばんはなし）が見張り台に1人ずつ（Lv8からは2人まで）立つ（`watchpost`。とってきたごはん（`r.meal`）は、食べてから行く。ハシゴを、うしろ向きによじのぼる動きで少しずつのぼる `cl`。上に立つ位置は `WPLIFT`（108、床の見えている所のまん中）だけ上。おりるときは、のぼる前の場所へ。行ける見張り台がなければ、しばらく起こさない `wpNo`）。コワイノがぜんぶいなくなったら（`nightClear`）、見張り台の子はおりて寝にいく（火の子と同じ。あたらしく立ちにも行かない）。見張り台は、せいれいが上に立っているときだけうつ（`watchGuard`）。上の子は、つかれない。うつときは、上の子が弓を引いてはなす動き（`bowT`、`bow`）。まっているときは、弓をもった腕を下げ（`bowidle`）、ふつうの顔。夜、コワイノがいるのに、どの見張り台にもせいれいが向かっていないと「見張り台にせいれいがいません」と1回知らせる（見張り台が多くて人が足りないとき・朝おりたあとは知らせない）。上に立つ子がいることは、見張り台をもらう会話と、ひでんのしょに書く。見張り台の上に、木の矢の本数をいつも出す（`drawArrowTags`、夜の暗さより上）。見張り台の上の子は、上に描いた所でタップする（`tapY`。見張り台の本体をタップすると見張り台の画面）。見張り台の上の子は、見張り台がこわれるまで攻撃されない（`onTower`、半分よりのぼったら）。この子は、コワイノが来るとこわがる（おどろいた顔）が、泣かない。
- 出撃（`sortieOn`・`fighter`、せいれいの `r.sortie`）：草原のサブクエスト（`sortie`、メインの「こもれびのまもり」のあと、アオが「わたしもたたかいたい」）を受けると（`S.flags.sortie`、ほかのステージへも `syncTools`）、せいれいの画面で出撃する・しないをえらべる（6時〜23時だけ。夜はかえられない、`sortieSec`）。火のせいれいと、こもれびのまもりをおぼえたフタバ（`sortieGuard`。サブクエストの前でもえらべる `sortieOK`）は、はじめ出撃する・ほかは、しない（`sortieDef`）。出撃した火のせいれいでない子は、火の子と同じ夜の動き（見回り・近くのコワイノをねらう・おなか250より下でにげる）で、近接のダメージはその子の攻撃力（`SORTIE`：間かく 木5・土10・風5、風はとどく2.25、水 ダメージなしで止める。受けるダメージは `hitN`）。出撃しない火のせいれいは、見張り台に立つ（`WPEL.fire`：威力0.5倍・矢を1回に2本 `use`・延焼 `BURN` 3ごとに3ダメージを3回、かけなおし）。火の子にかぎった夜の判定を足すときは `elem==='fire'` でなく `fighter(r)` を使う。たしかめは `tools/tests/sortie.cjs`。
- 見張り台に立つ子の属性で、うち方がかわる（`WPEL`・説明 `WPTXT`）：木はそのまま、土は威力1.5倍・うつ速さ0.5倍、風は射程1.5倍・威力0.5倍、水は矢をつかわず、あたったコワイノを止める（1分＋攻撃力1につき30秒・オオカゲなどは半分、ダメージなし、`waterStop`）。立つ子は、ベッドと同じく、見張り台の画面できめられる（`S.wpOwn`。きまった子がいないときは、だれでも）。カミサマにもらった見張り台も、こわすと素材がもどる。
- こもれびのまもり（`guardTick`）は、出撃しているフタバだけが使い（見張り台・家の中からは使わない）、フタバのまわり3マス（`GUARDR`）で、ねらわれている、たたかう子（`fighter`）を1人守る（遠くにはとどかない）。おぼえる会話で、フタバは前に出ると言い、出撃する。最後の夜は、フタバはかならず出撃（`fighter`）し、守る子のまわり3マスの子もまもる。最後の夜の会話（`e16`・`e15`）も、フタバが前に出る内容にする（「うしろにいる」と言わせない）。
- コワイノがねらう順番：近くのせいれい（歩いて行ける子）→ 見張り台の上のせいれい（見張り台をこわしにいく。柵・塀の中の見張り台は、柵の中のせいれいのあと）→ 柵の中のせいれい → 家の中のせいれい。
- 見張り台どうしは、あいだを5マスあけないと置けない（たて・よこ・ななめ。建てている途中の物・ひっこしミトンも同じ、`watchNear`）。
- 見張り台の強化は10段階（`WATCH`・`WUP`。Lv5からはやすらぎの砂もいる）。絵は段階ごとに1まい（`watchArt`：`watch`・`watch@2`〜`watch@10`。3Dの設計図 `tools/art/furn3d/items/watch.py`）。段階ごとに材料がじょうぶになる（木 → 石の台座・鉄の帯 → 石の土台・板かべ・胸壁）。旗・星・屋根はつけない（持ち主がきめた）。Lv5から夜にあかり（`watchLit`・`litP`。あかりとして数える：`LIGHTS`・`LITP`・`counts.watchlight`（`LIGHTQ`））。Lv8から2人立てる（`wpCap`・`act.slot`・立つ所ごとのうつ間かく `'w'+j+'_1'`、`wpGuardAt`）。前のLv2・Lv3は、読みこむときLv3・Lv5に（`watch5`）。
- かなものの矢（`arrow2`、枝1・石材1・空き缶1で10本、依頼ボードの「ワナ」）：見張り台の威力+1。あれば木の矢より先に使う。ホノのサブクエスト（`arrow2`、はじめてオオカゲを追いはらったあと。作った数 `S.flags.a2made`）でおぼえる。
- 見張り台は木の矢を放つ。1発で木の矢1本（`S.inv.arrow`）。木の矢がないとうたない（そのとき1回だけ「見張り台の木の矢がありません」）。木の矢は依頼ボードの「ワナ」でつくる（枝1・石材1で10本、`BL.arrow`、`kind:'ammo'`。置く物ではない）。はじめの見張り台といっしょに、カミサマが20本くれる。守護の台座は光の矢のまま。

## 手ざわり・まとまり・間（ポリッシュ）
- 夜のコワイノをぜんぶ追いはらって、さいごの子が倒れおわったら、起きている子がよろこぶ（`nightClearJoy`、1晩1回 `S.ns.clr`）。

## 火山のそうび
- 見張り台は、とどくコワイノがいる矢のうち、威力の大きい矢から使う（`towerVolley`。射程の短い強い矢がとどかなくても、ほかの矢でうつ）。射程の円（`rangeOf`）は、上に立つ子の属性・霧の夜を入れた、うつ所と同じ射程。矢をふやしたら `AMMO` に入る。
- コワイノの数は、せいれいの人数×1〜2倍（倍率はその日ごとにきまる小数 `waveMul`。答えの小数点以下はきりすて。平均レベルはたさない）。夜12時に上限でけずらない。しゅるいも平均レベルでまじる（`waveFor` の `alv`）。お話の進みは、オオカゲを追いはらったあとの数（`late`）だけ。
- できごとの間（`pace.js`）：朝（`morning` のはじめ、あらしをきめる前）に、きのうのきびしさの点（`paceScore`：こわされた物1つ1点 `S.ns.broke`・おなかが250より少なくなった子1人1点 `S.pcH`・あらし2点・夜の変化2点・オオカゲ3点）。5点いじょうなら、きょうとあしたの夜は夜の変化なし・あらしもきめない（`S.paceCalm`）。0点が3日つづいたら、その日だけ霧の夜25%・あらし10%（`S.paceSpice`）。夜の変化・あらしの決まり方をかえたら、ここも見る。たしかめは `tools/tests/pace.cjs`。
- 防衛の夜の変化（`nightVarPick`・`S.nightVar`、日ごとにしまう）：霧の夜15%（見張り台のとどく所が半分・うすい霧の絵）、群れの夜5%（コワイノが南のはしの1か所から来る `mureSpot`。群れの夜のあと7日は群れにしない `S.mureDay`）、1しゅるいだけの夜（`NVONLY`・`nightVarWave`、夜12時に上限でけずったあとで入れかえる。お話のコワイノはそのまま）：ワナクイのうたげ5%（数は半分）・かげのどろぼう市5%・かげのうしお5%（コカゲだけ、来る間かくが半分）。ワナクイ・カゲドロボウの夜は、ふつうの夜で会ってから（`S.seenEn`）。同じ夜に2つはない。オオカゲの夜・おだやかな夜・5日目より前（夜4回より前）にはない。夕方に知らせ、`#dayLbl` に出す。
- 草原の夜の来かた（`waves.js`。はじめてオオカゲを追いはらったあとの、ふつうの夜だけ `wavesOn`）：5つの小さな波（`WAVES`、目標の欄に `waveNote`。3つの波では、火のせいれい1人の村で手が足りなくなった）・先ぶれのハヤカゲ（`scoutTick`。村に入ると帰る。たおすと、まだ来ていない本隊が2わりへる `scoutDown`）・東か西からも来る夜（`nightSidePick`、夜20時に知らせる）。守りの草：ねばり草（`nebari`）・ほたるの草むら（`hotaru`、あかり。はじめて光に入ったコワイノを1晩1回止める `hotaruTick`）は、サブクエスト（`nebari1`・`hotaru1`）でおぼえる。ほたるの草むらは、依頼ボードで作るあかりのクエスト（`LIGHTQ`）には数えない（クエストの文とあわない）。たしかめは `tools/tests/waves.cjs`。
- 守りのしくみ（`defense.js`）：見張り台は段差1だんごとに射程+0.5（`towerRng`）、Lv5で強化の道（`WPATH`、`S.dyn[j].wp`）、合図の太鼓（`drum`、`DRUMS`）でうつ間かく0.8倍。天気の夜（`nightWx`：雨・風の強い日・あらし。夜に知らせは出さない、持ち主がきめた）。ヨロイカゲ（`armor`：`hurtEn` の `dt` が arrow なら半分、fire・poison・burn は2倍。ダメージを出す所は `dt` をつける）・ヒカリカゲ（`shiny`）。コワイノの絵をほかの種類からかりるときは `EN` の `art`。持ち主がことわった物：守り神の目印・波のあいまの修理・朝のおくりもの（もう出さない）。コワイノの弱点（`WEAK`、`hurtEn` の `o.el` に攻撃したせいれいの属性）・ベテランの見張り台（`S.dyn[j].vk`）・かげの巣（`kagenest`、`nestMorning`）・オオカゲの段階（`bossPhase`）・葉のかべ（`leafwall`、`GATE_IDS` に入れてせいれいだけ通す。守り神のちから `GUP` の `leaf`）・わざの枠3つ（`S.skillSet`、`skillOn`。わざのアイコン `SKILLS` の4つめ：`glight`・`shield`・`lwall`）。たしかめは `tools/tests/defense2.cjs`。見張り台のねらう順（`S.dyn[j].to`、`torderKey`）・落とし穴の罠（`pit`、穴は `S.dyn[j].pu`、土のせいれいがほりなおす `pitJob`）・季節のコワイノ（`SEASONEN`）・守りつづけた夜（`S.streak`、`streakWork`。日の欄は、たてのアイコン `shield` と晩の数だけ）。たしかめは `tools/tests/defense3.cjs`。たしかめは `tools/tests/defense.cjs`。
- 満月・新月（`moonOf`・`moonNow`）：8日ごとにめぐる（日の番号を8でわって0が満月・4が新月）。ほかの夜の変化とかさなる。夜（20時〜朝6時）だけ、`#dayLbl` の天気のかわりに月のアイコンと名前。コワイノの歩く速さ（`MOONSP`：満月0.9倍・新月1.1倍、オオカゲもふくめてぜんぶ）と夜の暗さ（`MOONDK`：満月 .54・新月 .78、ふだん .66）。

## 戦いの数字と手ざわり
- 戦いの数字は、ダメージの数字に小数点が出ないように、前の数の10倍の整数（パワーバランスは前のまま）：はたらく速さ・移動速度・スタミナは20がふつう（上の「せいれいのレベル」）、コワイノの体力（コカゲ100）・攻撃力（火のせいれいLv1で10）・見張り台・矢・罠・まもりの光・そうびの威力は10がひとつぶん。おなかも10倍のあと半分（最大500・さかい目・へる量・ふえる量・コワイノから受ける数 `hitF` など）。新しい数字も、この大きさの整数で書く。
- コワイノへのダメージは、かならず `hurtEn`（`night.js`）を通す（`e.hp-=` とじかに書かない）。ダメージは±15%ぶれる（`DMGVAR`。テストで数をたしかめるときは `o.exact`）。整数にまるめ、数字・火花・のけぞりを出す。倍（つかれ・見張り台に立つ子の属性・そうびの光）がかかる所は、その結果を `Math.round`（出る数字と、じっさいにへる量を同じにする）。
- 戦いの見た目（`night.js` の「戦いの手ざわり」：ダメージの数字 `DMGN`・火花 `SPKS`・のけぞり `HITV`・ふみこみ `ATKV`・`atkLunge`）は、実時間でうごく見た目だけ。ダメージの計算・コワイノの動きはかえない。時刻はセーブにのこさない（WeakMap）。数字は5×7のドット（`DG`）、夜の暗さより上に描く（`drawBattleFx`）。
- 火のせいれいの攻撃は、ふりはじめてから `HIT_LAG` あとに当たって見える（斬撃の絵・音・数字・のけぞりを、その時刻に合わせる）。矢は `SHOT_LAG`。たおれるコワイノは、当たってから `KO_HOLD` のあいだ白く止まって、たおれる。
- 止まる長さはダメージで3つ（`HIT_STOP` ふつう・`HIT_STOPB` 大きなダメージ・`HIT_STOPS` 守り神のわざ、`hitFx` が `HITV` の `s` に入れる）。止まっているあいだ、受けた側が左右にふるえ（`HIT_SHAKE`）、たたかれたせいれいも白く光る（`drawSpiritOL` の `white`）。たおしたときの音・+パワー・知らせは、白く止まりおわってから（`defeat` の `dKO`。上のパワーの数も、それまでふやさない `JPTPEND`）。
- 画面のゆれは `shakeScreen(lv)` の3段だけ（'s' 小 1.5px たてだけ・'m' 中 3px・'l' 大 4.5px。大はオオカゲの登場とたおしたときだけ）。小さいゆれで大きいゆれを上書きしない。うごきをへらす設定では、ゆらさない。ゆらす所を足すときも、これを通す（`#cv` に class をじかにつけない）。
- 木・岩は、たたくたびに、たたかれた向きへゆれる（`natJolt`・`dropIn`。木くず・石のかけらも毎回）。まもりの光でこわしたときも、せいれいと同じ手ごたえ（`natHit` の `juiceBreak`）。
- こわす（`burst` の `'rm'`）は、置くときの着地・上がる音をしない。こわした物がうきあがって消え（`rmGhost`・`RMFX`）、つづけてこわすほど録音の高さが下がる（`RMRT`）。置けない・こわせない所は、知らせといっしょに、そのマスの物と点線のわくが横にふるえて「こつん」（`refuseFx`。`canPlace`・`removeAt` の外がわで、本体は `canPlace0`・`removeAt0`）。たしかめは `tools/tests/feel-hit.cjs`。
