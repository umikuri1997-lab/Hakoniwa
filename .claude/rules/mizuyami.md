# 水・闇のステージ

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。

## 水のステージ（霧のみずべの村）
- ステージのならびは「草原0 → 火山1 → 土2 → 水3 → 風4」（持ち主がきめた）。水の番号は `MIZU`（`core.js`）。土のステージは、まだない。
- いまは試作（`js/mizube.js`、セーブは `S.mz`）：お話・新しい絵はない。夜のコワイノは、神殿を直したあとから、ほかのステージと同じ南のはしから来る。オオカゲは来ない。水のとどいた水路は堀で、コワイノの歩く速さ `MZMOAT` 倍（浅瀬の2倍ゆっくりにかさねる）。たしかめは `tools/tests/mizube-night.cjs`。マップえらびから、いつでも入れる。きまったこと・まだの物は `IDEAS.md`。
- 水路：「水路をほる」（`canal`、`TERRA` に入れた、せいれいの工事）でほったマスは `S.mz.cn`。水は、ひらいた水門から、同じ高さか低いほうへだけ流れ、水門1つで `MZFLOW` マスまで（`mzRefresh`：`recount` のはじめによぶ）。水のとどいた水路は `S.ground` を2（浅瀬）にする。水路・ため池・小舟の絵は、段差の絵のあと、行ごとに描く（高い段の水は、ゲームの水の絵では描けないので、ここで描く）。水路 `mzcanal:d<つながり>`・`mzcanal:w<つながり>`、ため池のふち `mzpond:<つながり>`、小舟 `mzboat`・`mzboat:c`、いかだ `mzraftb` はチップ（GPT の H-6）。水の流れ・さざなみ・氷・段をおちる水は、ゲームで描く。
- 霧：マスごと（`S.mz.clr`。晴れた所はもどらない）。`fogAt` が水のステージでは `mzMistAt` を見る。霧を見る所は `fogAt(j)` だけを書き、`S.fog&&` をつけない（つけると、水のステージの霧を見ない）。
- 舟便：船着き場（`dock`）が同じ高さの水でつながると、舟の道。道さがし（`roadSearch`）と歩く所（`spirit-work.js`）は、舟の道を歩く3倍の速さの道として見る。ほかの土地のお返しは `MZTRADE`（実数）。
- 川くだり（`raft`）・しずんだ宝箱（`mzchest`：水門をひらくと、ため池の南がわから浅瀬になる）。たしかめは `tools/tests/mizube.cjs`。
- 食堂（`js/mizube-shop.js`、数字は `SHOP`）：家の中に、店の看板・食卓・食卓のとなりのいす・料理の家具があると食堂（`recount` のたびに見なおす）。お客さんは1日2回、船着き場から歩いて来る、見た目だけの子（セーブしない。絵は旅の外套のチップ `guest`・`guest>1`・`guest>2`）。運ぶのは水あびより先（水あび・休み・ぶらぶらはやめる）。うでは料理のおわり。かいがら・メニュー・料理のおいしさ・歌の日は `S.mz`。たしかめは `tools/tests/mizube-shop.cjs`。
- 水のお話の前半（台本 `MIZUBE.md` の1〜4）：神殿 → 水門 → 水路 → しずんだ宝箱（カナデの紙）→ ノミをむかえる（来たらカミサマが旅立つ）→ 船着き場 → 食堂 → 歌の舞台 → くだりくらべ（ミオとノミが1回ずついかだでくだる）→ 2つめの水門 → 3つめの水門を霧の奥に見つける（3つめの水門は、ため池の北西のふち）。ノミは2人めのキーキャラ（土、一人称「おれ」、みじかく、ぶっきらぼう：`chatTone` の `nomi`）。たしかめは `tools/tests/mizube-story.cjs`。
- 水のお話の後半（`js/mizube-story.js`、台本 `MIZUBE.md` の5〜10）：3つめの水門を見つけたお礼の会話でミオとノミがけんか（仲なおりはおくりの水路の依頼の会話。そのあいだ2人のおしゃべり・遊びは止める）→ ため池の底のこうら（タップでミオとノミが歩いて行き、そろったら場面）→ おくりの水路（3つめの水門の前から南の低い池まで、下りだけでつながる）→ キリノオオカゲ（`EN.kirino`：強さはヨルノオオカゲと同じ。夕方の会話、その夜に来る。まわりの見張り台は射程半分、まわりの水路はこおって堀にならない・朝にとける。負けたら `MZKRETRY` 日あと）→ 夕方に3つめの水門をタップ（ミオがひらく。ほかのせいれいは直さない）→ つぎの朝の夜明け（霧がぜんぶ晴れ、ため池に水がもどり、白い花）→ その日の夕方の食堂でクリア（`S.flags.mzEnd`）。場面は `wsScene`（会話の話者のしぼりこみ `windLines` は `NUSHI3` も通す）。たしかめは `tools/tests/mizube-story2.cjs`。
- テストで水路を書くときは、神殿（まん中の水門のま南）と、はじめの木箱をよける（上にかさねると、神殿が消えて工事をたのめなくなる）。神殿を直したあとは、お礼の会話を読みおえるまで、せいれいが待っている。

## 闇のステージ（WORLD 6、`WD===YAMI`、`js/yami.js`）
- お話の設定は `STORY.md` の「さいごの章」、作る順番とまだきめていないことは `IDEAS.md`。水・土・風ができるまでは、マップえらびのとじたカードを5回タップでひらく。
- ずっと夜：時計・ねる時間（`isNight`）はほかのステージと同じ。空・光・音を時刻でかえる所を足したら、`hour()` でなく `skyHour()` を使う。
- はじめは、せいれいが0人。まもりの光が地面にとどくと、はじめの1回だけ、光のせいれいトモリが生まれる。
- 光の属性（`ELEM.light`）はトモリだけ：神殿では呼べない（`ELEM_KEYS` に入れない）・たたかわない・コワイノにねらわれない・たたかれない（さいごの夜の、むかえる〜ゆりかごへ、だけはねらわれる）・まわり4マスが歩くあかり。属性ごとの表を足したら、光でこわれないか（`表[r.elem]` をそのまま使っていないか）を見る。
- トモリ（光）・ツキミ（闇）の絵は、GPT の H-4：部品のチップ `sp_light:*`・`sp_dark:*`（ケープ `cape`・胸のかざり `chest`・ツキミのナイトキャップ `cap`）と、3Dの動きの絵（`tools/art/spirit3d/light_dark.py`、`build.py --add light,dark` で、ほかの属性の絵をそのままに足せる）。`SPC.light`・`SPC.dark` は、3Dの絵の色と同じにする（ちがうと、色がえで合わない）。せいれいの絵を属性の名前でさがす所は `spArt(el)` を通す。
- コワイノの来かた：トモリが生まれたときから来る。23時〜6時は、ほかのステージと同じ大きな群れ。6時〜23時は、時計の1時間ごとに25%でコカゲが1〜2ひき。朝の光がないので、朝6時に消えない。追いはらうまでのこる。
- お話の前半（`QUESTS6`）：あかり → ヒイロ（はじめに来る火のせいれい、あにき）→ ヨリ（夜、ねているトモリのとなりにいる、おそってこない影。`S.enemies` に入れず、コワイノの絵で描くだけ。夜にタップ）→ 夜の仕事のあと3つ（見た目だけの印。昼、ヨリがまだ見ていない印で待つ）→ あさやけ（聞いたつぎの朝6時の場面。ヨリが朝の光でうすれて消える）。
- 朝の空：おわったお話の数ぶん、朝の時間（4時半〜8時半）だけ明るい。あさやけのあとは、朝の時間に本当の朝の光。
- さいごの目標のお礼の会話は、目標の一覧のおわりでも出す（`checkQuest`）。
- お話の後半：すわりこむトモリ（あかりは1マス）→ からっぽの夜のゆりかご（庭の北の3×3と手前の1行。見た目だけで、物は置けない）→ あけよい草（ヨリの消えた所に芽、朝ごとにのびて2日でつぼみ。まわり3マスにあかりのない20〜23時にひらく。トモリは自分のあかりをおとす）→ 5つの属性で直す → さいごの夜（あかりを消す → 大きな影をむかえる → ゆりかごへ → やすむ → 朝6時）→ クリア。
- 依頼の会話のない目標になったかは `yamiAt`（`qAt` は依頼の会話を聞いたあと）。
- 消したあかりは `recount` で `LIGHTS`・`LITP` からのぞき、つぎの朝6時にもどる。消せるのは、あけよい草のそばのあかり（つぼみのあいだ）と、さいごの夜のぜんぶ。
- 大きな影はたたかわない（`S.enemies` に入れない）。さいごの夜のトモリはたたかれてもおなかがへらず、3回か朝になったら、3日あとにやりなおし。
- トモリ・ゆりかごを直す子の行動は `decide0` のはじめの `yamiDecide` できめる。夜も歩く・待つのは `NIGHT_OK` に入れてある。
- クリアのあとは、空・暗さが、ほかのステージと同じ昼と夜。
- クリアした日の夜20時、ゆりかごから闇のせいれいツキミが生まれる（会話をさいごまで見てから）。闇の属性（`ELEM.dark`）はツキミだけ：神殿では呼べない・たたかわない。夜はねむらず、ねむるせいれいのそばにすわって見守り（家の中ではかくれる）、まわり `TKWR` マスでねむる子のつかれのとれる速さ `TKWK` 倍。朝はねむる。
- クリアのあと、追いはらったコワイノは夜のほうへかえる（白く止まる → ふりむいて北へ歩く → 紺にとけて、ドットの三日月がのこって消える）。たしかめは `tools/tests/yami-after.cjs`。
- 会話でヒイロがいないときは、ヒイロの行だけはぶく（`ideaDialogue`）。
- たしかめは `tools/tests/yami.cjs`・`tools/tests/yami-story.cjs`・`tools/tests/yami-story2.cjs`（会話は自動プレイと同じ送り方 `DLGA`＋`#dlgBtns`。朝の日記の紙はとじる。タップで始める会話は `DLGTAP` を入れてから）。
