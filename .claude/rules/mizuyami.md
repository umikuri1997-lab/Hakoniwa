# 水・闇のステージ

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。たしかめは `tools/tests/mizube*.cjs`・`yami*.cjs`。

## 水のステージ（霧のみずべの村）
- ステージのならびは「草原0 → 火山1 → 土2 → 水3 → 風4」（持ち主がきめた）。水の番号は `MIZU`（`core.js`）。
- いまは試作（`js/mizube.js`、セーブは `S.mz`）。夜のコワイノは、神殿を直したあとから、ほかのステージと同じ南のはしから来る。オオカゲは来ない。水のとどいた水路は堀で、コワイノの歩く速さ `MZMOAT` 倍（浅瀬の2倍ゆっくりにかさねる）。マップえらびから、いつでも入れる。きまったこと・まだの物は `IDEAS.md`。
- 水路：「水路をほる」（`canal`、`TERRA` に入れた、せいれいの工事）でほったマスは `S.mz.cn`。水は、ひらいた水門から、同じ高さか低いほうへだけ流れ、水門1つで `MZFLOW` マスまで（`mzRefresh`：`recount` のはじめによぶ）。水のとどいた水路は `S.ground` を2（浅瀬）にする。水路・ため池・小舟の絵は、段差の絵のあと、行ごとに描く（高い段の水は、ゲームの水の絵では描けないので、ここで描く）。水路 `mzcanal:d<つながり>`・`mzcanal:w<つながり>`、ため池のふち `mzpond:<つながり>`、小舟 `mzboat`・`mzboat:c`、いかだ `mzraftb` はチップ。水の流れ・さざなみ・氷・段をおちる水は、ゲームで描く。
- 霧：マスごと（`S.mz.clr`。晴れた所はもどらない）。`fogAt` が水のステージでは `mzMistAt` を見る。霧を見る所は `fogAt(j)` だけを書き、`S.fog&&` をつけない（つけると、水のステージの霧を見ない）。
- テストで水路を書くときは、神殿（まん中の水門のま南）と、はじめの木箱をよける（上にかさねると、神殿が消えて工事をたのめなくなる）。神殿を直したあとは、お礼の会話を読みおえるまで、せいれいが待っている。

## 闇のステージ（WORLD 6、`WD===YAMI`、`js/yami.js`）
- お話の設定は `STORY.md` の「さいごの章」、作る順番とまだきめていないことは `IDEAS.md`。水・土・風ができるまでは、マップえらびのとじたカードを5回タップでひらく。
- ずっと夜：時計・ねる時間（`isNight`）はほかのステージと同じ。空・光・音を時刻でかえる所を足したら、`hour()` でなく `skyHour()` を使う。
- はじめは、せいれいが0人。まもりの光が地面にとどくと、はじめの1回だけ、光のせいれいトモリが生まれる。
- 光の属性（`ELEM.light`）はトモリだけ：神殿では呼べない（`ELEM_KEYS` に入れない）・たたかわない・コワイノにねらわれない・たたかれない（さいごの夜の、むかえる〜ゆりかごへ、だけはねらわれる）・まわり4マスが歩くあかり。属性ごとの表を足したら、光でこわれないか（`表[r.elem]` をそのまま使っていないか）を見る。
- コワイノの来かた：トモリが生まれたときから来る。23時〜6時は、ほかのステージと同じ大きな群れ。6時〜23時は、時計の1時間ごとにコカゲが1〜2ひき。朝の光がないので、朝6時に消えない。追いはらうまでのこる。
- 依頼の会話のない目標になったかは `yamiAt`（`qAt` は依頼の会話を聞いたあと）。消したあかりは `recount` で `LIGHTS`・`LITP` からのぞき、つぎの朝6時にもどる。消せるのは、あけよい草のそばのあかり（つぼみのあいだ）と、さいごの夜のぜんぶ。
- 大きな影はたたかわない（`S.enemies` に入れない）。さいごの夜のトモリはたたかれてもおなかがへらず、3回か朝になったら、3日あとにやりなおし。
- トモリ・ゆりかごを直す子の行動は `decide0` のはじめの `yamiDecide` できめる。夜も歩く・待つのは `NIGHT_OK` に入れてある。クリアのあとは、空・暗さが、ほかのステージと同じ昼と夜。
- クリアした日の夜20時、ゆりかごから闇のせいれいツキミが生まれる（会話をさいごまで見てから）。闇の属性（`ELEM.dark`）はツキミだけ：神殿では呼べない・たたかわない。夜はねむらず、ねむるせいれいのそばにすわって見守り（家の中ではかくれる）、まわり `TKWR` マスでねむる子のつかれのとれる速さ `TKWK` 倍。朝はねむる。
- クリアのあと、追いはらったコワイノは夜のほうへかえる（白く止まる → ふりむいて北へ歩く → 紺にとけて、ドットの三日月がのこって消える）。会話でヒイロがいないときは、ヒイロの行だけはぶく（`ideaDialogue`）。
- テストの会話は自動プレイと同じ送り方 `DLGA`＋`#dlgBtns`。朝の日記の紙はとじる。タップで始める会話は `DLGTAP` を入れてから。

## まとめ（お話の流れは `MIZUBE.md`・`STORY.md`・コードの目標の表を見る）
- 水のお話は、前半（神殿 → 水門 → 水路 → ノミをむかえる → 食堂 → くだりくらべ）と後半（けんか → 仲なおり → キリノオオカゲ → 3つめの水門 → 夜明け → クリア `S.flags.mzEnd`）。場面は `wsScene`。
- 闇のお話は、あかり → ヒイロ → ヨリ → あさやけ → すわりこむトモリ → ゆりかご → あけよい草 → さいごの夜 → クリア。クリアした日の夜にツキミが生まれる。
- トモリ（光）・ツキミ（闇）の絵は `sp_light:*`・`sp_dark:*` と3Dの動き（`light_dark.py`）。`SPC.light`・`SPC.dark` は3Dの絵の色と同じにする。
