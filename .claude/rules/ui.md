# UI・画面の手ざわり

`CLAUDE.md` の決まりのつづき。ぶつかったら `CLAUDE.md` が先。数字（px・秒・こさ）はコードと `tools/ui/` が本物。たしかめは `tools/tests/` の `ui-*`・`touch-feel`・`book` など。

## 画面の見た目・ボタン・一覧
- できた印（✓）は 7×6ドットのチェック（1ドット2px）。32のアイコンを小さく出すと、にじむ。
- せいれいのふきだしはドット（1ドット＝ゲームの半分の点、段々の角、わく1ドット、45度の段々のしっぽ、整数ピクセルにそろえ、ふだんの拡大より大きくしない）。roundRect・円の丸いふきだしにしない。
- 会話ウィンドウは暗くしない。名前の左にアイコンを出さない。立ち絵（`#dlgPort`）がはみ出すので、わくは `.dlg::before` に描く（`.dlg` を clip-path で切ると立ち絵も切れる）。会話のわくは、どのステージも木のわく＋中は紙（`paper_ui.py`）。はみ出す物があるわくは同じ作りに。ムービーの暗転も濃くしすぎない。
- UIはドット風：
  - 字は PixelMplus10（ゲームで使う字だけの woff2 を `index.html` に。字をふやしたら、しぼりなおす。ファイル名は中身の sha1 の先10字。太字にしない）。
  - わくは、角が段々の SVG を 9スライスで `border-image`（fill）。背景の色ごとに絵が1まい（`index.html` の「わくの絵の色ごとの絵」。新しい色を足したら絵も足す）。SVG に width・height を書く（ないと角が大きくなる）。clip-path で切らない。わくのない四角（一覧の行・「目標」の札など）も同じ作り。
  - 丸い物（とじるボタン・タップの案内の輪・スキルの輪・カミサマの光など）は、段々のドットの丸の絵。新しいUIを足したら、角丸がのこっていないかブラウザでしらべる。`border-radius` はぜんぶ0。
  - アイコンは32×32のドット絵（`svg.pxi`）。線は2ドットの太さ（1つずつ描く。16×16を自動で細くすると形がくずれる）。画面のアイコンは、絵文字・色つきの絵にせず、ドットのアイコン（`PXI`、`js/ui.js`）。ボタンの中の記号（↻・‹ ›・♪ など）も字でなくドットのアイコン。
- パネル（下のシート・上の欄・下のバー・知らせ・ポップアップなど）のわくは紙。絵は `tools/ui/paper_ui.py` で作り、`index.html` の `paper-ui:begin`〜`end` に入れる（手で直さない。道具の関数を直して作りなおす）。新しいパネルは `PAPER_SEL` に足す。ボタンは紙にしない。
- 草原（WD 0）だけは、紙ではなく、わくのない切りっぱなしの明るい板（木目・ふちは切り口の色・下に板のあつみ）：
  - ボタン：ぷくっとふくらんだ木の板。おすとつぶれてへこみ、はなすとぽよんと戻る。下のバー（みる・おく・メニュー）はボタンにしない：なわの穴のある平らな木札（えらんだ札は字がこげ色・少し下がる）。丸いボタンは、すこしベベルした木の円柱。
  - 木目は CC0 の `tools/art/textures/wood049.png` をドットにした4つのこさ。字とアイコンは彫りこみ。ゲージも彫りこんだみぞ。字の下の札に色はつけない。
  - かざり：植物（つた・花）と金具はつけない（持ち主がきめた）。下のバーは、自然の板の横木から、なわでつるした木札。目標の札も上の欄からなわでつるす。タップでぶらんとゆれる。見出しと「目標」の札は焼き印（字の左右にかげをつけない）。
- 依頼ボード：木のわくのコルクに紙をピンでとめる。紙は右下の角がまるくそり返ったわく（9スライス）＋ CC0 の紙（`paper005.png`、そり返った角にはかけない）。ピンは白木の糸まき形（持ち主のお手本の写真から）。ささる所は紙の上。紙を mask で切らない（ピン・×まで切れる）。
- 図鑑と思い出帳は、めくる本（`js/book.js`）。ひでんのしょは巻物（`js/scroll.js`）で、タブ・見出し・項目にアイコン（まだ出会っていない項目には出さない）。思い出帳：はじめは目次、章ごとにページ。日記は1日1ページ。
- 本（`book.js`）：
  - ×でとじると、表紙までめくりもどしてから表紙がとじる。日記はひらいたとき表紙を出さない。たての画面は1ページ、よこ（はば720より広い）は見開き。表紙のときは左のページを出さない。
  - 表紙はかたい板：まげない・そらせない（上のふちだけもち上げると、ペラッとまがって見える。持ち主がきらう）。上と下のふちは、まっすぐ横のまま。中身を切らずに横にちぢめてまわす。板のあつみ（`BKTHK`）は、紙のたばと同じ右下へのずれで、まわるあいだも、とじたあとも下と右に描く。1ページの画面で90度をこえた所は、とじ目に立った板のあつみを見せる（何も出さないと、とちゅうで急に出てくる）。
  - めくる絵は、中身をちぢめずに切りとり、紙のうら・かげは1ドットのキャンバスにコマごとに描く。指でつまんでめくる・遠くはぱらぱら。見出し・日づけは、ななめのマスキングテープ（テープだけななめで、字はまっすぐ）。
  - ページはスクロールさせない：入らない分はつぎのページへ（節・一覧・リストは中もわける）。1ページの画面では、左のページをかくしてから、はばをはかる（先にはかると、はばが半分になる）。画面の大きさがかわったら、わけなおす。写真はページの高さにおさめ、あとで入る絵は先に場所をとる。ページの写しはキャンバスもうつす。写真の `blob:` は作りなおすまで手ばなさない。
  - 紙のたばは、のこりのわりあいで（色・すきま・とじ目でまるくしずむ・奥ほど暗い）。罫線は引かない。音は本物の録音（`tools/sound/ui_asmr.py`。とじる音は持ち主の音）。
- 巻物（`scroll.js`）：上下の軸はキャンバス、緑の無地の布の表装と金の帯。よむと軸がまわり、まいたあつみが上はふえ下はへる、ひもと房がゆれる。ひらくとまん中から上下へのびる。とじるときは、まきもどってから。
- ひでんのしょの図（`manfig.js`）：チップ・せいれい・コワイノをならべた小さな場面（1:1）。「あそびかた」の1つだけ（いらない所に入れない。持ち主がきめた）。
- 本と巻物の中だけ、金の角かざり（つる）・角の金具・見出しのリボンを使う。花の絵は入れない（持ち主がきめた）。ほかのUIには出さない。
- 持ち主がえらばなかった・ことわったUIの案は、もう出さない：時間・天気でUIの色や光がかわる・せいれいがUIのふちにいる・ちょうがとまる・植物のかざり・金具・手がきのゆらいだわく・角のかざり・リボンの見出し・指のカーソル・こい／黒いわく・紙のすじ・角のおれた紙・丸太の輪切りのボタン・芽つきの板・布のラベル・はめこみのキー。思い出帳のめくる出かた（`memBook`）は、たのまれたので使う。
- 草原の手ざわり：下のバーの木札は、ゆっくりゆれる（雨の日は大きく）。知らせは、なわでつるした木札で上からおりて上へひきあげる。上の数は、めくり数字のようにまわる。メニューの板は1まいずつ「とん、とん」。ゲージは、はちみつのようにのびて、さきが光ってゆれる。一覧をなでると、行ごとに木の歯車の「カラッ」。村レベルが上がると数に焼き印とけむり。下のシートをとじると、写しの板がうきあがって下へすべる（本物はすぐとじる。写しは本物のすぐあとなので、id でさがすと本物が先）。依頼ボードの新しい紙（ひらいてから新しくたのんだ物だけ）は、ぺたっと置かれてピンがささる。
- もどせない決定のボタン（データがきえる・うわがき・強化の道・かけらをささげる など。どのステージも）は `data-hold`：おしつづけると、こげ色がたまって「じゅっ」と決まる（タップでは決まらない）。
- たっせいのハンコ（`uiStamp`）：ふりあげて、ためて、ドン。とどいた瞬間に持ち主のハンコの「ぽんっ」・紙がゆれる・インクがとぶ。メインの目標をたっせいしたら、目標の札と「たっせい」の知らせに赤い「できた」。図鑑の物は白いふちのシールで、はじめて見たとき上からぺたっとはる。
- `input.js` ほか：地図をはやくはなすと少しすべって止まる（はしで止まる・うごきをへらす設定ではすべらない。すべり中のタップはタップにしない）。置く前の家具は、絵の上からドラッグするとマスごとについてくる（`notch`）。わざのボタンは、使えるようになるとはねて「ちりん」、使えないときにおすと左右にふるえる。タップしたせいれいは、ひまならこちらを向いてぴょん、仕事・遊びのとちゅうなら小さくうなずく。ピンチは、はしでも少しのび、はなすと `ZBACKS` 秒でもどる（`clampCam` はピンチ中ともどるあいだだけ、はしをこえてよい）。下のシートは、見出しを下へなでるととじる（本・巻物はのぞく）。コワイノの体力ゲージは、へった分が白くのこって少しおくれてちぢむ。足もとの作業のバーは、おわったら白く光ってはねて消える。
- ポップアップ（`.pxcard`・`.idea-card` など）は下から「にゅっ」。知らせは上から。
- `js/ui-fx.js`：上の数がふえたら、はねて光る。「しらべる」で地図をタップすると葉（火山は火の粉）。知らせにせいれいの顔。なにもない一覧には村のせいれい。読みこみ中は、せいれいが横向きに歩く。どれも1ドット（1.5px）ずつ steps で、うごきをへらす設定では止める。長おししたボタンは、もう1ドットしずみ、はなすと大きく「ぽよん」。±は長おしでだんだん速くくりかえす（はなしたときの1回はかぞえない）。シートを開くと行が1つずつ。一覧のはしで板がたわむ。ふるえは Android だけ（設定の「ふるえ」）。
- CSS の動き（`@keyframes`）は、`tools/ui/ui_motion.py` の `SRC` に、とおる所だけ書き、道具が1/60秒・1.5pxのコマにして `index.html` の `ui-motion:begin`〜`end` に入れる（手でなおさない）。使う側は `steps(1)`。
  - 手で書いた `@keyframes` と道具の動きに同じ名前をつけない（あとのほうがうわがきする）。くりかえす動きは、さいごのコマをはじめにもどし、ならびの切りかえは画面の外で。
  - とおる所だけを `steps(1)` でつなぐと、1コマで10px以上とんで、かくつく。コマは半コマあと（(i+0.5)/60）に書く。おくれ（`--ti` など）は1/60秒の倍数。1コマに1ドットくらいの動きは、かくついて見えるので、落ちる動きなどは1コマ2ドット以上。
- UIの色は `tools/ui/colors.md` の役目ごとの色（新しい役目は表に足す）。背景は1色（#f4e9d2）。ボタンは上 #f6ead0・下 #e6d2ab（えらんだ・大事は #a8743f。いくつもえらぶチップだけ黄色 `.chip.sel`）。ボタンはつやのある立体（こいふち・上半分が明るく下半分が少し暗い・上のふちに明るい線・下に2ドットの影・左上に白い光）。丸いボタンも同じ作り。新しいパネル・ボタンもこの色。
- 画面のはばでかわる字の大きさは、clamp・vw でなく、px を @media できりかえる（`index.html` の「画面のはばでかわる字の大きさ」）。
- おせない状態（強化できない・いちばん上など）はボタンでなく札（`.gst`）。
- パワー・素材・食料が足りないボタンは `disabled` にしない。`lackOn(ボタン,知らせ)` で、うすくして押せるようにし、何が足りないか短く知らせる。使いまわすボタン（`#cYes`）は、ほかの画面で `lackOn(b,'')` にもどす。
- ボタンをおすと、へこんだわくの絵にかわり、2ドット下がって影がきえる（どのボタンも）。下のバーのえらんでいるボタンも、こい色のへこんだわく。
- ボタンの字は、することのことば（「うえる」「もらう　パワー〇」）。「はい」「OK」だけにしない。知らせのカードは「とじる」、前の画面へは「もどる」（メニューの中の「もどる」は、見出しの左の小さなボタン）。
- たたんだ欄をタップして下に広げる出し方はしない（持ち主がきらい）。えらぶ物はポップアップで出す。
- 「おく」のしぼりこみ（一覧の上に1行の横スクロール）：すべて・さいきん（もらった順。こわした・もどした物は入れない）・タグ（依頼ボードと同じ）。道具・だんさは「すべて」だけ。なにもないときは、ひとことと「すべてを見る」。「おく」の「建てる」の欄は、素材を「持っている数/いる数」で1行ずつ（足りない物は赤）。
- 見守る（`follow.js`）：その子をカメラでゆっくり追う（行動はかえない）。ドラッグ・下の札・物語のカメラ・いなくなる・村の切りかえ・思い出帳の再生でおわる。
- 下のシートは、はば640まで（大きな画面ではまん中）。なにもない一覧は、小さなドットの絵とやさしいひとこと。もちものの見出しに、しまえる数を書かない（持ち主がきめた。しまう家具の画面のゲージで出す）。
- タップの案内でボタンをさすときは、指と文字をボタンの横（下のバーは上）に出し、ボタンの字をかくさない。会話の名前の札は属性の色のわく（カミサマは `pm-god`）。「つぎへ」には、うごく▼。
- 守り神の光・こもれびのまもりのボタンは、段々のドットの丸。ほかのUIと同じベージュ（草原も木にしない）で、うすく半透明（たまった所は濃いめ、たまっていない所は透明でわくだけ）、アイコンは下のバーと同じ色。砂時計と目標のわくは同じ高さ。
- 図鑑：マップごとに、スポット・家具・建物・レシピ・コワイノ・アイテムのタブ。見つけた・おぼえた物だけ（レシピ・家具・建物は、そのマップでおぼえた物と、置いた・持っている物。アイテムは一度でも持った素材・食べ物）。
- 作れる家具（`kind:'furn'`）は依頼ボードのタブ（`CRAFT_TABS`）に入れる（入れないと作れない）。依頼ボードで作らない家具（ガゼボ・東屋・湯のわき岩など）は、持っていれば「おく」の「そのほか」。
- 依頼ボードの「いま作れる」は、作る属性のせいれいが村にいるかも見る。依頼ボードには持っている数を書かず、作るリストに「木材（1/3）」（足りないと赤）。やすらぎの砂など箱の外の物も同じ。
- 下のバーの「もちもの」：素材・食べ物・おそなえ箱の物。上の素材・食料をタップしても開く。物をタップしたときのえらぶこと（置く・畑にまく・あげる・おたきあげ）は、ぜんぶポップアップ。「置く」をえらんだら、ウィンドウをとじて「おく」でえらんだときと同じにする。

## 知らせ・置いたときの動き・会話
- 知らせは、同じ文をまとめて数をつけ（「〜（3）」）、出すのは2つまで、のこりはまつ。大事な物（good・warn）は長め、ほかは短め。
- クエストのごほうびのパワーは `rewardPower(n)` でわたす。じかに `S.pt+=` して知らせを出さない。
- 置いたばかりの家具は、ぽんと着地。木と花は風でゆれ、雨の日は大きく。雨の日、外でじっとしている子は少しふるえる。ふきだしがとなりと重なるときは、あとの子のぶんを上へずらす。
- 村のようすに、つぎの村レベルでおぼえる物を出す（`learnedIn` と同じ決まり。おぼえた物・このステージで出ない物はのぞく）。
- 一度さいごまで見た会話（思い出帳はぜんぶ）にだけ「はやおくり」。早送りでも、動作の待ちとえらぶ場面は待つ。

## 字・小さなボタン・タイトル
- 上の欄は札（ふちなしのわく #e9d8b4）：1行め 時刻・天気、2行め パワー・せいれい・食料・素材・村レベル。食料・素材は数だけ（しまえる数のゲージは出さない）。
- 画面の字（`font-size`）は5の倍数のpx（10・15・20…）。11〜14pxなどは、2倍の画面でドットがずれて線の太さがふぞろいになる。キャンバスの字（`ctx.font`）はべつ。
- 小さなボタン・数の札のおせる所を広げるときは、中に `<hit-pad>`（48px）。パネルの中のならんだ小さなボタン（タブ・「？」など）には `<hit-pad>` を入れない（となりのタップをうばう）。何もない所をおしたら、おした所をふくむパネルの中で、いちばん近いボタンにする。
- 小さいドットの字に、ふちどりや左右のかげをつけない（にじむ）。かげは下に1つだけ。白い字・明るい字に、草原の彫りこみの明るいかげを受けつがせない。太字もつけない。タイトルの小さい字はこい緑、ボタンの字は白に下のこいかげ。
- タイトルとマップえらびの絵は、コードで描くドット絵（`index.html`。整数の四角で描き、pixelated で大きく）。タイトルは1秒に8回だけ描き、見えないときは描かない。データが読みこめたら、ゲームの絵だけ（地面・物・せいれい）で1マス64ドットの場面に描いて整数倍でうつす（空と雲だけコード）。物は文字・ボタンをよけて行ごとに。動かない物は行ごとの層に1回だけ描く。フタバはベンチに正面を向いてすわって寝ている。ほかの子は会えた子だけ、ゲームの動きをする。ステージごとの物は `TART`（`reach`・`clear`・`k`・`bg`）。新しいステージはここに足す。
- 数のマイナスは全角の「－」（U+FF0D）。「−」（U+2212）はフォントにないので使わない。
- `#topUI .htag` などに `display:…!important` を書くと、`[hidden]{display:none!important}` にかつ（細かさが上）。`hidden` で出し入れする物には `…[hidden]{display:none!important}` も書く。
