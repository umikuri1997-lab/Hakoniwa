# 天気・季節・手ざわり・日記

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。

## 虹
- 雨とあらしの見た目（`weather-fx.js`、見た目と音だけ・セーブしない）：雨つぶは奥・まん中・手前の3つの層のドット（`WXL`）、強さは村の時計で強くなったり弱くなったり（`wxRainK`）。あらしの日は突風（`wxGust`：雨がよこへたおれ、木が風下へかたむき `swayK`、葉・小枝がとぶ `wxLeaves`）とかみなり（`wxBolt`：画面が光り、ドットの稲妻、少しおくれて本物の録音のゴロゴロ `SAMPLES.thunder`、`tools/sound/thunder.py`。うごきをへらす設定では光をうすく）。雨のもや（画面のはしが白くかすむ）は `hdPost`、あらしの地面のつやは `feelRow`（ひし形の屋根のつやは、まだない）。
- 雨（雪・あらしもふくむ）の日、外のたき火は消える（`campOut`：あかり `LIGHTS`・`LITP` にも遊び場にもならない。絵は `campfire#off`）。料理もしない（`cook`・`cookS` のえらぶ所と `cook` の start）。家の中・ガゼボ・東屋の下はそのまま。
- 風の強い日（`S.today==='kaze'`）は、はたおり機で布1こが時計の27分（`PROC.loom.Tk`、時間は `prT`）。
- 冬は、池・川で水あびをしない（温泉・おふろ・露天ぶろはする。`goBathe` の `cold`）。
- 冬、火のせいれいが外の1マスに `FIRESTAY`（時計の20分）立つと、まわり2マスの雪がとける（`fireMeltTick`・`FIREMELT`。見た目だけ・つぎの朝6時にもどる）。
- 天気のよほう（`weather.js`）：雨・虹・あらし・その日のできごとは、2日先まで前もってきめる（`S.wxQ`・`wxRoll`・`wxFill`）。朝は `wxMorning` がそのとおりにする（前の日に天気をきめる所を足すときは `wxRoll` に。朝に Math.random できめない）。できごとの間（`pace.js`）のあらしの決まりも `wxRoll` の中（その朝がおだやかな日なら新しいあらしをきめない・しずかな日がつづいた日は `PACESTORM`。もうきめた日はかえない）。天気の札（`.htag.wxtag`）をタップすると、きょう・あした・あさって（`wxPop`）。たしかめは `tools/tests/weather.cjs`。
- 季節の料理：あたたかい料理（`ef.warm`）を食べた子は冬の寒さ（`seaWarm`）、つめたい料理（`ef.cool`）は夏の暑さ（`seaTired(r)`）が、時計の6時間とどかない（`r.warmT`・`r.coolT`）。どの料理かは `tools/cook/cook_table.py` の `seasonal`、表の外の料理は `FOODS` の `ef`。冬・夏は、箱からその季節の料理を先にとる（`seaFood`）。
- 虹：雨の日のつぎの日、50%で出る（よほうできめる。その日は雨にしない、`S.rbDay`・`rainbowToday`）。その日は、たのしさのへりかた0.5倍（`RB_FUN`）。空にドットの虹（`drawRainbow`）、日の欄は「虹」。草原・火山の両方。

## 時間・温度・質感の手ざわり
- `js/feel.js`：見た目と音だけ（数字はかえない。セーブは雨のつぎの朝の印 `S.wetD` と、つもった雪 `S.snowA`・`S.snowT` だけ）。絵は1マス64ドットのドット絵を1回作ってならべ（`feelArt`）、マスごとの出る・出ないはマスの番号から決める（`hash`。しまわない）。たしかめは `tools/tests/feel.cjs`。
  - 時間：窓と家のあかりは、家ごとにちがう時刻にともり・消える（`feelWin`）。晴れた昼の雲のかげ（`feelClouds`）と、葉のある木の落ち影の中の木もれ日（`komorebi`：落ち影のこい所の内がわに光のつぶ、チップごとに1回作る4コマ）。かげの色は青むらさき（落ち影 `castshadow.py`・足もとのかげ。日なたはあたたかく、かげは青く）。雪は、雪の日（`snowNow`）にふっているあいだだけ、だんだんつもり（`snowTick`・`SNOWUP`）、やむとゆっくりとける（冬 `SNOWMW`・ほかの季節 `SNOWMS`）。冬でも雪の日でなければ雪はふらない（`seasonN`）。つもると、はじめは雪のかたまりがちらばり、`SNOWFULL0` より多いと、地面（物の下・道の上も。家の中・床・畑・水はのぞく）・木と岩の上が、一面だんだん白くなる（`snowCover`・`feelRow` の `snowPat`・`feelCap` の `_thick`。ひし形の屋根には、まだ雪をのせていない。火のまわりはつもらない `FEELMELT`。神殿・見張り台のあかりでは、とけない `FEELNOMELT`。外に置いた家具・建物の上にも `feelCapOK`。こさはマスごとになめらかなノイズでずらして、つもるのもとけるのも、まだらに `snowCell`）、秋は木のまわりに落ち葉（`leafCover`）。夜あけの朝もや・朝つゆ。
  - 温度：白い息（冬と夜あけ、外で起きているせいれい）。火のあかりのゆらめき（`feelFlick`）。夏の昼のかげろう・セミ。冬、屋根をはずした家の中はあたたかい色（`feelWarm`）。ひまなせいれいは、冬は火に手をかざし、夏の昼は木かげ・水べにすわる（`feelRest`：`goWeather` から。すずむのは `sunset` の行動に `shade` の印）。
  - 質感：足音は足もとの材質ごと（`feelSurf`・`feelStepSnd`：画面のまん中に近い子と見守っている子だけ）。足もとの反応（浅瀬の波紋・土ぼこり・雪の足あと・草のかけら・ふんだ花がゆれる `feelKick`）。足もとからとぶ粒は材質ごとの表（`FEELKICKM`：数・何歩ごと・高さ・ひろがり・落ちる速さの上限・うしろへ流れる速さ。重さ `FEELKG` で山なり、雪はふわっと）。雨の日は水面の波紋・のきのしずく・地面のはね・水たまり（`puddleLv`：つぎの日の昼にかわく。形は地面のまま、たて:よこ＝0.8:1。冬はこおった氷の絵 `A.ice`）。夜（23時〜6時、`isNight`）、水たまりが見えているあいだは、せいれいもコワイノも、ふむとすべって止まる（`rainPud`・`rainSlip`。すべる水たまりの罠の半分 `RAINSLIP`。出てから、またふむと、またすべる）。場所の音（`feelAmb`：川・火・葉・セミ。カメラの近くにあるときだけ。その場で作る音）。
  - 地面の物は、物・せいれいより下に描く（`feelGround`）。高い段のマスは、段差の絵のあとに描く（`feelLifted`。先に描くと、上の面の絵にかくれる）。空気の物（息・もや・しずく・雲のかげ）は、夜の暗さより下（`feelAir`）。
  - 3Dから写した絵などの上のふちに雪をのせるときは、チップの絵の、列ごとのいちばん上のドットに白をのせる（切り立った横のふちにはのせない）。ゆれる木は、木と同じ変形の中で描く（`dropIn` の中）。

## 雑草・きのこ・枝・つり
- 毎朝（`weedMorning`）、マップを4×4の16エリア（1エリア27×27マス、`areaOf`）にわけて、エリアごとに生やす（ステージのはじめも同じ）：雑草3本（1エリアに20本まで、`WEEDDAY`・`WEEDMAX`）・ふんばり草3本（よみがえった土地、20本まで、`FUNDAY`・`FUNMAX`）・きのこ1本（木のそば、5本まで、`KINODAY`・`KINOMAX`）・枝5本（落とし物、木のまわり2マス、地面に10本まで、`EDADAY`・`EDAMAX`）。それにたして、植えた木（`tree`）1本ごとに25%で、まわり2マスに1本（`EDAP`。その木のまわりに、ひろわれていない枝があれば落とさない）。よみがえった土地は緑の草、荒れた土地は枯れた草（緑の草は生やさない）。あとで土地がよみがえったら、そこの枯れた草は緑の草にかわる（`recount`）。土地ごとに草がちがう（草原：しなやかな草・かさかさ草、火山：くるくる草・ちりちり草）。どのステージにも生えるふんばり草（オヒシバ、緑の草）。枝は木を切っても出ない。
- せいれいが雑草・きのこをとって箱へ（きのこは食べ物。おなか1。`weed`、`WEEDS`。しゃがんでひっぱって抜く動き。まわり10マス（風の子は15マス、`seekR`）以内の雑草・きのこがあれば、木を切る・石をほるより先にむしる。木材が10より少ないときは、木を切るのが先）。落ちている物は、せいれいのまわり10マス（風の子は15マス）で見つけたときだけひろいに行く。木を切る・石をほるより先（おつげの「木・石をあつめる」のときも。ふだんの仕事では、木材が10より少なければ木を切るのが先）（ヌシのかけらと、守り神の光でこわした物 `lt` はべつ：どこでも、おつげ・木を切る・石をほるより先にひろいに行く。畑の世話よりはあと。落ちる絵は、木材・石材・竹のアイコン）。風の子は、落とし物・ふしぎな種・きのこ・雑草・枝を、建てる・依頼のものづくり・植えるのつぎ（畑の世話・おつげ・木・石より先）にひろう（`goWork` の `r.elem==='wind'`）。「しらべる」で雑草・きのこ・落とし物（枝など）をタップすると、せいれいがとりにいく（どこでも。草・きのこ `S.wreq` は畑の世話より先（あとにすると、畑の多い村で、いつまでもとりに行かない）。落とし物の `tap` は守り神の光でこわした物と同じ順：畑の世話のあと）。しまう所（箱・箱）がなければ、タップしたときにそう知らせる。雑草の上には、物をそのまま置ける。
- 雑草の絵（`weed0g`〜`weed1k`・`weedc#0〜2`）は、もらった絵の明るさ1.3倍（色×1.3）。
- 雑草・きのこ・枝・空き缶の絵は、もらった絵（`weed0g`〜`weed1k`・`weedc#0〜2`・`kinoko#0〜2`・`drop:eda`・`drop:can`、g64。もらった絵を、前の絵のはば・高さの中にたて横の比をかえずにおさめ、下のはしとまん中を前の絵にそろえた（BOX でちぢめる）。枝（`drop:eda`）は3Dから写した絵（`tools/art/furn3d/items/nat_eda.py`、はば64。皮の色とかげは、草原の木の幹と同じ `tone5`））。きのこ（ベニテングタケ・シイタケ・ブナシメジ）とふんばり草（穂なし長い・短い・穂あり）は、場所で3しゅるいからえらぶ。素材のアイコンは、草（しなやかな草・かさかさ草・くるくる草・ちりちり草・ふんばり草）は、もらった草のアイコンの絵（`ICONS`、根のついた束）。きのこ・枝・空き缶は、マップと同じ絵。木材・石材・たねのふくろ（`ART.bag`）のアイコンも、もらった絵（草と同じタッチ）。たねのアイコンは、たねのふくろと、育つ作物の絵のセット（`seedIcon`）。
