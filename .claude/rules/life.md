# 天気・季節・手ざわり・日記

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。

## 虹
- 雨とあらしの見た目（`weather-fx.js`、見た目と音だけ・セーブしない）：雨つぶは奥・まん中・手前の3つの層のドット、強さは村の時計で強くなったり弱くなったり。あらしの日は突風（雨がよこへたおれ、木が風下へかたむき、葉・小枝がとぶ）とかみなり（画面が光り、ドットの稲妻、少しおくれて本物の録音のゴロゴロ、`tools/sound/thunder.py`。うごきをへらす設定では光をうすく）。雨のもや（画面のはしが白くかすむ）は `hdPost`、あらしの地面のつやは `feelRow`（ひし形の屋根のつやは、まだない）。
- 雨（雪・あらしもふくむ）の日、外のたき火は消える（あかりにも遊び場にもならない。絵は `campfire#off`）。料理もしない。家の中・ガゼボ・東屋の下はそのまま。
- 風の強い日は、はたおり機で布1こが時計の27分。
- 冬は、池・川で水あびをしない（温泉・おふろ・露天ぶろはする）。
- 冬、火のせいれいが外の1マスに時計の20分立つと、まわり2マスの雪がとける（見た目だけ・つぎの朝6時にもどる）。
- 天気のよほう（`weather.js`）：雨・虹・あらし・その日のできごとは、2日先まで前もってきめる。朝は `wxMorning` がそのとおりにする（前の日に天気をきめる所を足すときは `wxRoll` に。朝に Math.random できめない）。できごとの間（`pace.js`）のあらしの決まりも `wxRoll` の中（その朝がおだやかな日なら新しいあらしをきめない・しずかな日がつづいた日は `PACESTORM`。もうきめた日はかえない）。天気の札をタップすると、きょう・あした・あさって。たしかめは `tools/tests/weather.cjs`。
- 季節の料理：あたたかい料理を食べた子は冬の寒さ、つめたい料理は夏の暑さが、時計の6時間とどかない。どの料理かは `tools/cook/cook_table.py` の `seasonal`、表の外の料理は `FOODS` の `ef`。冬・夏は、箱からその季節の料理を先にとる。
- 虹：雨の日のつぎの日、50%で出る（よほうできめる。その日は雨にしない）。その日は、たのしさのへりかた0.5倍。空にドットの虹、日の欄は「虹」。草原・火山の両方。

## 時間・温度・質感の手ざわり
- `js/feel.js`：見た目と音だけ（数字はかえない。セーブは雨のつぎの朝の印と、つもった雪だけ）。絵は1マス64ドットのドット絵を1回作ってならべ、マスごとの出る・出ないはマスの番号から決める（しまわない）。たしかめは `tools/tests/feel.cjs`。
  - 時間：窓と家のあかりは、家ごとにちがう時刻にともり・消える。晴れた昼の雲のかげと、葉のある木の落ち影の中の木もれ日（落ち影のこい所の内がわに光のつぶ、チップごとに1回作る4コマ）。かげの色は青むらさき（落ち影 `castshadow.py`・足もとのかげ。日なたはあたたかく、かげは青く）。雪は、雪の日にふっているあいだだけ、だんだんつもり、やむとゆっくりとける（冬 `SNOWMW`・ほかの季節 `SNOWMS`）。冬でも雪の日でなければ雪はふらない。つもると、はじめは雪のかたまりがちらばり、`SNOWFULL0` より多いと、地面（物の下・道の上も。家の中・床・畑・水はのぞく）・木と岩の上が、一面だんだん白くなる（ひし形の屋根には、まだ雪をのせていない。火のまわりはつもらない。神殿・見張り台のあかりでは、とけない。外に置いた家具・建物の上にも。こさはマスごとになめらかなノイズでずらして、つもるのもとけるのも、まだらに）、秋は木のまわりに落ち葉。夜あけの朝もや・朝つゆ。
  - 温度：白い息（冬と夜あけ、外で起きているせいれい）。火のあかりのゆらめき。夏の昼のかげろう・セミ。冬、屋根をはずした家の中はあたたかい色。ひまなせいれいは、冬は火に手をかざし、夏の昼は木かげ・水べにすわる（すずむのは `sunset` の行動に `shade` の印）。
  - 質感：足音は足もとの材質ごと（画面のまん中に近い子と見守っている子だけ）。足もとの反応（浅瀬の波紋・土ぼこり・雪の足あと・草のかけら・ふんだ花がゆれる）。足もとからとぶ粒は材質ごとの表（数・何歩ごと・高さ・ひろがり・落ちる速さの上限・うしろへ流れる速さ。重さで山なり、雪はふわっと）。雨の日は水面の波紋・のきのしずく・地面のはね・水たまり（つぎの日の昼にかわく。形は地面のまま、たて:よこ＝0.8:1。冬はこおった氷の絵）。夜（23時〜6時）、水たまりが見えているあいだは、せいれいもコワイノも、ふむとすべって止まる（すべる水たまりの罠の半分。出てから、またふむと、またすべる）。場所の音（川・火・葉・セミ。カメラの近くにあるときだけ。その場で作る音）。
  - 地面の物は、物・せいれいより下に描く。高い段のマスは、段差の絵のあとに描く（先に描くと、上の面の絵にかくれる）。空気の物（息・もや・しずく・雲のかげ）は、夜の暗さより下。
  - 3Dから写した絵などの上のふちに雪をのせるときは、チップの絵の、列ごとのいちばん上のドットに白をのせる（切り立った横のふちにはのせない）。ゆれる木は、木と同じ変形の中で描く（`dropIn` の中）。

## 雑草・きのこ・枝・つり
- 毎朝、マップを4×4の16エリア（1エリア27×27マス）にわけて、エリアごとに生やす（ステージのはじめも同じ）：雑草3本（1エリアに20本まで）・ふんばり草3本（よみがえった土地、20本まで）・きのこ1本（木のそば、5本まで）・枝5本（落とし物、木のまわり2マス、地面に10本まで）。それにたして、植えた木1本ごとに25%で、まわり2マスに1本（その木のまわりに、ひろわれていない枝があれば落とさない）。よみがえった土地は緑の草、荒れた土地は枯れた草（緑の草は生やさない）。あとで土地がよみがえったら、そこの枯れた草は緑の草にかわる。土地ごとに草がちがう（草原：しなやかな草・かさかさ草、火山：くるくる草・ちりちり草）。どのステージにも生えるふんばり草（オヒシバ、緑の草）。枝は木を切っても出ない。
- せいれいが雑草・きのこをとって箱へ（きのこは食べ物。おなか1。しゃがんでひっぱって抜く動き。まわり10マス（風の子は15マス）以内の雑草・きのこがあれば、木を切る・石をほるより先にむしる。木材が10より少ないときは、木を切るのが先）。落ちている物は、せいれいのまわり10マス（風の子は15マス）で見つけたときだけひろいに行く。木を切る・石をほるより先（おつげの「木・石をあつめる」のときも。ふだんの仕事では、木材が10より少なければ木を切るのが先）（ヌシのかけらと、守り神の光でこわした物はべつ：どこでも、おつげ・木を切る・石をほるより先にひろいに行く。畑の世話よりはあと。落ちる絵は、木材・石材・竹のアイコン）。風の子は、落とし物・ふしぎな種・きのこ・雑草・枝を、建てる・依頼のものづくり・植えるのつぎ（畑の世話・おつげ・木・石より先）にひろう。「しらべる」で雑草・きのこ・落とし物（枝など）をタップすると、せいれいがとりにいく（どこでも。草・きのこは畑の世話より先（あとにすると、畑の多い村で、いつまでもとりに行かない）。落とし物は守り神の光でこわした物と同じ順：畑の世話のあと）。しまう所（箱・箱）がなければ、タップしたときにそう知らせる。雑草の上には、物をそのまま置ける。
- 雑草・きのこ・枝・空き缶の絵は、もらった絵（`weed0g`〜`weed1k`・`weedc#0〜2`・`kinoko#0〜2`・`drop:eda`・`drop:can`、g64。もらった絵を、前の絵のはば・高さの中にたて横の比をかえずにおさめ、下のはしとまん中を前の絵にそろえた（BOX でちぢめる）。雑草の絵（`weed0g`〜`weed1k`・`weedc#0〜2`）は、もらった絵の明るさ1.3倍（色×1.3）。枝（`drop:eda`）は3Dから写した絵（`tools/art/furn3d/items/nat_eda.py`、はば64。皮の色とかげは、草原の木の幹と同じ `tone5`））。きのこ（ベニテングタケ・シイタケ・ブナシメジ）とふんばり草（穂なし長い・短い・穂あり）は、場所で3しゅるいからえらぶ。素材のアイコンは、草（しなやかな草・かさかさ草・くるくる草・ちりちり草・ふんばり草）は、もらった草のアイコンの絵（根のついた束）。きのこ・枝・空き缶は、マップと同じ絵。木材・石材・たねのふくろのアイコンも、もらった絵（草と同じタッチ）。たねのアイコンは、たねのふくろと、育つ作物の絵のセット。
- 草・きのこのアイコン（持っている物・もちもの・作るリスト）は、その物の絵を使う。小麦などの絵文字を草のかわりに使わない（草は `ic:<素材>`、きのこは `obj:kinoko`、枝・空き缶は落ちているときと同じ絵 `chip:drop:eda`・`chip:drop:can`。ふきだしも同じ）。
- 素材：しなやかな草・かさかさ草・くるくる草・ちりちり草・ふんばり草（草の名前のまま、むしった草ごとに）・枝・空き缶（`MATN`）。きのこは食べ物（`FOODS`）。素材と箱の物を両方使う物は、`BL` の `food` に食べ物を書く（どくの罠のきのこ）。草原の草を使う家具は、火山では火山の草（`mat1`）。
- 「おたきあげ」：もちものの素材をタップすると出るメニューで、±で数をえらんでたのむと、せいれいが箱から神殿へもっていき、おたきあげしてパワーになる（`MATTRADE`：草5こ・木材・石材・竹・枝3こ・空き缶2こでパワー1。1回に持てる数ずつ運び、パワーにならないのこりはためる）。すてるボタンはない。
- ブリキのじょうろ（`joro`、空き缶2・枝1）：はじめて空き缶をつったら思いつく（「あたらしいレシピ！」の知らせ）。まわり5マスの畑の水やりの速さ+10%、住み心地+3。
- はじめてかさかさ草を手に入れたら、まるクッションを思いつく（ちりちり草では思いつかない）。しなやかな草（火山はくるくる草）は、ブランコ（4）・ひしがたラグ（6）・カーテン（5）で使う。枝は、たいまつ・たき火・ランプ・つむじ風の罠・木のスツール・道しるべ・木の矢で使う。くもラグはおそなえのまま。草あみのラグはなくした。もどさない。
- 草を使う修理は、どのステージにも生えるふんばり草で書く（ステージの草は `mat1` がないとほかのステージで作れない）。
- つり（`fishLoot`）：家具1%・空き缶30%・枝30%・地図の切れはし4%・ふしぎなふくろ2%・のこりは魚。乱数は `q` の1回でわける（ほかに Math.random をふやすと、テスト `stage-items.cjs` がこわれる）。どこでつっても同じ。つりのスポットは、つりに行く確率だけを上げる（12.5%、つり場 20%、つりスポット・よるづり場 1つで+10%）。せいれいがつりをえらぶ点数は10から。つりは、どの属性のせいれいもする（水のせいれいは点数+9で、えらびやすい）。
- めぶきのしずくは、カミサマからは買えない。大きなコワイノ（オオカゲなど `boss:1`）の落とし物25%。火山のおまつりの屋台はそのまま。
- コワイノの落とし物：家具0.5%・コワイノのレシピ0.1%。落とし物・つりで、家具を手に入れたときや、レシピをおぼえたとき（やすらぎの砂で石どうろう など）は、トーストだけにせず、「うけとった！」と同じ大きな知らせを出す。見出しはふつうの言い方（「ひろった！」「つりあげた！」「あたらしいレシピ！」。「めずらしい」などは足さない）。

## 手ざわり・まとまり・間（ポリッシュ）
- きのうの日記（`diary.js`）：朝6時から朝6時までの1日に、作業・できごと・追いはらったコワイノ（見張り台は上の子）を書き、朝に紙を出す（会話・画面が出ていれば知らせだけ）。朝の紙が出ているあいだの会話は、紙をとじてから出す。ゆうべの守りも日記の中。絵日記の文は、名前・アイコン・見出しをつけない。書くのは章のはじめからいる子（草原はフタバ・火山はホムラ、言いかたは `chatTone`）。文は、その日のいちばんの話題1つについて、はじめからおわりまでつながった通しの文（`js/diary-full.js` の `DYFULL`：話題ごとに12こいじょう。小分けの文をつなげない。持ち主がきめた。`DYOPEN`・`DYBODY`・`DYCLOSE` は、`DYFULL` にない話題のときだけ）は、フタバの話しかた（「わあ」「えへへ」「〜んだ」「〜だよ！」）の子どもの絵日記のように書き、かたい言葉（「ありがたい」など）は使わない。絵を写した日は、はじめのできごとを絵の物の文にする。ただし、大きなできごと（オオカゲを追いはらった・負けた・試練・新しいなかま・いなくなった・イベント）のある日は、そちらを書く（ふだんのことを書かない。持ち主がきめた）。その子が村にいない朝は、文も絵ものせない。ひとことの文は、しゅるいごとに、ぜんぶ使うまで同じ文を出さず、できた文がまったく同じ日記は作らない。文は、しゅるいの中にうしろに足すだけ。日記の文は、書く物に合う文だけ（「なでた」「さわった」「におい」「どっしり」「食べる」「土」などのことばと、物のしゅるい。火・罠・道や壁・かざり・飲み物・花・虫など）。文を足したら、物によっておかしくならないか、`DYRULE` にも足す。ゆうべのかつやく：追いはらった数＋守った数（助けてにげる・こもれびのまもり）が2点いじょうでいちばんの子（おなじ点なら追いはらった数）を、日記のいちばん上に絵と「かつやく」のハンコで出し、たのしさ+10・思い出帳（`memo()` だと、つぎの日の日記にも入るので `S.memo` にじかに）。日記の紙も、思い出帳と同じ本（`book.js` の `bookMake`）：1ページめは、思い出帳のその日のページと同じ絵日記（日づけのテープ・天気・テープではった絵・その下に、けい線の紙の文。絵と文は1ページに入れる：入らなければ絵をちぢめる。できごと・ゆうべのひとことは、入らなければつぎのページ）。朝の日記の文は、書いているように1字ずつ出し、そのあいだ持ち主の書く音（10秒の録音）をくりかえして鳴らす（タップでさいごまで）。めくると、点のページ（かつやく・ゆうべの守り・きのうのしごと。数え上げ・ハンコは、そのページを見せたとき。点のページが2ページいじょうにわかれたら、わかれたページごとに見せたときに数え、数えおわったら自動でつぎへめくる。見えていないページでは数えない・書かない・音を出さない）、そのあと追いはらったせいれい・みんなのしたこと。思い出帳には1日1ページ。たしかめは `tools/tests/diary.cjs`。
- べつのカメラで村を描きたいとき（写真など）は、`render` をそのカメラで1回よんで写しとり、同じコマのうちにもとのカメラで `render` しなおす（画面には出ない）。HD-2D のにじみのもとは、そのたびに作りなおす（のこすと、ちがう所のにじみがかさなる）。シートの中の `blob:` の絵は、とじるときの写しの板（`sheetGhost`）も読むので、読みこんだらすぐ手ばなさない。
- 村の名前・村の写真（`photo.js`）：村の名前は、フォントにある字（ひらがな・カタカナ・英数字・ー・・）だけで8字まで（日本語の変換中はけずらない）。村のようすでつけ、マップえらび・写真に出す。写真（日記の絵）は、手では写さない。その日いちばん心にのこった物を、その場所に近よって自動で写す。昼だけ。大事さ：はじめてできたスポット＞できた家具・建物＞新しいなかま＞書く子が見にいった物・夕焼け・生き物・ひとりのしぐさ＞夕方まで何もなかった日の書く子のまわり。その日の絵より大事なときだけ写しなおし、前の絵はけす。書く子がいなければ写さない。村ぜんたいは写さない（持ち主がきめた）。同じコマで写す所を描いて写しとり、すぐもとのカメラで描きなおす（画面のカメラはうごかない。数の文字・矢の数・置く前のわくは写さない）。長い辺480にちぢめた JPEG を、セーブではなく IndexedDB（`hakoniwa-photo`）に、ステージごとに30まいまで（いっぱいなら古いのからけす）。思い出帳の「村の写真」は見る・けすだけ。たしかめは `tools/tests/photo.cjs`。
- こよみ（`calendar.js`、メニューの「こよみ」）：今日から10日ぶんに、もう決まっている予定だけ出す（夕方にきまる夜の変化・虹は出さない）。オオカゲの夜は、目標の欄の `bossDays` と同じ計算。決まった予定を足したら `calEvents` と `tools/tests/calendar.cjs` にも足す。
