# ステージでかぎられた仕組み（コードはあるが、出ない所がある）

ある物が、そのステージで出るか・手に入るかを言う前・クエストに入れる前に読む。
- おまつり（屋台・ちょうちん・りんごあめ など）は火山だけ（`festOn` の `WD===1`、「おまつりをひらこう」のあと）。草原にはない。
- かまど（`oven`）は火山から（`w:1`。火山ははじめからもらう）。草原では、おぼえない・作れない（古い台所のあとの、こわれたかまどだけ。前のセーブで使っていなければわすれる `S.flags.ovenW1`）。草原のクエストに、かまどを使う物を入れない。
- すべり台・シーソーは風のステージだけ（`WIND_STAGE_TOYS`）。のれんは火山から。
- なくした仕組み（`VGIFT`・2階建て・倉庫・よぞらの窓・アーチ門・石の柵・村レベル14のご神木 `shinboku`（古いセーブは `S.flags.shinGone1` で、けしてパワー160・木材40をもどす））は、それぞれの所に書いてある。のこったコードは、古いセーブの読みかえのため。
- 草原（ステージ1）は洋風。草原で使う物の絵・プロンプトは洋風にする（しめなわ・鳥居など和風の物を入れない）。
- 和風の物（石どうろう・ふうりん・えまかけ・こまいぬ・ちょうちん・かどまつ・のれん・行燈・竹の物など）は火山からの物（`BL` の `w:1`）。草原では、おぼえない・買えない（石どうろうは、火山でやすらぎの砂をはじめてしまったとき。カミサマのかざりは火山だけ）。
