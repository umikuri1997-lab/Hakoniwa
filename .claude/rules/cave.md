# 洞窟の探検

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。数字は `cave.js` のはじめの表（実数）が本物。たしかめは `tools/tests/cave*.cjs`。

## 洞窟の探検
- 洞窟（`js/cave.js`）：土のステージの核。土のステージでは巣穴をタップして入る（ほかのステージは、設定の「テスト用」の「洞窟へ」。きまった案は `IDEAS.md`）。土のステージの彫り絵・岩の山は `tsuchi.md`。村は止めたまま、洞窟だけを動かして描く。村の `S` は入れかえない。
- 洞窟のマスは、村のマップの外（y が `H` より下）。洞窟の中の場所は、せいれい・コワイノとも、この座標で持つ（`drawEnemy`・`hitFx`・`fxSpr`・`sfxAt` がそのまま使える）。
- パーティは村のせいれいそのもの（おなかは本物がへる）。場所・道・指示だけ、洞窟の中の物で持つ。食べ物は、食べたときに村の分をへらす。ひろった物は、帰ったときにわたす。
- たたかいの数字は村と同じ（攻撃力・`SORTIE`・`EN` の `hitF`・`hitN`・まもりの光の `GUP`）。まもりの光のしくみ（ため・音・まとめてたおすと早くたまる）は、村に足したら洞窟（`caveLight`・`cvLightHit`）にも足す（洞窟だけ外さない。持ち主がきめた）。洞窟だけの数字（歩く速さ・見える広さ・門の時間・ひろえる数）は `cave.js` のはじめの表に実数で書く。
- 属性の道は、わき道だけに置く。入口から下へおりる坂（`R`）までは、どのパーティでも行けるようにする。
- 属性の道は、5つとも、することがちがう（同じ「タップして待つ」にしない。持ち主がきめた）：土 岩をおす向きをえらぶ（くぼみ `h` にはめる）・火 消えるたいまつをともして回り、ぜんぶともると石のとびらがひらく（ひらいたまま：しまると、中のせいれいが出られなくなる）・水 2つの水門の片方だけ（みぞを1マスずつ流れる）・風 風車のまっすぐ先に立たせる・木 足場の葉を3まい置く。新しい属性の道を足すときも、ちがう遊びにする。
- 洞窟のたたかい：光をしぼると、見える広さも、ねているコワイノが起きる広さも小さくなる。ねているコワイノへのはじめの一撃は `CVAMBUSH` をたす。コワイノどうしは同じマスに入らない。
- 部屋のできごと：ひびの床 `q`（せいれいが通りすぎるとくずれる。かならず、まわり道を作る）・うすい壁 `W`（まもりの光でくずれる）・岩の落ちてくる所 `!`（コワイノにも当たる）。
- 洞窟のごほうび：化石（石のかたまりから1つ。図鑑の「かせき」、そろえるとパワー `CVFOSALL`）と、洞窟だけの家具（古いカンテラ `oldlantern`・ほりだした土器 `doki`。`chest`・`shopOnly` でレシピにしない。はじめの1回だけ、2回めからはパワー `CVAGAIN`）。村で手に入る物（石材・木材）は、洞窟のごほうびにしない。
- 洞窟にいるあいだも村は動く（持ち主がきめた。いつでも出かけられ、夜も洞窟にいられる。夜は村にいるせいれいだけでまもる）。つれていったせいれいは `S.res` から出して `S.cvAway`（`cvAwayOut`・`cvAwayBack`。セーブでは `res` にもどす）。main.js が村の `stepWorld` をうしろで動かすあいだは `VBG`：会話は `DLGLATER` にためて、もどってから出す・音と知らせは出さない・村のカメラの動きはすぐおわらせる・オオカゲの登場の見せ場はしない・画面のあいた時の村の処理（`tsTick` など）は止める。大事なこと（夜・朝・コワイノが来た・こわされた・村で消えた）だけ、洞窟の画面に知らせる（`cvVBack`）。`C.t` は洞窟の中だけの時計。洞窟の中から村の `stepWorld` をよばない。
- 4階から下は、いるだけでおなかがへる（`CVDEEP`）。
- 8階（異形の培養室 `js/cave-baiyou.js`）：ガラスの入れ物は、床のマスにのる、歩けない・見とおせる物（`C.g=1` の物 U・Q。中にためしのからだ `e.gj`）。U はふち道をふさぎ、まもりの光でわれる（`cvLightHit`）。Q は見るだけで、火のせいれいが `CVTAMER` マスまで近づくとわれる。入れ物の中のバケモノは、われるまで目をさまさず、ねらわれない（`cvGlassOn`）。ふさぐ入れ物は `tools/cave/cave_maps.py` の `check(glass=False)` で、わらないと坂へ行けないことをたしかめる。名ふだ（K）は、ならびのはしの1つだけちがう字。
- 9階（失敗した神の墓場 `js/cave-hakaba.js`）：大穴の中の島（坂）へ、ほねの橋（地図の V・はじめは大穴）。まもりの光でほねにとどめをさすたびに（`e.byLight`。`cvDefeat` から `cvHoneLight`）、西から3つに分けて1つずつかかる（`S.flags.cvHoneN`）。ほねは橋に要る数より多く置く。橋なしで坂へ行けないことは `check(bone=False)` でたしかめる。
- 10階（神の創造炉 `js/cave-ro.js`）：下へおりる坂はない（`check` は坂なしでも通る）。炉にくべられたもの（`bk_ro`）の通ったあとがあつくなる。まん中の島の失敗した神 N は見るだけ（トトの場面は `tsuchi-oku.js`。大きなあなぐまと根は `cvShadeDraw` のあとの `tsOkuShade`）。炉から谷の上へのびるひびは、北のはしまでの大穴。
- 洞窟の階：下へおりる坂のそばまで来ると、その階はクリアで、つぎの階がひらく（光の柱と「ひらいた」の知らせ）。出かけるときに、ひらいた階からえらぶ。階を足すときは `CVFLOORS` に、地図（`map`）・高さ（`lv`）・宝箱（`chest`）を足し、1階とちがうしかけの組み合わせにする。
- 洞窟の階は10（`STORY.md`）。`CVFLOORS` は10こ、ぜんぶ地図がある（地図のない階は `null` で、行けるのは、はじめの `null` の手前まで `cvFlOpen`）。階ごとのバケモノ `CVBKFL`・道具 `CVREL` は、階の番号のならび。すべる氷・溶岩・ふきだす溶岩・あつい床のマス・ゆらぐ岩の橋は、けした（持ち主がきめた。新しい階には、新しいしかけを作る）。
- 村を切りかえるときは `caveAbort`（`resetVillageTransient`）。会話・ポップアップ・レベルアップの画面のあいだは、洞窟も止める。

## まとめ（細かい作り方は `tools/cave/`・`tools/art/cave/` とコードを見る）
- 洞窟の地図（`CVFLOORS`）は `tools/cave/cave_maps.py` で作り、`--write` で書きこむ（手でなおさない）。まるい空洞とくねった道で作る（四角い部屋にしない）。高い所から低い所へはとびおりられ、のぼるのは坂（`^`）から。どこからでも入口か坂へもどれること、しかけを通らないと坂へ行けないことを道具で確かめる。大穴（`O`）は4階から。
- 洞窟の敵はコワイノでなく洞窟だけのバケモノ（`cave-bake.js`）。たおせないこわい物には、かならずよけ方を作る。絵は、骨を入れて写したチップ `bk<名前>#<コマ>`（チップがないときはコードの仮の絵）。
- 洞窟の絵は村の段差と同じクォータービューのマス（`iso-cave.js`・`iso-cave2.js`）。洞窟の中では村の環境音を止める。洞窟のタップは、パーティが歩いて行けるマスならそこへ、行けなければ近い行けるマスへ。
