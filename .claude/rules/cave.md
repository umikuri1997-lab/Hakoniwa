# 洞窟の探検

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。

## 洞窟の探検
- 洞窟（`js/cave.js`）：土のステージの核。いまは、設定の「テスト用」の「洞窟へ」から入る（きまった案は `IDEAS.md`）。村は止めたまま、洞窟だけを動かして描く。村の `S` は入れかえない。
- 洞窟のマスは、村のマップの外（y が `H` より下）。村のマスを見る共通の描き方が、何もない所を見るようにするため。洞窟の中の場所は、せいれい・コワイノとも、この座標で持つ（`drawEnemy`・`hitFx`・`fxSpr`・`sfxAt` がそのまま使える）。
- パーティは村のせいれいそのもの（おなかは本物がへる）。場所・道・指示だけ、洞窟の中の物で持つ。食べ物は、食べたときに村の分をへらす。ひろった物は、帰ったときにわたす。
- たたかいの数字は村と同じ（攻撃力・`SORTIE`・`EN` の `hitF`・`hitN`・まもりの光の `GUP`）。洞窟だけの数字（歩く速さ・見える広さ・門の時間・ひろえる数）は `cave.js` のはじめの表に実数で書く。
- 属性の道は、わき道だけに置く。入口から下へおりる坂（`R`）までは、どのパーティでも行けるようにする（たしかめは `tools/tests/cave.cjs`）。
- 属性の道は、5つとも、することがちがう（同じ「タップして待つ」にしない。持ち主がきめた）：土 岩をおす向きをえらぶ（くぼみ `h` にはめる）・火 消えるたいまつをともして回り、ぜんぶともると石のとびらがひらく（ひらいたまま：しまると、中のせいれいが出られなくなる）・水 2つの水門の片方だけ（みぞを1マスずつ流れる）・風 風車のまっすぐ先に立たせる・木 足場の葉を3まい置く。新しい属性の道を足すときも、ちがう遊びにする。
- 洞窟のたたかい：光をしぼると、見える広さも、ねているコワイノが起きる広さも小さくなる。ねているコワイノへのはじめの一撃は `CVAMBUSH` をたす。コワイノどうしは同じマスに入らない。
- 部屋のできごと：ひびの床 `q`（せいれいが通りすぎるとくずれる。かならず、まわり道を作る）・うすい壁 `W`（まもりの光でくずれる）・岩の落ちてくる所 `!`（コワイノにも当たる）。
- 洞窟のごほうび：化石（石のかたまりから1つ。図鑑の「かせき」、そろえるとパワー `CVFOSALL`）と、洞窟だけの家具（古いカンテラ `oldlantern`：家の中に置くあかり・ほりだした土器 `doki`：かざり。`chest`・`shopOnly` でレシピにしない。はじめの1回だけ、2回めからはパワー `CVAGAIN`）。村で手に入る物（石材・木材）は、洞窟のごほうびにしない。
- 洞窟にいた時間（`C.t`、`S.t` と同じ単位）は、出たときに村を進める（`stepWorld` を回す。夜20時まで。つれていったせいれいは止める）。洞窟の中から村の `stepWorld` をよばない。
- 洞窟の階：下へおりる坂のそばまで来ると、その階はクリアで、つぎの階がひらく（光の柱と「ひらいた」の知らせ）。出かけるときに、ひらいた階からえらぶ。階を足すときは `CVFLOORS` に、地図（`map`）・高さ（`lv`）・宝箱（`chest`）を足し、1階とちがうしかけの組み合わせにする。
- 氷の階：すべる氷は、道さがしで、ぶつかるまですべる（とちゅうで止まれない。止まる所の一覧 `cvBfsRing` にも入れない）。マグマの階の溶岩は、地底の水（`C.wt`）をマグマの色で描いた物。冷やすと `C.wt` をけす（タイルは毎コマ、地図から描く）。
- 洞窟の地図（`CVFLOORS`、56×44）は `tools/cave/cave_maps.py` で作り、`--write` で書きこむ（手でなおさない）。階は7つで、`STORY.md` の神をつくる仕事のじゅん（ねっこ・水晶・みずうみ・氷・化石・マグマ・ゆりかごのへや）。さいごの階のほかは、まん中の大穴（`O`：歩けない・見とおせる）のまわりを、北から南へおりていく（持ち主のたのみ：メイドインアビスのように）。おり方は階ごとにかえる（ふちをぐるっと・水晶の橋・滝の上を島づたい・大穴にはった氷をすべる・ほねの橋・かべの山道をじぐざぐ・底の施設）。ふち道を切って、そのおり方を通らないと坂へ行けないようにする。大穴の上の橋 `X`・氷 `J` は、床のマスで、橋は板の色のタイル。手がかりの物 `K` は、せいれいが読めない人間の字ではなく、形で伝える（ならびのはしの1つだけちがう）。しかけの部屋はハンコで置き、道具がつながり（入口→坂・どこからでももどれる・物のとなりに立てる）をたしかめる。大穴は `CVQAB` だん低い穴で、うしろのマスのかべが底まで下へのび、下ほど暗い。大穴の底の遠くの岩だな・もや・ちりと、暗さの上の底のあかりは、底のひし形の中だけ（`js/iso-cave2.js`）。大穴のとなりのマスに、かべぎわのかざり・つらら石・光る鉱石をおかない。テストは場所の数字でなく、物のしゅるいでさがす（`tools/tests/cave.cjs`）。
- 洞窟の地図は、まるい空洞とくねった道で作る（四角い部屋にしない）。高さ：高い所から低い所へはとびおりられ、のぼるのは坂（`^`）からだけ（コワイノも同じ）。がけの正面が見えるのは、高い所が北のときだけなので、おりていく向きは南にする。作ったら、どこからでも入口か坂へもどれること（とびおりた先で、とじこめられない）をたしかめる（`tools/tests/cave.cjs`）。地底の水（`~`）は歩けない・岩もおせない。
- 洞窟の地面のまだら（`Ms`）は、どの階もコケの所くらい植物をびっしり（持ち主のたのみ）。地面は階らしいテクスチャ（コケ `cave:moss`・霜 `cave:frost`・溶岩のかさぶた `cave:ash`・小石 `cave:pebble`）と、その階の植物（`cave:plant#26〜31` マグマ・`#32〜37` 氷）。溶岩（`cave:lava`）は、暗さの上で光らせる。
- 洞窟の暗さと光：光のとどかない所は `CVDARK`（暗すぎると、なにがあるかわからない）。守り神の光はゆっくりゆらぐ。光るきのこ（`g`）・光る鉱石（正面の見える岩）は、そのまわりだけ明るく、まだ見ていない所でも `CVLURE` マスまで、ぼんやり見える。しずくは見た目と音だけ。
- 洞窟の音：洞窟の中では村の環境音を止め、洞窟の空気の音だけ。効果音にこだま。しずく・足音は石の足音の録音。音は CC0 の録音（`tools/sound/cave_amb.py`）。
- 洞窟の絵（`js/iso-cave.js`）：村の段差と同じ、ふつうのクォータービューのマス（持ち主がえらんだ）。床は、その段の高さのひし形のタイル、岩のかべは床より1だん高いブロック。手前のとなりが低い所だけ、1だんずつかべのタイル。描く順は x+y、まわりより低くない平らな床は先に。坂 `^` は村の階段の形。タイルは、こさの番号のテクスチャにその階の色をぬって作り、とっておく（出たら手ばなす）。物・せいれい・コワイノは足もとで立てる、地面にはりつく物は地面にはる。見ていないマスは描かない。水・橋・滝・岩の正面のかざり・小石・しずく（落ちた音も）・水のうつりこみは `js/iso-cave2.js`（マスごとの物は、描く順の一覧に入れる）。タップは見えている高い段のマス。絵はチップ `cave:〜`（3Dから写した物は `tools/art/furn3d/items/cave_*.py`、帯と床は `tools/art/cave/cave_tex.py`）。
- 洞窟の敵は、コワイノではなく洞窟だけのバケモノ（`js/cave-bake.js`）。階ごとのたたかえるバケモノ（`EN` に入れて村と同じたたかいの数字）と、たおせない4つのこわい物（声のこだま1階から・見はりの目2階から・えさ3階から・ほりつづける手4階から、大穴のある階だけ）。こわい物には、かならずよけ方（光をしぼる・まもりの光）を作る。数字は `cave-bake.js` のはじめに実数で書く。絵は、持ち主が色をつけたトリポのモデル（`tools/art/models/cave/bk_*.glb`。テクスチャを点の色にして切りわけた物。色はそのまま）に骨を入れて（`bake_rig.py`：リギングのスキルの決まりで、親子の骨・関節はからだのまがる所（断面をはかって置く）・重みは Blender のボーンヒート（`heat/<名前>.npz`）を使い、ないときだけメッシュの面の上の道のりで、4本まで合計1・UV のつなぎ目で同じ場所の点は同じ重み・部品でできた体は部品ごと。光すいは、かさののびちぢみと4本の足のくさり、夜の水は、まん中の柱のくさりと4つのへり。ひと形はもも・すね・上うで・下うで・背骨・頭、えさは耳・あご・頭・せなか、ほる手は手首と3つのふしの指）ポーズをつけて写したチップ `bk<名前>#<コマ>`（`tools/art/cave/bake_rig.py`・`bake_build.py --chips`。止まる0・1／歩く w0〜w3／たたく a0・a1、左むきは反転）。チップがないときは、コードの仮の絵。たしかめは `tools/tests/cave-bake.cjs`（`cave.cjs` は、こわい物を止めてたしかめる）。
- むかしの道具（`js/cave-relic.js`：階ごとに1つ。家具は `BL` の `rel_<k>`（`relic:1`・`chest`・`shopOnly`）、絵は3D `tools/art/furn3d/items/rel_*.py`）：手がかりの物（`K`、さいごの階はゆりかご `Y`）をしらべると、せいれいのひとこと（形のことだけ。人の字は読めない）と、その階の道具。見つけた道具は、村の家具・図鑑の「むかしの道具」・洞窟でのふしぎな力（岩をおす速さ・光すい・わかれない・声のこだま・化石・あつい床・えさ）。図鑑の「バケモノ」は、会ったバケモノとこわい物。たしかめは `tools/tests/cave-relic.cjs`。
- 洞窟のタップで歩く先：暗い所でも、パーティが歩いて行けるマスならそこへ（歩きながら見える所を明るくする）。行けなければ、タップから `CVTAPR` マスまでの、いちばん近い行けるマス。それもなければ「そこへは行けません」。見えている所だけをえらぶと、まわり4マスしか進めない。ドラッグ・ピンチで見回したあと `CVLOOKMS` は、カメラがパーティを追わない（タップでもどる）。
- 村を切りかえるときは `caveAbort`（`resetVillageTransient`）。会話・ポップアップ・レベルアップの画面のあいだは、洞窟も止める。
