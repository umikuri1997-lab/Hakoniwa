# せいれいのくらし・仕事・遊び

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。

## おなか
- 草原のはじめ（フリーモードでない・WD===0）は、ベッドの目標（`bed`）がおわるまで（村にベッドが1つもないあいだ）、おなか・たのしさ・つかれが進まない（`preBedCalm`）。
- おなかの最大は、レベル1で500（火の子は1000、`HMAX1`・`HMAX1F`。持ち主のたのみで前の半分、ほかのおなかの数もぜんぶ半分にしてバランスはそのまま。古いセーブは `hun2Mig`・`S.flags.hun2`）。レベルが上がるたびに100〜750ふえる（`hMax`、せいれいとレベルごとにばらつく。`lvGain` と同じく id とレベルから決まるので、しまわない）。
- 火の子が受けるダメージ（おなか）は、コワイノの表の `hitF`・`hitFS`（となりで戦っているとき）と `hitFN`・`hitFNS`（はなれているとき）。ほかの子は `hitN`・`hitNS`。
- ごはんに行く前に、持っている素材をしまう（そばにコワイノがいるときは、そのまま食べにいく。`goEat`）。
- せいれいは、おなかが250より少なくなったら、どんなときも（仕事・遊び・ねている・夜の戦い中でも）食べにいく。コワイノがそばにいるときは、安全に行ける箱へ（`goEatSafe`）。火の子も250より少なくなったら、戦いをやめてにげる。

## なかまを呼ぶ
- あたらしい子の名前は `NAMES` から。使いきったら、うしろに数をつける。キーキャラの名前（フタバ2など）は使わない。
- なかまを呼ぶのにいる力（`needFor`）は、いる子の数に、いなくなったキーキャラ（`S.buried`・`S.lost`）も数えて決める（キーキャラが死んでも、いる力は下がらない）。めぶきのしずくでよみがえらせるときも、その属性の力がたまっていないとだめ（`reviveNeed`）。
- ホノ（草原の火のキーキャラ）は、あにき（おれ）だけ。会話にあねご／あにきの2つの言い方（`{A,B}`）を書かない。
- 名前をつける（`nick.js`）：なかまが来たときの紹介の画面（`NEWRES`）でだけ、名前をかえられる（章のはじめの子・もどってきた子はのぞく）。ふつうの子は `r.name` をかえる。お話の子（ノドカ・ホノ・アオ・フウ・シズク、`NKFIX`）は `r.name` をかえず、画面に出す名前だけ `S.nick` でかえる（会話は `dlgSpeak` の `nickTx`、ほかの画面の文字は `nickWatch`）。お話の子の名前でしくみを見分ける所は、もとの名前のまま。お話の子のもとの名前をふくむ名前はつけられない（おきかえが2回かかる）。たしかめは `tools/tests/nick.cjs`。
- なかまを呼べるのは1日に1回だけ。神殿の「！」で呼ぶ・お墓からよみがえらせる・めぶきのしずくでよみがえらせる、どれも1回に数える（`calledToday`：`S.summonDay`・`S.mebukiDay`）。1日は朝6時から朝6時まで（`callDay`。夜中の0時ではかわらない）。呼んだ日は、神殿の「！」も出さない（タップもできない）。

## おつげ
- はじめにえらべるおつげは、木・石・食料だけ。ほかのおつげ（いっぱいあそぶ など）は、水のステージでおぼえる（`ORACLE` の `water`、`S.flags.oracleWater`）。

## 畑の仕事
- 収穫は、木のせいれいがいれば木のせいれいだけ。水やりは、水のせいれいがいれば水のせいれいだけ（木の子の世話の水やり `tend` はしない）（`canJob`）。
- 水やりは、水をくんでから（`draw`・`waterSrc`）：池・川の水・井戸（いくらでも）・みずがめ（雨の日に畑10マスぶんたまる `JARS`・`S.dyn[j].w`）。1回くむと、持てる数1ごとに畑5マス（`r.wcan`・`WCANK`）。井戸・みずがめに、まわりの畑を水やりなしにする効果はない。みずがめには効果範囲の表示を出さない。
- 花：まわり3マスで、たのしさ+0.2／1時間（`ENVG` に 0.56）、花と同じ属性のせいれいは+0.6／1時間（`ENVE[属性]` に 1.11 をたす）。芽のあいだは効果なし。
- コンポスター（`composter`、木材10、1マス）：サブクエスト（`compost`、箱の草が10こで木のせいれいのおねがい）でおぼえる。タップして、草の種類ごとに入れる数をえらぶ（ぜんぶで20こまで、`cmpPop`）と、せいれいが箱から運ぶ（`S.cmpQ`→`cpick`→`r.cpk`→`cput`。1回に持てる数まで `qPick` の3つめ。炉・加工・おたきあげも同じ）。入れて1日で、草1こが肥料1こ（`cmpTick`、`S.dyn[j].b`・`.c`）。肥料はコンポスターの中。
- コンポスターへ運ぶ草（`r.cpk`）・畑へ運ぶ肥料（`r.fert`）は、せいれいの頭の上にアイコンをつんで見せる（`carryIcon`・`carryIcons`）。
- 肥料やり（木のせいれい、`fert`）：コンポスターから肥料をとって（`cget`、持てる数まで `r.fert`）、畑にまく。1つの畑に1日1回（`fdD`）、まくたびに、その畑の収穫+1（`d.fb`、上限なし、収穫で0にもどす）。
- 水をくむ（`draw`）：1回だけくむ。かがんでバケツを水へおろし、両手でひき上げて、胸の前でかかえる（動き `draw` は、くむ行動の進みぐあい `'ph'` でコマをえらぶ）。バケツが水に入る所・ひき上げる所で、本物の水の音（`dscoop`・`dlift`、`tools/sound/spirit_act.py`）と水しぶき（`WBEAT`）。みずがめの絵（`jar`・空 `jar~e`）は、水がたまっているときと空で出し分ける。はば1マス（64）、下のはしは55（g64）。まるクッション（`pouf`）の下のはしは47（g64）。
- 行動をはじめるとき、持っている物を先にしまいにいく行動（`startAct` の `store`・`smat`・`sitem`）は、夜もつづける行動（`NIGHT_OK`）に入れる。入れないと、夜に「しまう→やめる→見張り台へ→しまう」をくりかえして動けなくなる。
- 箱にしまう時間は9（`STORET`・`storeDur`）。しまうあいだも、足もとに進みぐあいのバーを出す（`WORKP`）。

## スポット
- 作ったことのないスポットは、ひでんのしょで名前も組み合わせも「？？？」（`S.spotSeen`）。ヒントは、雑談（`CHATS` の `hint`、`spotHintOK`。4回に1回くらい）で出す。そのスポットの物（自然の物はのぞく）が1つでも置いてあって、いまそのスポットが村にないときだけ。話の中で、もうあるように言っている物（小屋・生き物・噴水など）は、`spotHintOK` の3つめ（`has`）で、それがあるときだけ。スポットを足したら、ヒントの雑談も足す。
- 物の組み合わせ（まわり3マス以内）で、効果が少し上がる（`SPOTS`・`calcSpots`、`recount` のたびに作る）。いま44こ（水べのいすだけでできる「つり場」もスポット）。効果は%で書き、ひかえめに（+5〜20%）。おなじスポットは重ならない（いくつできても1こ分）。ちがうスポットは、効果が同じでも、たし算で重なる（`spotN`）。はじめてできたときは、先にマップの場面（`spot-scene.js` の `spotScene`：村の時間を止め、カメラがよる → かこみが1周はしる → 物が1つずつ光ってはねる → 光の柱・紙ふぶき、近くのせいれいがよろこぶ。村の切りかえで `spotSceneReset`）を見せてから、ポップアップで名前・条件（「条件：井戸・畑×3」の形、`spotCond`。図鑑も同じ書き方）・効果と「できた」のハンコを出し（`showSpotPop`。とじたあとカメラがもどる）、家具をタップすると出る。スポットができたとき（新しい組み合わせがそろったとき）と、家具をタップしたときは、そのスポットの物がならぶ所を点線でかこみ、中をキラキラさせる（4秒、`spotFx`）。一覧は、ひでんのしょの「くらし・家具」。スポットには、代表の家具の絵をアイコンにする（`SPOTREP`：家具の名前、`spotIcon`。ひでんのしょ・図鑑・できたときのポップアップ・家具の画面）。スポットを足したら `SPOTREP` にも足す。

## せいれいのレベル
- Lv1の能力は属性ごと（`EL_BASE`：はたらく速さ・移動速度・スタミナの合計は、どの属性も60。20がふつう `STD`）。せいれいごとに、はたらく速さ・移動速度・スタミナを、それぞれ−6〜+6（2きざみ）でばらつかせる（`mkVar`・`VRDEV`）。この3つにたす数（レベル・強化・ふしぎな種・遊び・特性・そうび・料理・イベント・むらのちから・得意な仕事・なれ）も、20がふつうの大きさの整数で書く。
- レベルが上がるたびに、攻撃力は、属性ごとのはば（`EL_GROW`：たとえば火の攻撃力1〜20）のどれかだけ、かならずふえる。はたらく速さ・移動速度・持てる数は、属性ごとの%で+1（100をこえた分は、かならず+1。はたらく速さ・移動速度は、20がふつうにする前の伸びの1/5にそろえた %）。せいれいごとの、のびやすさ（`grw`：能力ごとに−20〜+20、id から決まるのでしまわない）が、攻撃力ははばの中で多いほうへ・少ないほうへよせ、ほかは%にたす。Lv40まで（`lvGain`）。Lv1の攻撃力は `EL_ATK`（火10・土8・木5・風3・水0）、持てる数は1。火でないせいれいの攻撃力は、出撃の近接のダメージ（水はダメージなし）。食べる量はレベルでかわらない（1、火は2）。けいけんのボーナスはない（そうびの銀のかみかざりだけにある）。おなかの最大は上がるたびに100〜750（`hMax`）。

## 遊び（せいれいの動き）

## せいれいの気持ちの見え方
- すわる家具（いす・ベンチ）：となりのマスから、すわる位置へ、ぴょんと乗る。背もたれのがわのマス（`seatBack`）からは乗らない・おりない（前か横へまわる `seatSides`。道さがし `roadSearch` でも、背もたれのがわとの行き来はしない `seatBackStep`）。すわる・ねる・遊ぶ家具とお墓（`SEATF`）は、使うときだけ上に乗る（道さがしでは上を通る手間 `SEATCOST`、使わない行動の行き先は、となりの空いたマス `seatStand`。たしかめは `tools/tests/seat-pass.cjs`）。おりるときは、すわる位置からとなりのマスへ（`SEATMV`・`SEATLAST`、場所はすぐうつし、絵だけを `SEATMVMS` ではねながらうつす）。家具にめりこんで見せない。
- 食べる動きと音は、食べている物で分ける（`eatKind`：のみもの `eat_drink`・パン `eat_bread`・くだもの `eat_fruit`・料理 `eat_meal`）。食べ物は手で持つ：基本は両手（持ち主のきめ。くだもの・料理も両手、`motions.py` の `eat_*`）。食べ物の絵の上に、持っている手（`drawMitt`）をかさねる。3Dの絵がないとき（横にすわる など）は、いままでの食べる形（`spPose` で `eat_*` を `eat` に）。絵は `eatIcon`（字の絵がなければ食べ物のアイコン → その物の絵）。音は、持ち主が集めてくれた freesound の録音（`tools/sound/src/eat/`、出どころは `CREDITS.txt`）から、持ち主が候補のページで「つかう」にした、ひと口ぶんを切った物（`tools/sound/eat_asmr.py` の `PICK`）。かじった瞬間から切り、大きさはいちばん大きい所でそろえる（静かな所を大きくすると吐息になる。いちばん大きい所をさけると、かじった音がなくなる）。やわらかい物（きのこもふくむ）は、高い音を2200Hzより上でけずった「もぐ」`ea_soft`。つば・すする音・ストロー・吐息は使わない。食べ物ごとに（`eatSnd`・`EATSND`・料理の絵のしゅるい `EATSNDIC`）かむコマ（`WBEAT` の `@eat`）で、とても小さく（`EATV`）、だれが食べていても `SFXGAP.ea_` 秒に1回。CC BY の録音を使うときは、音のクレジットに作者・元音源・ライセンス・編集したことを書く。
- つりのおわりの `FISHPULL`（行動の時間）は、魚がかかって、うきのまわりで水しぶきとバシャバシャ（`fishbite`）・さおをぐいぐい引く（3Dの `fishpull`）。
- つりの結果：魚・家具・レシピ・宝の物はよろこぶ、枝はがっかり、設計図はふしぎそうに首をかしげて「？」（`spReact`：正面を向いて、手をとめる）。家具などができたとき（建てる・もの作り・料理のかかげる所）は、にっこり。
- たのしさが低い（遊びに行くさかい `funLow`：30より下、風は60より下）ときは、たまに（歩いていても。`moodOn`：7秒ごとに、たのしさの量に合わせた確率 10〜60% で4.5秒）、頭のまわりに大きさのちがう、むらさきのうずまきが、まばらにわいてうかぶ「もやもや」（`drawMoya`・`MOYAS`。どうぶつの森のしょんぼりの雲のように）。ごきげん（`FUNF` 以上）のときも、たまに音符（`drawHum`・`humTick`。こわがっているときはのぞく）。ねている・物を運ぶ・ふきだし・正面を向く反応のときは出さない。音は、画面のまん中にいちばん近い1人（見守っている子がいれば、その子）だけ、つぎつぎ小さく（`moodMark`・`moodTick`）：鼻歌は会話の声の母音を、声の1周期ずつ（前半・後半をならした2つの形を、ゆっくりうつりかわらせる。周期ごとにばらつく・行ったり来たりすると、低い音でぶつぶつ鳴る）重ねて高さのかわらない「あー」にのばした音（`SAMPLES.vowel`、`tools/sound/voice_vowel.py`）を、1つの音に1本ずつ（`vNote`。粒をつなげると音の中がコロコロゆれすぎる）、スキップのリズム（`HUMSK`：長い音・短い音をかわりばんこに）で、上がっていく明るいフレーズの「るんるん」に（どの音もやさしくゆらす `HUMVIB`、さいごの音は少し大きく `HUMVIBL`・`VIBHZ`。持ち主がきめた）。高い音をけずる（`humPhrase`・`HUMS`）。もやもやは持ち主の声を、尻上がりにしないで、ゆっくりの「もやん」にした物（`SAMPLES.moya`、`tools/sound/owner_moya.py`。ffmpeg の rubberband で高さと速さだけかえる）。どちらも、その子の声の高さで、会話の画面の声が出ているあいだは鳴らさない。たしかめは `tools/tests/mood-fx.cjs`。
- じょうろは、取っ手を上からにぎり、胴ごと前へかたむけて、そそぎ口の先が前の下を向く（`props.py` の `can`、まうえをそろえる `up`）。

## 道・床の絵
- せいれいの能力（はたらく速さ・移動速度・スタミナ・持てる数・攻撃力）は、整数のたし算だけで作る（属性の初期値・ばらつき・強化・ふしぎな種・遊び・特性・そうび・料理。倍率をかけない）。画面の数が、そのまま本当の速さ（はたらく速さ・移動速度・スタミナは20がふつう `STD`、`rMul` は÷20。攻撃力は÷100のまま。季節の倍 `seaMul` は、かけてからまるめた数を使い、画面にも「20→24」と出す `seaTxt`・`staNow`）。前のセーブの倍率・10がふつう・100がふつうだったころの数は `vrInt`（`iv` が3ならかえてある）と `stat10Mig`（`S.flags.stat10`）・`stat5Mig`（`S.flags.stat5`：強化・種・遊び・イベント・料理の分を÷5してまるめる）でたす数に。能力の大きさをかえたら、`STD`・`rMul`・`staNow` を使わずに数で割っている所（歩いてつかれる `WALKTIRE` で、`100/staOf` がのこっていて、つかれが5倍になった）を `staOf`・`/100` でさがす。けいけんなど、ほかの画面の数には小数点を出さない（中の計算は丸めない）。

## 手ざわり・まとまり・間（ポリッシュ）
- すれちがう子どうしは、昼でコワイノがいないときだけ、ときどき立ちどまって、にっこり手をふり、会話の声をごく短く小さく「やっ」と鳴らす（`passGreet`・`greetStop`・`greetVoice`、1秒に1回だけ調べる）。夜の見張り・戦いの動きにはかかわらない。

## なかよし
- せいれい2人ごとのなかよし（`S.bond`、0〜100、`bond.js`）。いっしょに遊ぶ+1・おしゃべり+1.5・同じ食卓+1・同じ夜に守る+1（1晩1回）。30で「なかよし」（`bestMate`。ポップアップで知らせる `SPOT_POPS` の `bond`。2人が向かい合ってはねる絵とドットのハート `bondPic`）と2人のピンクの会話1回（`BOND_TALKS`、ないときは属性の組 `BOND_GEN`）、60で遊びにさそう、100で3マス以内のはたらく速さ+5%（`BOND5`）。思い出帳ではふやさない。前のセーブの数は1回だけ倍（`S.flags.bondX2`）。60・100でも2人のピンクの会話を1回ずつ（`BOND_TALKS2/3`・`BOND_GEN2/3`、キー `bd2_`・`bd3_`。前の段階の会話を見てから）。夜の戦い（`support.js`）：たたかうせいれいの3マス以内に、たたかっている、なかよし30・60・100がいると攻撃力+2・+3・+5（いちばん高い1人ぶん、`supAtk`）。にげる子に、なかよし30いじょうの、たたかうせいれいがつきそい、攻撃をかわりにうけ、とどけたら+2（`escort`・`escGuard`。火のせいれいの「コワイノが来たらたたかいに行く」でやめない）。「しらべる」でタップしたコワイノから、ねらいへ4秒の点線（`tgtShow`・`drawTgtLine`）。たしかめは `tools/tests/support.cjs`。
- 家があってベッドがないときは、家の中の床で寝る（`goSleep`。地面で寝るときと同じ寝かた・つかれのとれ方）。家に行けない夜は、その場でまつ。
- せいれいの顔（`drawRes0` の `mood`）：おなかが250より少ない（`HUNGRYF`）とおなかがすいた顔（`hungry`：しょんぼりの目）、つかれが30より少ない（`TIREDF`）とつかれた顔（`tired`：半分とじた目）、たのしさ70いじょう（`FUNF`）はにっこり。顔の絵は `tools/art/spface/spface_art.py`（1色のドット。属性の色にかわる）。せいれいの顔に口をかかない（持ち主のきめ）。
- 床・地面（ベッド・いす・ベンチでない所）で寝る子は、横になって丸くなって寝る（ひざをまげ、手を胸に、頭をまるめた 3Dの絵 `sleepcurl` を、よこにたおす `flSl`・`FLSLX`・`FLSLY`。頭は子ごとに左か右。持ち主のきめ）。夕焼けを見る子は、正面を向いて地面にすわる（`sitF`）。タイトルのフタバ（ベンチ）は、正面を向いてすわり、足のうらを2つ見せる形のまま（`soleImg`）。
