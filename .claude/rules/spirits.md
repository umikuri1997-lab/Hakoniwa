# せいれいのくらし・仕事・遊び

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。

## おなか
- 草原のはじめ（フリーモードでない・WD===0）は、ベッドの目標がおわるまで（村にベッドが1つもないあいだ）、おなか・たのしさ・つかれが進まない。
- おなかの最大は、レベル1で500（火の子は1000。持ち主のたのみで前の半分、ほかのおなかの数もぜんぶ半分にしてバランスはそのまま）。レベルが上がるたびに100〜750ふえる（せいれいとレベルごとにばらつく。id とレベルから決まるので、しまわない）。
- 火の子が受けるダメージ（おなか）は、コワイノの表の `hitF`・`hitFS`（となりで戦っているとき）と `hitFN`・`hitFNS`（はなれているとき）。ほかの子は `hitN`・`hitNS`。
- ごはんに行く前に、持っている素材をしまう（そばにコワイノがいるときは、そのまま食べにいく）。
- せいれいは、おなかが250より少なくなったら、どんなときも（仕事・遊び・ねている・夜の戦い中でも）食べにいく。コワイノがそばにいるときは、安全に行ける箱へ。火の子も250より少なくなったら、戦いをやめてにげる。

## なかまを呼ぶ
- あたらしい子の名前は `NAMES` から。使いきったら、うしろに数をつける。キーキャラの名前（フタバ2など）は使わない。
- なかまを呼ぶのにいる力は、いる子の数に、いなくなったキーキャラも数えて決める（キーキャラが死んでも、いる力は下がらない）。めぶきのしずくでよみがえらせるときも、その属性の力がたまっていないとだめ。
- ホノ（草原の火のキーキャラ）は、あにき（おれ）だけ。会話にあねご／あにきの2つの言い方（`{A,B}`）を書かない。
- 名前をつける（`nick.js`）：なかまが来たときの紹介の画面でだけ、名前をかえられる（章のはじめの子・もどってきた子はのぞく）。ふつうの子は `r.name` をかえる。お話の子（ノドカ・ホノ・アオ・フウ・シズク）は `r.name` をかえず、画面に出す名前だけ `S.nick` でかえる。お話の子の名前でしくみを見分ける所は、もとの名前のまま。お話の子のもとの名前をふくむ名前はつけられない（おきかえが2回かかる）。たしかめは `tools/tests/nick.cjs`。
- なかまを呼べるのは1日に1回だけ。神殿の「！」で呼ぶ・お墓からよみがえらせる・めぶきのしずくでよみがえらせる、どれも1回に数える。1日は朝6時から朝6時まで（`callDay`。夜中の0時ではかわらない）。呼んだ日は、神殿の「！」も出さない（タップもできない）。

## 畑の仕事
- 収穫は、木のせいれいがいれば木のせいれいだけ。水やりは、水のせいれいがいれば水のせいれいだけ（木の子の世話の水やりはしない）。
- 水やりは、水をくんでから：池・川の水・井戸（いくらでも）・みずがめ（雨の日に畑10マスぶんたまる）。1回くむと、持てる数1ごとに畑5マス。井戸・みずがめに、まわりの畑を水やりなしにする効果はない。みずがめには効果範囲の表示を出さない。
- 花：まわり3マスで、たのしさ+0.2／1時間、花と同じ属性のせいれいは+0.6／1時間。芽のあいだは効果なし。
- コンポスター（木材10、1マス）：サブクエスト（箱の草が10こで木のせいれいのおねがい）でおぼえる。タップして、草の種類ごとに入れる数をえらぶ（ぜんぶで20こまで）と、せいれいが箱から運ぶ（1回に持てる数まで。炉・加工・おたきあげも同じ）。入れて1日で、草1こが肥料1こ。肥料はコンポスターの中。
- コンポスターへ運ぶ草・畑へ運ぶ肥料は、せいれいの頭の上にアイコンをつんで見せる。
- 肥料やり（木のせいれい）：コンポスターから肥料をとって（持てる数まで）、畑にまく。1つの畑に1日1回、まくたびに、その畑の収穫+1（上限なし、収穫で0にもどす）。
- 水をくむ：1回だけくむ。かがんでバケツを水へおろし、両手でひき上げて、胸の前でかかえる（動きは、くむ行動の進みぐあいでコマをえらぶ）。バケツが水に入る所・ひき上げる所で、本物の水の音（`tools/sound/spirit_act.py`）と水しぶき。みずがめの絵（`jar`・空 `jar~e`）は、水がたまっているときと空で出し分ける。はば1マス（64）、下のはしは55（g64）。まるクッション（`pouf`）の下のはしは47（g64）。
- 行動をはじめるとき、持っている物を先にしまいにいく行動（`startAct` の `store`・`smat`・`sitem`）は、夜もつづける行動（`NIGHT_OK`）に入れる。入れないと、夜に「しまう→やめる→見張り台へ→しまう」をくりかえして動けなくなる。
- 箱にしまう時間は9。しまうあいだも、足もとに進みぐあいのバーを出す。

## 料理
- 食卓は2しゅるい（食卓・大きな食卓、2×2。食べられる人数は食卓2・大きな食卓4）。食卓を見る所（食べる席・しょくたくなどのスポット・いすの向き）は `TABLES.has` を使い、`'table'` だけをくらべない。まるいサイドテーブルはなくした。もどさない。
- 料理は、材料の組み合わせ（しゅるいごとに1こ、3しゅるいまで）と家具（調理台・たき火・かまど）できまる（`cook.js`）。表は `tools/cook/cook_table.py` で `js/cook-table.js` に書き出す（数字は実数。表をかえたら道具を動かす）。材料1・2しゅるいの組み合わせは、どれも調理台かたき火で作れる。表にない組み合わせは、ふしぎな料理。とくべつな魚は、とくべつな料理がなければ「さかな」の料理。作り方は `recOf(<材料+材料@家具>)`、`r.cing.rec`・`r.cgot.rec` もこの名前（前のセーブの料理の名前も読める）。
- 料理の家具は「やすむ・おまかせ・入れる」。おまかせは、作ったことのある料理だけで、おいしくなさそうな料理（たのしさがへる）・ふしぎな料理はえらばない。作るまで名前は「？？？」、はじめてできたら「あたらしい料理！」。図鑑の「りょうり」。
- 料理は、その料理の属性（表の `el`）のせいれいだけが作る（ふしぎな料理はだれでも）。時間は料理の `time`（実数）。画面では「とくい」と言わず、「作る：火」のように短く書く。料理のアイコンは、もらうまでコードのドット。たのむプロンプトは `tools/art/cookfood/prompts.py`。
- 火を使わない料理（サラダ・ジュース）は調理台で、ほかはかまど。調理台・流し台の絵は3Dから写した絵（`tools/art/furn3d`、前・右・後ろ・左の4つの向き）。料理をする家具は `COOKST`、その料理の家具は `dishSt`。
- 料理の家具の上の物（`work-fx.js`）：調理台の絵は台だけ。作っているあいだは、置いた道具（調理台は料理のしゅるいで、まな板・ボウル・ピッチャー・こねばち。かまどの口に、なべ・フライパン・天板。たき火は、三脚のなべ・網・くし）と材料、もりつける所からは、できた料理を家具の上にかさねる。かかげるときに、せいれいが持ち上げる。せいれいの動きは置いた道具にあわせる（まな板はきざむ・ボウルなどはかきまぜる・なべはおたま・ほかはうちわ。同じ道具を手と家具に2つ出さない）。絵は `tools/art/furn3d/cooktop.py`（道具は家具の3Dにのせて写し、材料・料理は1つずつ。場所は `js/cook-top-data.js`）。料理・材料をふやしたら、作りなおす。
- 料理・もの作りの動き（`js/work-fx.js`）：進みぐあいで動きをかえる（料理：材料を持つ → 調理台はきざむ → 作り方ごとの動き → もりつける。もの作り：ならべる → のこぎり → トンカチ → みがく）。手もとの音と粒は、描く時刻で動きの決まった所（`WBEAT`）をこえたときに出す（時間の数で鳴らさない）。できたら、こちらを向いてかかげてから終わる。料理は家具のほうを向く。作業台の上の形は、できてかかげているあいだは、台の上の物をなくす（設計図 `tools/art/furn3d/items/wbwork.py`。作業台がないときは下げて地面に）。たしかめは `tools/tests/work-motion.cjs`。
- 箱などから取る・置く行動（`work-fx.js` の `TAKEACT`・`PUTACT`）：その物のほうを向き（上の物にはうしろ向き）、頭の上の物をおろして、物の高さに合わせて手をのばす（上から入れる物は、ぴょんととんで、ふちの上から入れる・前から入れる家具は胸の高さ・地面の物はしゃがむ。せいれいは手が短く、背のびでは木箱のふちにとどかない）。取る・置く物・行動を足したら、どちらかに入れる。動きは `fieldStoryAnim` から `workAnim` をとおる。動きは行動のはじめから（せいれいの時間）。音は、取る・置くのあいだ、持ち主がくれたゴソゴソ（`tools/sound/gosogoso_loop.py` でつなぎ目なくした形）をつなげて鳴らし、おわったら止める（近い子から2人まで・小さく）。
- spirit3d の、たいらに持つ道具（フライパン・ボウル・お皿・あわだて器）は、`props.py` の返す `up`（道具の上の向き）を、`rig.posed` が手のまわりで回して、まうえ（あわだて器はまっすぐ下）にそろえる。うでの角度だけで向きをきめると、向きごとに道具がたおれる。
- テストでせいれいを `S.res[0]` から写して作るときは、`r.nap=false` にする（新しいゲームのはじめの子は、ねている場面の `nap` がのこっていて、行動の動きが出ない）。

- とくにする仕事（`focus.js`：はたけ・木・石・ひろう・料理）：せいれいの画面でえらぶ。しごと場の担当のすぐあと、ふだんの仕事より先。その子ができない仕事はえらべない。たしかめは `tools/tests/focus.cjs`。
- 建てる場所・依頼のものづくりは、行ける所ならどんなに遠くても、ふだんの仕事（植える・ひろう・畑・木・石・草）より先（土の子の修理・食べ物あつめ・空腹・夜・お話はさらに先）。

- 箱がいっぱいで木・石をあつめられないときは「箱がいっぱいです」を1回だけ知らせる（しまえる数がふえるか、2わり空いたら、また知らせる）。

## スポット・箱
- 作ったことのないスポットは、ひでんのしょで名前も組み合わせも「？？？」。ヒントは、雑談（4回に1回くらい）で出す。そのスポットの物（自然の物はのぞく）が1つでも置いてあって、いまそのスポットが村にないときだけ。話の中で、もうあるように言っている物（小屋・生き物・噴水など）は、それがあるときだけ。スポットを足したら、ヒントの雑談も足す。
- 物の組み合わせ（まわり3マス以内）で、効果が少し上がる（`recount` のたびに作る。水べのいすだけでできる「つり場」もスポット）。効果は%で書き、ひかえめに（+5〜20%）。おなじスポットは重ならない（いくつできても1こ分）。ちがうスポットは、効果が同じでも、たし算で重なる。はじめてできたときは、先にマップの場面（`spot-scene.js`：村の時間を止め、カメラがよる → かこみが1周はしる → 物が1つずつ光ってはねる → 光の柱・紙ふぶき、近くのせいれいがよろこぶ。村の切りかえでおえる）を見せてから、ポップアップで名前・条件（「条件：井戸・畑×3」の形。図鑑も同じ書き方）・効果と「できた」のハンコを出し（とじたあとカメラがもどる）、家具をタップすると出る。スポットができたとき（新しい組み合わせがそろったとき）と、家具をタップしたときは、そのスポットの物がならぶ所を点線でかこみ、中をキラキラさせる（4秒）。一覧は、ひでんのしょの「くらし・家具」。スポットには、代表の家具の絵をアイコンにする（ひでんのしょ・図鑑・できたときのポップアップ・家具の画面）。スポットを足したら `SPOTREP` にも足す。
- 部屋のスポット（`room:1`）：もとの物も、いる物も、同じ家の中にあるときだけ（しんしつ・おふろば・しょさい・リビング・ダイニング・だいどころ・ものおき部屋・ちょぞう部屋・なや）。家をタップした画面に、そろった部屋の名前を出す。説明は「家の中に、〜」。部屋のスポットがはじめてできたら、ポップアップの OK でパワー+20。
- 箱ごとの中身（`js/boxes.js`）：食料箱・素材箱はなくし、木箱にまとめた。もどさない。しまう家具は、どれも食べ物も素材も入る。中身は箱ごと。箱ごとに入れる物をえらべる（食べ物・素材・1つずつの物。なにもえらばなければ、なんでも）。
  - `S.mat`・`S.fs` は使える数（箱と神殿のまえの合計から、とっておいた数 `S.rsv` をひいた数）。じかにふやした・へらした分は `boxSync`（毎コマ）があわせる：ふえた分は神殿に近い、あいた箱へ、入らなければ神殿のまえ。へった分は神殿のまえ → 中身の多い箱から。`S.rsv` は毎回、建てる所・依頼・炉・コンポスター・おたきあげから数えなおす（`rsvNeed`）。
  - せいれいがしまう・とりだす所は、その箱をかえる。しまうときは入れられる箱、食べるときは食べ物のある箱、ほかは物のある箱。料理の材料は、いくつかの箱から集める。
  - 建てる・依頼の素材は、たのんだときはとっておくだけ。建てるせいれいが箱へとりにいき（1回に持てる数まで、ほかの運びと同じく頭の上に積む）、とどけてから建てる。やめたら、とっておいた分はもどし、とどけた分はその場所に落とす。
  - 作業台は家具。よこ2マスで、作業台と材料置き場がセット（向き4つ）。依頼で運んだ素材は、その置き場へ置く（絵は運んだわりあいの `matyard#0〜3`）。作りおわっても置き場はのこる。依頼は、空いた作業台に1つずつわりあてて作る（となりの箱にいる素材が多い台・依頼ボードに近い台から）。作業台がないと作らない（依頼の紙・ベッドの目標に「作業台がありません」）。作業台そのものの依頼だけは、作業台が1つもなければ地面で作る（作業台はだれでも作れる）。作業台・置き場のとなり（たて・よこ。かべかけは、すぐ上の壁）のしまう家具にある素材は、運ばずに使う（ない分だけ、ほかの箱から運ぶ）。作業台をこわす・うつすと、運びこんだ素材はそこに落とす。置くときは、箱のとなりの置けるマスを緑に。置くときの見た目にも、材料置き場を、えらんだ向きのならびで出す。草原のメインの目標「作業台を置こう」（家の壁のあと。カミサマが1つくれる）、火山は神殿を直したときにもらう。たしかめは `tools/tests/wbench.cjs`。
  - 材料置き場（`matyard`、`build.js`）：建てる所・設計図（設計図ごとに1つ）のとなりの空いたマスに1マス出す。せいれいは運んだ素材を置き場へ置き、絵は運んだ素材の合計のわりあいで4まい（空・半分より少ない・半分から・ぜんぶ。素材の種類ではわけない）。作業台・足場の上に素材のアイコンは積まない。空きがなければ置き場は出さず、前のとおり作る所へ運ぶ。作りおわる・やめるとかたづき、やめたら運んだ分は置き場の所に落とす。タップで「木材（2/5）」。数は、依頼の紙・足場・置き場をタップした知らせだけ（マップには出さない。持ち主がきめた）。絵は3D（`tools/art/furn3d/items/matyard.py`）。たしかめは `tools/tests/mat-yard.cjs`。

## すわる・食べる・つりの動き
- すわる家具（いす・ベンチ）：となりのマスから、すわる位置へ、ぴょんと乗る。背もたれのがわのマスからは乗らない・おりない（前か横へまわる。道さがし `roadSearch` でも、背もたれのがわとの行き来はしない）。すわる・ねる・遊ぶ家具とお墓は、使うときだけ上に乗る（道さがしでは上を通る手間をかけ、使わない行動の行き先は、となりの空いたマス。たしかめは `tools/tests/seat-pass.cjs`）。おりるときは、すわる位置からとなりのマスへ（場所はすぐうつし、絵だけをはねながらうつす）。家具にめりこんで見せない。
- 食べる動きと音は、食べている物で分ける（のみもの・パン・くだもの・料理）。食べ物は手で持つ：基本は両手（持ち主のきめ。くだもの・料理も両手、`motions.py` の `eat_*`）。食べ物の絵の上に、持っている手をかさねる。3Dの絵がないとき（横にすわる など）は、いままでの食べる形。絵は、字の絵がなければ食べ物のアイコン → その物の絵。音は、持ち主が集めてくれた freesound の録音（`tools/sound/src/eat/`、出どころは `CREDITS.txt`）から、持ち主が候補のページで「つかう」にした、ひと口ぶんを切った物（`tools/sound/eat_asmr.py` の `PICK`）。かじった瞬間から切り、大きさはいちばん大きい所でそろえる（静かな所を大きくすると吐息になる。いちばん大きい所をさけると、かじった音がなくなる）。やわらかい物（きのこもふくむ）は、高い音を2200Hzより上でけずった「もぐ」。つば・すする音・ストロー・吐息は使わない。食べ物ごとに、かむコマ（`WBEAT` の `@eat`）で、とても小さく、だれが食べていても `SFXGAP.ea_` 秒に1回。CC BY の録音を使うときは、音のクレジットに作者・元音源・ライセンス・編集したことを書く。
- つりのおわりは、魚がかかって、うきのまわりで水しぶきとバシャバシャ・さおをぐいぐい引く。
- つりの結果：魚・家具・レシピ・宝の物はよろこぶ、枝はがっかり、設計図はふしぎそうに首をかしげて「？」（正面を向いて、手をとめる）。家具などができたとき（建てる・もの作り・料理のかかげる所）は、にっこり。
- たのしさが低い（遊びに行くさかい：30より下、風は60より下）ときは、たまに（歩いていても。7秒ごとに、たのしさの量に合わせた確率 10〜60% で4.5秒）、頭のまわりに大きさのちがう、むらさきのうずまきが、まばらにわいてうかぶ「もやもや」（どうぶつの森のしょんぼりの雲のように）。ごきげんのときも、たまに音符（こわがっているときはのぞく）。ねている・物を運ぶ・ふきだし・正面を向く反応のときは出さない。音は、画面のまん中にいちばん近い1人（見守っている子がいれば、その子）だけ、つぎつぎ小さく：鼻歌は会話の声の母音を、声の1周期ずつ（前半・後半をならした2つの形を、ゆっくりうつりかわらせる。周期ごとにばらつく・行ったり来たりすると、低い音でぶつぶつ鳴る）重ねて高さのかわらない「あー」にのばした音（`tools/sound/voice_vowel.py`）を、1つの音に1本ずつ（粒をつなげると音の中がコロコロゆれすぎる）、スキップのリズム（長い音・短い音をかわりばんこに）で、上がっていく明るいフレーズの「るんるん」に（どの音もやさしくゆらす、さいごの音は少し大きく。持ち主がきめた）。高い音をけずる。もやもやは持ち主の声を、尻上がりにしないで、ゆっくりの「もやん」にした物（`tools/sound/owner_moya.py`。ffmpeg の rubberband で高さと速さだけかえる）。どちらも、その子の声の高さで、会話の画面の声が出ているあいだは鳴らさない。たしかめは `tools/tests/mood-fx.cjs`。
- じょうろは、取っ手を上からにぎり、胴ごと前へかたむけて、そそぎ口の先が前の下を向く（`props.py` の `can`、まうえをそろえる `up`）。

## せいれいの能力の数字
- せいれいの能力（はたらく速さ・移動速度・スタミナ・持てる数・攻撃力）は、整数のたし算だけで作る（属性の初期値・ばらつき・強化・ふしぎな種・遊び・特性・そうび・料理。倍率をかけない）。画面の数が、そのまま本当の速さ（はたらく速さ・移動速度・スタミナは20がふつう `STD`、`rMul` は÷20。攻撃力は÷100のまま。季節の倍 `seaMul` は、かけてからまるめた数を使い、画面にも「20→24」と出す）。能力の大きさをかえたら、`STD`・`rMul`・`staNow` を使わずに数で割っている所（歩いてつかれる所で、`100/staOf` がのこっていて、つかれが5倍になった）を `staOf`・`/100` でさがす。けいけんなど、ほかの画面の数には小数点を出さない（中の計算は丸めない）。

## すれちがい
- すれちがう子どうしは、昼でコワイノがいないときだけ、ときどき立ちどまって、にっこり手をふり、会話の声をごく短く小さく「やっ」と鳴らす（1秒に1回だけ調べる）。夜の見張り・戦いの動きにはかかわらない。
