# 風のステージ

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。

## 風のステージ（風のやんだ空の村）
- ステージ番号は4（`WIND`、WORLD 5）。いま遊べるお話のステージは `STAGES`（草原・火山・土・水・風）。ステージを回す所は `[0,1]` と書かずに `STAGES` を使う。
- ステージの番号は、じかに書かず名前で書く（`KUSA` 草原・`KAZAN` 火山・`TSUCHI` 土・`MIZU`・`WIND`・`YAMI`・`FREE`、`core.js`）。`WD` を見る所で、「草原でない＝火山」（`WD!==KUSA`）と書かない。風でも通るので、火山だけの物は `WD===KAZAN` と書く。ステージごとにかわる値（壁・柵・素材の一覧・雑草の絵・日記を書くせいれい など）は、`core.js` の表 `STAGE`（`stg()`）に書き、`WD===KAZAN?…:WD===WIND?…` とつながない。そのステージだけのしくみ（温泉・鉱脈など）を、そのステージのコードの中で `WD===KAZAN` で見るのは、そのままでよい。
- お話は「風のやんだ遊園地」（持ち主がきめた。芯・おわり・さいごの夜・これから作る分は `IDEAS.md` と `STORY.md`）。いま入っているのは目標1〜7（`QUESTS5`：風穴 → 神殿 → となりの島へ風をとどける（ハヤテが目をさます）→ メリーゴーラウンドを直す → コーヒーカップ・空中ブランコ → 島をぜんぶうかせる → 観覧車（てっぺんから雲のすきまにつばさが見える、会話の合図 `wind:peek`）→ 雲の下）と、プロローグ・着いてからの会話。雲の下：雲の海のはしの印（観覧車に近い、南が雲の海の、行ける陸のマス）へカザネ（いればハヤテも）が歩いて待ち（待つあいだ、おなか・たのしさ・つかれはへらない）、そこへまもりの光を落とすと、村の時間を止めて雲がひらき（絵はかりのドット絵）、風のヌシ様が話す。会話をさいごまで見てから、おえたことにする。たしかめは `tools/tests/wind-story2.cjs`。はじめからいるのはカザネ（風、ねばりづよい）、2人めはハヤテ（風。はじめにうかんだ島で目をさます）。さいごの夜とおわり（`js/wind-story.js`）：ひと晩、遊び場を守る（遊具が4つ動けば、その夜21時に影が来て、遊具を先にこわしにくる。こわされた遊具は、こわれた遊具にもどる。朝に2つのこれば勝ち、負けたら3日あと）→ ヌシ様をむかえる（勝った朝、雲の海のはしからヌシ様がのぼり、遊具の風がつばさになる。そのあとクリア）。場面は村の時間を止める（`wsScene`・`GIFT_ACTIVE`）。ヌシ様の鳥は、3Dから写した絵（GPT の H-5：とぶ16コマ・島をささえる姿。`tools/art/windnushi/sheet.py` が assets/g の1まいのシートを作る。大きいのでアトラスに入れず、ヌシ様が出るときだけ読みこむ）。たしかめは `tools/tests/wind-story.cjs`。
- 遊園地（`js/wind.js`）：遊具は4つ（`RIDES`：メリーゴーラウンド・コーヒーカップ・空中ブランコ・観覧車。`STAGEONLY` 風）。はじめは、こわれた遊具（`RIDEB`）が島に1つずつ（メリーゴーラウンドはまん中の島）。「しらべる」でタップすると、せいれいが直し（建てる所のしくみ、素材はいらない）、直すとレシピをおぼえる。こわれた遊具は、こわせない・うつせない。
  - 遊具は、風のせいれいが係をしているあいだだけ動き、のれる。係は、のった子がおりるたびに、たのしさ+5。風の道のそば（まわり2マス）の遊具は、係がつかれない。メリーゴーラウンドの依頼のあいだは、ハヤテは係をしない（カザネが動かして、ハヤテがのる）。
  - わすれた楽しさ：風のステージのせいれいは、遊具のほかの遊び家具で遊ばない。はじめて遊具にのる・係をするたびに、遊び方を1つ思い出す。思い出したときは、頭の上にその遊び家具の絵と光・ひとこと。せいれいの画面に「思い出した遊び：〇」。
  - 遊具の絵は、3Dから写したチップ（GPT の H-1、`tools/art/handoff3d/register.py`）：動かない所 `<id>:s` に、まわる角度のコマの動く所 `<id>:m0〜m15`（16コマでひとまわり）をかさねる。こわれた遊具は `<id>b`。のる子の位置は、そのコマの座席（チップの `seats`）。チップがないときは、コードの仮の絵。
  - 遊具が動いた回数は `S.flags.rideRun[遊具]`（のった子がおりたとき）。目標のクリアは、これで見る。
- テストで目標を進めるときは、村レベルアップの画面（`#lvup`）がひらくと村の時間が止まる（`paused`）。とじながら進める（`tools/tests/wind-stage.cjs`）。
- 草原と同じ遊びのくりかえしにしない（持ち主がきめた）：はじめの目標から風であそぶ。木材をためて橋をかける作業はさせない（木の橋は風のステージではかけられない）。
- 浮き島と雲の海：島でない所は雲の海。雲の海は、マップのはしにつながる `ground` 1 のマス（セーブには入れず、地形から作る）。歩けない・置けない・橋はかけられるのは水と同じ。水としてのふるまい（水をくむ・つり・水あび・ハス・水べの生き物・水の音）を見る所は `S.ground[j]===1` ではなく `waterJ(j)`（本物の水だけ）を使う（`S.ground===1` で見ると、雲の橋から雲の海へ歩き出す。道さがし・ハスを植える・水あびも）。島の中の池は、雲の海から3マスいじょうはなす（はしにつながると、池も雲の海になる）。
- 島どうしは、橋（まっすぐ10マスまで）でぜんぶつなげるようにならべる（たしかめは `tools/tests/wind-stage.cjs`）。
- 雲の海と島のがけの絵は、コードの仮の絵。雲の橋・風のすじ・しずんだ島の雲も、コードの仮の絵。風穴・かざみは3Dから写したチップ（H-2。風穴の白いつぶはゲームで描く）。
- 風のしくみ（`js/wind.js`。セーブは `S.wind`：風穴のマスと向き・うかんだ島だけ。風の道・雲の橋・島の番号は `recount` のたびに作る）：
  - 風穴（`kazaana`。はじめは石でふさがった `kazaanab`）：まん中の島と大きな島に1つずつ。「しらべる」でタップすると、せいれいが石をどける（建てる所のしくみ）。こわせない・うつせない。
  - 風の道：風穴から、きまった向きへまっすぐ。1つの風穴で、曲げた分もあわせて40マスまで。向きの番号は置く家具の向きと同じ（0 手前・1 右・2 奥・3 左）。
  - かざみ（`kazami`、4つの向き、木材3、風のステージだけ `STAGEONLY`）：風の道に置くと、そこで向きがかわる。
  - 風を止める物：木・岩・茂み・建物・家の壁とドア・神殿・風穴。段差はこえる。ランダムに生えた木でも止まるので、テストでは風の道の列をあけてからたしかめる。
  - 雲の橋：風が雲の海をこえて、向こうの陸にとどいた所だけ。`walk`・`wetJ` で歩ける。風の向きをかえると消える。
  - しずんだ島（`windSunk`）：風の道がふれるまで、歩けない・置けない。霧と同じ決まりにするため、`fogAt`・`fogBlock` が風のステージでは `windSunk` を見る（`S.fog` は空の配列。`S.fog&&fogAt(j)` と書いてある所が、そのまま効く）。ふれると、うかぶ演出（霧が晴れる演出と同じ作り。村の切りかえで `windRiseReset`）。いちどうかんだら、しずまない。
  - とりのこされたせいれい：橋が消えて、まん中の島へもどれなくなったら、まん中の島へはこぶ。
  - 追い風：風の道の上を、風と同じ向きに歩くと移動速度1.5倍。
  - 風車・古い風車（見た目だけ）は、風のステージでは、まわり2マスに風の道があるときだけまわる。
- 風の草・花・素材（`tools/art/windgrass/windgrass_art.py`、もらった白い背景の絵は `unwhite.py` ですかす）：雑草はなびき草 `weed4g`・ほうき草 `weed4k`、花はたんぽぽ `tanpopo`（風の村でははじめから植えられる）。雲わた（雲の海のふちの陸）・風の羽（風の道の上・風の小鳥の落とし物）は毎朝、落とし物でわく。草原の草を使う家具は、`mat3`（水）・`mat4`（風）・`mat5`（闇）でその土地の草で作る（実数で書く）。素材を足したら、`MATN`・`MATTRADE`・`GRASSK`・`NOMAT` にも足す。
- 水・闇の草・花・素材（`tools/art/mizuyami/mizuyami_art.py`）：水はあし `weed3g`・がま `weed3k`・アイリス `ayame`、闇は夜つゆ草 `weed5g`・かげ草 `weed5k`・月見草 `tsukimi`（その土地の花は、はじめから植えられる）。粘土は水路をほると1こ、丸石は毎朝、水べの陸に落とし物。闇は、庭の岩をほると月光石、木を切ると古木の材も1こ。たしかめは `tools/tests/stage-mats.cjs`。
- 水の木はオーク（`tree~m`・`deadtree~m`）と、自然の木の4わりはメープル（`maple~m`）。闇の木は枯れたオーク（`tree~y`・`deadtree~y`）。どれもアカシアと同じ作り（`tools/art/nature3d/tree_prep.py`・`furn3d/items/nat_oak.py`・`nat_maple.py`・`nat_deadoak.py`、落ち影も）。
- 風の木はアカシア（植えた木 `tree~k`・自然の木 `deadtree~k`、切ると木材。設計図 `tools/art/furn3d/items/nat_acacia.py`、モデルは `acacia_prep.py`）。ステージでの木の名前は `STAGEN[ステージ]`。風・水・闇でそろえる物の案は `IDEAS.md`。
- 風の家具（しまもようのハンモック・風船の屋台・気球のかごのいす・かざぐるまの花壇・風見のランプ、`STAGEONLY` 風）：まわりのたのしさは、風の道のそば（まわり2マス）では `envW`（実数）、ほかは `env`。水の家具（テラスの席・窓辺の花の鉢・運河の街灯・水路の洗い場）は、水べのそば（まわり2マスに水）で `envW`。気球のかごのいすは、すわれるいす（`SEATS`）。
- 風・水・闇の家のドア（帆布のドア `canvasdoor`・アーチの木のドア `archdoor`・古い庭の木戸 `niwadoor`）は、ふつうのドアの壁ごとの絵の板の所に、コードのドットの板を入れた絵（`tools/art/stagedoor/stagedoor_art.py`、`<壁>.<id>#h0〜3`）。家のドアかどうかは `HDOORS`（`'door'` だけをくらべない）。
- あかりの家具を足したら、`LIGHTS`（あかりの数）だけでなく、夜に光る所と大きさの表 `LIGHTP`（`night.js`）にも足す（入れないと、夜に光らない）。水の大門は運河の町の門（`canalgate`）、闇の大門は古い庭の鉄の門（`irongate`）。月光石の壁は `LIGHTP` だけに入れ、夜にほのかに光る（あかりの数には入れない）。
- 闇の家の壁はこけむした石の壁（`mosswall`）・月光石の壁（`moonwall`）、柵はいばらの生垣（`ibara`）、塀はくずれた石の欄干（`kuzure`）、家具は月光石のランプ・ほたるのかご（あかり）・夜のしとね・月見台。闇の物を作るのは火のせいれい（はじめのヒイロ）。
- 水の家の壁は木組みの壁（`timberwall`）・運河の石積みの壁（`canalwall`）、柵はあしの垣（`ashifence`）、塀は運河の石の欄干（`rankan`）。となりの柵のドアは、その柵・塀の戸の絵（`<柵>.gate#h0〜3`・`#v0〜3`）。その土地の物を作るせいれいは、その土地にはじめからいる属性（風は `wind`・水は `water`）にする（`maker`。ちがうと作れない）。
- 風の柵は、ロープの手すり（`ropefence`、新しい風の村ではじめから使える）。となりの柵のドアは、ロープの戸の絵（`ropefence.gate#h0〜3`・`#v0〜3`。御簾垣の戸と同じ作り）。
- 風の塀は、遊園地の白い塀（`parkfence`・ドア `parkdoor`・入場ゲート `parkgate`、`STAGEONLY` 風）。3Dから写す（`fence3d.py`・`doors3d.py`）。白い物は、ふつうのかげだと灰色になるので、かげをつけない材質（`flat`）で写す。
- 風の家の壁は、帆布の壁（`canvaswall`、新しい風の村のはじめの家・設計図の壁）とアカシアの板壁（`acaciawall`）。3Dとテクスチャで写した5まい（上の面・正面・柱の切り口と正面・たての帯）を、竹の壁の道具で組む（`tools/art/windwall/windwall3d.py`）。壁の正面に光があたる向きで写す（ふつうの光だと、正面がかげになって白い布が灰色になる）。
- 風の村にも、神殿を直したあとから夜にコワイノが来る（目標2の `enemy:true`）。来る所は雲の海のふち（雲の海にとなりあう、村まで歩いて行ける陸）。オオカゲは来ない（`waveFor`。さいごの夜はナギノオオカゲ）。はじめての夜はカザネのひとこと。
- 風のさいごの夜（`js/wind-story.js`）：遊具をねらう影の群れに、ナギノオオカゲ（`EN.nagi`。絵はオオカゲの絵に色をかさねた、かりの絵）が1ぴきまじる。ナギノオオカゲだけは風穴・かざみもねらい、こわすと風穴はふさがり、かざみはもちものへもどる。勝った朝、ヌシ様をもちあげる守り神の出番「風をあつめる」（`WIND_PLAY`：遊具からのぼる風のすじ3本を、指で下から上へなぞる。すじからはなれると風がちる）。3回しっぱいしたら、つぎの日の朝にもう一度。たしかめは `tools/tests/wind-story.cjs`。
- コワイノの来ない夜（`S.flags.calmNight`）：`S.enemyOn` がないと時計は18時で止まる（朝が来ない）ので、コワイノなしで夜をすごさせるステージは、この印で時計を進める。
