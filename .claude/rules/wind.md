# 風のステージ

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。たしかめは `tools/tests/wind-*.cjs`・`stage-mats.cjs`。

## 風のステージ（風のやんだ空の村）
- ステージ番号は4（`WIND`、WORLD 5）。いま遊べるお話のステージは `STAGES`（草原・火山・土・水・風）。ステージを回す所は `[0,1]` と書かずに `STAGES` を使う。
- ステージの番号は、じかに書かず名前で書く（`KUSA`・`KAZAN`・`TSUCHI`・`MIZU`・`WIND`・`YAMI`・`FREE`、`core.js`）。`WD` を見る所で、「草原でない＝火山」（`WD!==KUSA`）と書かない。火山だけの物は `WD===KAZAN`。ステージごとにかわる値（壁・柵・素材の一覧・雑草の絵・日記を書くせいれい など）は、`core.js` の表 `STAGE`（`stg()`）に書き、`WD===KAZAN?…:WD===WIND?…` とつながない。そのステージだけのしくみ（温泉・鉱脈など）を、そのステージのコードの中で `WD===KAZAN` で見るのは、そのままでよい。
- お話は「風のやんだ遊園地」（持ち主がきめた。芯・おわり・さいごの夜・これから作る分は `IDEAS.md` と `STORY.md`）。目標1〜7（`QUESTS5`：風穴 → 神殿 → となりの島へ風をとどける（ハヤテが目をさます）→ メリーゴーラウンドを直す → コーヒーカップ・空中ブランコ → 島をぜんぶうかせる → 観覧車（てっぺんから雲のすきまにつばさが見える、会話の合図 `wind:peek`）→ 雲の下）と、プロローグ・着いてからの会話。はじめからいるのはカザネ（風）、2人めはハヤテ（風。はじめにうかんだ島で目をさます）。
  - 雲の下：雲の海のはしの印（観覧車に近い、南が雲の海の、行ける陸のマス）へカザネ（いればハヤテも）が歩いて待ち（待つあいだ、おなか・たのしさ・つかれはへらない）、そこへまもりの光を落とすと、村の時間を止めて雲がひらき、風のヌシ様が話す。会話をさいごまで見てから、おえたことにする。
  - さいごの夜とおわり（`wind-story.js`）：ひと晩、遊び場を守る（遊具が4つ動けば、その夜に影が来て、遊具を先にこわしにくる。こわされた遊具は、こわれた遊具にもどる。朝に2つのこれば勝ち、負けたら3日あと）→ ヌシ様をむかえる（勝った朝、雲の海のはしからヌシ様がのぼり、遊具の風がつばさになる。そのあとクリア）。場面は村の時間を止める（`wsScene`・`GIFT_ACTIVE`）。ヌシ様の鳥は、3Dから写した絵（`tools/art/windnushi/sheet.py` が assets/g の1まいのシートを作る。大きいのでアトラスに入れず、ヌシ様が出るときだけ読みこむ）。
  - 遊具をねらう影の群れに、ナギノオオカゲ（`EN.nagi`。かりの絵）が1ぴきまじる。ナギノオオカゲだけは風穴・かざみもねらい、こわすと風穴はふさがり、かざみはもちものへもどる。勝った朝、ヌシ様をもちあげる守り神の出番「風をあつめる」（`WIND_PLAY`：遊具からのぼる風のすじ3本を、指で下から上へなぞる。すじからはなれると風がちる）。3回しっぱいしたら、つぎの日の朝にもう一度。
- 遊園地（`wind.js`）：遊具は4つ（`RIDES`：メリーゴーラウンド・コーヒーカップ・空中ブランコ・観覧車。`STAGEONLY` 風）。はじめは、こわれた遊具（`RIDEB`）が島に1つずつ（メリーゴーラウンドはまん中の島）。「しらべる」でタップすると、せいれいが直し（建てる所のしくみ、素材はいらない）、直すとレシピをおぼえる。こわれた遊具は、こわせない・うつせない。
  - 遊具は、風のせいれいが係をしているあいだだけ動き、のれる。係は、のった子がおりるたびに、たのしさ+5。風の道のそば（まわり2マス）の遊具は、係がつかれない。メリーゴーラウンドの依頼のあいだは、ハヤテは係をしない（カザネが動かして、ハヤテがのる）。
  - わすれた楽しさ：風のステージのせいれいは、遊具のほかの遊び家具で遊ばない。はじめて遊具にのる・係をするたびに、遊び方を1つ思い出す。思い出したときは、頭の上にその遊び家具の絵と光・ひとこと。せいれいの画面に「思い出した遊び：〇」。
  - 遊具の絵は、3Dから写したクォータービューのチップ（設計図 `tools/art/furn3d/items/<id>.py`・`ride_common.py`、もとの形 `handoff3d/rides.py` の1.5倍＝せいれいが乗ってちょうどよい大きさ。置くマスはメリー・カップ・空中ブランコ 3×3・観覧車 4×3。写すのは `tools/art/iso/iso3d.py` → `rides_iso.py`）：動かない所 `<id>:s` に、まわる角度のコマの動く所 `<id>:m0〜m15`（コマ＝くりかえし1周期の1/16、チップの `pf`）をかさねる。こわれた遊具は `<id>b` の1まい。のる子の位置は式（`wind.js` の `RIDESEAT`：3Dの式と同じ）で、すわる絵。カップは手前のかべで下半身をかくす（`cut`）。観覧車は、のっているあいだ、せいれいを描かない。
  - 遊具が動いた回数は `S.flags.rideRun[遊具]`（のった子がおりたとき）。目標のクリアは、これで見る。
- テストで目標を進めるときは、村レベルアップの画面（`#lvup`）がひらくと村の時間が止まる（`paused`）。とじながら進める。
- 草原と同じ遊びのくりかえしにしない（持ち主がきめた）：はじめの目標から風であそぶ。木材をためて橋をかける作業はさせない（木の橋は風のステージではかけられない）。
- 浮き島と雲の海：島でない所は雲の海。雲の海は、マップのはしにつながる `ground` 1 のマス（セーブには入れず、地形から作る）。歩けない・置けない・橋はかけられるのは水と同じ。水としてのふるまい（水をくむ・つり・水あび・ハス・水べの生き物・水の音）を見る所は `S.ground[j]===1` ではなく `waterJ(j)`（本物の水だけ）を使う（`S.ground===1` で見ると、雲の橋から雲の海へ歩き出す）。島の中の池は、雲の海から3マスいじょうはなす。島どうしは、橋（まっすぐ10マスまで）でぜんぶつなげるようにならべる。
- 雲の海・島のがけ・雲の橋・風のすじ・しずんだ島の雲は、コードの仮の絵。風穴・かざみは3Dから写したチップ（風穴の白いつぶはゲームで描く）。
- 風のしくみ（`wind.js`。セーブは `S.wind`：風穴のマスと向き・うかんだ島だけ。風の道・雲の橋・島の番号は `recount` のたびに作る）：
  - 風穴（`kazaana`。はじめは石でふさがった `kazaanab`）：まん中の島と大きな島に1つずつ。「しらべる」でタップすると、せいれいが石をどける。こわせない・うつせない。
  - 風の道：風穴から、きまった向きへまっすぐ。1つの風穴で、曲げた分もあわせて40マスまで。向きの番号は置く家具の向きと同じ（0 手前・1 右・2 奥・3 左）。かざみ（`kazami`、4つの向き、`STAGEONLY` 風）：風の道に置くと、そこで向きがかわる。
  - 風を止める物：木・岩・茂み・建物・家の壁とドア・神殿・風穴。段差はこえる。ランダムに生えた木でも止まるので、テストでは風の道の列をあけてからたしかめる。
  - 雲の橋：風が雲の海をこえて、向こうの陸にとどいた所だけ。`walk`・`wetJ` で歩ける。風の向きをかえると消える。
  - しずんだ島（`windSunk`）：風の道がふれるまで、歩けない・置けない。霧と同じ決まりにするため、`fogAt`・`fogBlock` が風のステージでは `windSunk` を見る（`S.fog` は空の配列）。ふれると、うかぶ演出（村の切りかえで `windRiseReset`）。いちどうかんだら、しずまない。
  - とりのこされたせいれい：橋が消えて、まん中の島へもどれなくなったら、まん中の島へはこぶ。追い風：風の道の上を、風と同じ向きに歩くと移動速度1.5倍。風車・古い風車（見た目だけ）は、風のステージでは、まわり2マスに風の道があるときだけまわる。
- あかりの家具を足したら、`LIGHTS`（あかりの数）だけでなく、夜に光る所と大きさの表 `LIGHTP`（`night.js`）にも足す（入れないと、夜に光らない）。水の大門は運河の町の門（`canalgate`）、闇の大門は古い庭の鉄の門（`irongate`）。月光石の壁は `LIGHTP` だけに入れ、夜にほのかに光る（あかりの数には入れない）。
- 風の村にも、神殿を直したあとから夜にコワイノが来る（目標2の `enemy:true`）。来る所は雲の海のふち（雲の海にとなりあう、村まで歩いて行ける陸）。オオカゲは来ない（`waveFor`。さいごの夜はナギノオオカゲ）。はじめての夜はカザネのひとこと。
- コワイノの来ない夜（`S.flags.calmNight`）：`S.enemyOn` がないと時計は18時で止まる（朝が来ない）ので、コワイノなしで夜をすごさせるステージは、この印で時計を進める。

## まとめ（細かい作りはコードを見る）
- 風・水の家具は、風の道・水べのそばで `envW`（実数）、ほかは `env`。風・水・闇の家のドアは `HDOORS` で見る（`'door'` だけをくらべない）。その土地の物を作るせいれいは、その土地にはじめからいる属性にする（`maker`）。
- 風の家の白い物は、かげをつけない材質（`flat`）で写す。草・花・素材を足したら、`MATN`・`MATTRADE`・`GRASSK`・`NOMAT` にも足す。
- 風のさいごの夜は、遊具をねらう影の群れにナギノオオカゲがまじる（風穴・かざみもこわす）。勝った朝、守り神の出番「風をあつめる」でヌシ様をもちあげる。
