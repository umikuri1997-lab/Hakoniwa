# 土のステージ

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。洞窟は `cave.md`。

## 土のステージ（ひびわれた岩の谷）
- ステージ番号は2（`TSUCHI`、WORLD 3）。火山でヌシ様をむかえたら、ひらく（とじたカードを5回タップでもひらく）。お話は「ちいさなあなぐま」（`IDEAS.md`・`STORY.md`）。PRのならびと進みは `STATE.md`。
- はじめからいるのはトト（土、ねばりづよい）。2人めのキーキャラはハニ（土。はじめは木のコノハで、古いセーブは `MIGRATIONS` の v13 でハニにする）。お話に出る火のせいれいはイブキ。村は夕方16時からはじまり、はじまりの地ゆれ（`tsIntro`：カメラが巣穴へ・ゆれ・トトがころがり出る）のあとに会話。
- 地われ：北のはしから南のはしへ、谷をたてに割る1本（`tsRift`）。ground 1 で、マップのはしにつながる所が地われ（`riftM`・`riftJ`。雲の海と同じ作り・セーブには入れない）。水のふるまいは `waterJ` で見る（地われは水ではない）。歩けない・置けない・橋はかけられない。せまい自然の岩の橋（`TSBRY` の2行）が1つ。
- 谷：東・西・北のまわりは高いがけ（`tsWallK`）。川はない。北のがけのふもとに、あなぐまの巣穴（`anagura`。こわせない・うつせない）。洞窟の入口になる（神殿のあと、巣穴をタップして出かける）。
- 土の物（数は実数・`STAGEONLY` 土・作るのは土のせいれい）：日干しれんがの壁・岩をくりぬいた壁・木のいた戸・石ころの垣と、その戸（`ishidoor`。ほかのステージの「柵のドア」とはべつの物）・砂岩の塀とドア・岩のアーチの門。木はオリーブ（`~t`）、雑草はいわ草 `weed2g`・かれすすき `weed2k`、花はいわかがみ（はじめから植えられる）。素材は砂岩（谷の岩をほると、まず砂岩 `TSSAGAN`、持てる数ののこりで石材）。草原の草を使う家具は `mat2`。
- くずれた岩の山（`S.ts.rub`、`tsRubGen`）：谷のはしのがけのふもとに10（洞窟の階の数）。1つずつ、半径3.6マスのマスを `tsrubble`（こわせない・うつせない・歩けない。もとの自然の物は `keep` にとっておく）でふさぐ。ふさいでも、ほかの土地へ行けること（`reach`）をたしかめて置く。1つめは地われの西がわの、村にいちばん近い所。洞窟の階をはじめてクリアした数（`S.cvClr`）だけ、村にもどったあと（`tsTick`、画面があいているとき）カメラが行って、ゆれてくずれる（`tsRubOpen`）。古いセーブは `MIGRATIONS` の v11 で作り、7つのセーブは v14 で、のこりの3つを足す（`tsRubGen` は足りない分だけ作る）。
- 夜（`js/tsuchi-night.js`）：ツチノオオカゲを追いかえすと `S.enemyOn`（古いセーブは `MIGRATIONS` の v12）。つぎの夜から、コワイノとバケモノが谷の地われのふち（`tsRiftSpot`、村のまん中から10マスより遠い所。群れの夜は1か所のまわり）から来る。数はほかのステージと同じで、そのうち3びきに1ぴきが、洞窟でひらいた階（`S.cvClr`）のバケモノ（`tsBkWave`。ひらいた階から、じゅんばんに。持ち主がえらんだ）。オオカゲは来ない。朝、バケモノは消えずに、歩いて地われへもどる（`tsBkMorning`・`e.home`）。村でもうごくとくちょう：夜の水のかたまりは2つにわかれる・組みかけのほねは、たおしても `CVHONET` 分で組みなおす（くずれたあいだは `e.down`・`spawned:false`。まもりの光でとどめ `tsBoneLight`）・炉にくべられたものの通った所は、あつい床（`TSHOT`。セーブしない）。光すい・ためしのからだ・ゆりかごのみはりのとくちょうは、洞窟だけ。絵は洞窟と同じ `cvBkDraw`。トトが根になったあと（`S.ts.totoRoot`）は来ない（`tsBkWave`。コワイノは来る）。
- 彫り絵3（6階・`TSCARVE` の fl:5）：ツチノオオカゲを追いはらったあとに出て、見るとトトがにげる（`tsTotoFlee`：`S.ts.totoGone` にとっておく。村・パーティからいなくなる。トトはもどらない：10階で根になる `tsuchi-oku.js`）。トトのいない村で、トトのセリフを出さない（`S.res.find` の結果をたしかめる）。
- 石の大橋（`js/tsuchi-bridge.js`）：岩の橋の南2行の地われ6マスを、せいれいが1マスずつかける（工事 `site`・できたマスは ground 0・`S.ts.brd`）。タイルは `tsKind` が 'b' を返すマス。らんかんの花は `S.ts.brFlower`（仮の絵）。
- 洞窟のいちばんおく（`js/tsuchi-oku.js`）：目標 `tsoku`。10階の島の前に、にげたトト（`S.ts.totoGone`。パーティの外・`cvActorsL` で描く）。かげのゆりかご（`EN.tsuchi` を `C.en` に入れ、`tsOkuTick` がうごかす。`cvFoe`・`cvTarget` はさける。光は `cvLightHit` から `tsOkuLight`）。ふれたせいれいは `a.tsSleep` のあいだ動かない。おわると `S.ts.totoRoot`（トトは村にもどらない）。
- お話のおわり（`js/tsuchi-nushi.js`）：根になったあと、村で巣穴の南にトトの根（`tsroot`・`S.ts.rootJ`）。目標 `tsnushi`：つぎの日の昼（9〜16時）に根のそばへ集まり（`gatherAt`）、ハニが子どものあなぐま（`tsnushi`・`S.ts.haniNushi`）になって `S.res` から出る。目標がおわるとクリア（`tsClear`：`S.cleared`・`clearSnap`）。根とあなぐまは、こわせない・うつせない（`NOMOVE`）。
- 地われをうめる（`tsuchi-bridge.js`）：石の大橋のあと、橋のとなりの行（北は `TSBRY-1`・南は `TSBR2Y+2`）から1行ずつ、北・南 `TSFILLROWS` 行まで（`tsFillRow`）。材料・時間は橋と同じ。できたマスは `S.ts.brd`。切りはなされた地われのマスは水になるので、帯の中をうめる（`tsRiftSeal`）。
- 地ゆれ（`js/tsuchi-quake.js`）：橋のあと `TSQKEVERY` 日ごと（`S.ts.qk`）。前の日に知らせ、その日の昼に、ささえの柱（`tspillar`・土の家具）から `TSPILR` マスより遠い家の壁が `TSQKWALL` まいくずれ（`S.broken` に入る。夜のこわれと同じ）、がけのふもとに岩が落ちる。壁は `breakable` でないものもあるので、朽ちさせず、くずして建てなおす。
- 粘土とやきもの（`js/tsuchi-yaki.js`）：谷の岩をほると砂岩のあと、持てる数がのこっていれば粘土 `TSNENDO`（`spirit-act.js` の mine）。粘土の窯（`tskama`・`PROC`）で粘土3こ→やきもの（`yaki`）1こ。やきものでつぼ（`tsubo`）。`yaki` は土以外では出ない（`NOMAT`）。かわら・土の壁は作っていない。
