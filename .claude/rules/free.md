# フリーモード

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。

## フリーモード
- フリーモード（`WD===FREE`・`S.free`、`js/free.js`）は、草原をクリアすると開く、自由に作る土地。コワイノは来ない（守りの物は出さない）。セーブは `hakoniwa-free-v2`（前のセーブは引きつがない。持ち主がきめた）。
- 神殿もカミサマもない。おそなえ箱と依頼ボードは、はじめから村にべつべつに置いてある。おたきあげ・季節のささげもの・なかまを呼ぶ「！」はない。神殿があるかを見る所（`STATUE>=0`）を足すときは、フリーモードで止まらないか見る（置けるかは `noTemple()`、場所は `OBOX` をかわりに）。
- なかまは呼ばない。属性の力がたまると、朝に谷の南の切れ目からやってくる（1日1人）。消えたせいれいは呼びもどせない。
- 土地をクリアすると開く（`freeTier`：0 草原まで・1 火山まで）。火山をクリアすると：火と水のせいれい・火山の物（`BL` の `w`・`STAGEONLY`・竹が谷に生える）・鉱脈と炉とそうび・おまつり・火山のイベントと魚。火山のよみがえる温泉3か所と、それを使うイベントは入れない。新しい土地を足したら、`freeTier` と、開く物をここに足す。
- マップは花の谷：川はなく、丘がぐるりとかこみ、南に1か所だけ切れ目、池4つ・木立。野の花は見た目だけで、物・床を置くとなくなる。
- お話は、本編でしたことのくりかえしにしない（持ち主がきめた）。第1章は、数ではなく、やり方をえらべる目標（家の住み心地の★・好きなスポット・なかまをむかえる・好きなイベント・すてき度の★）。おまつりのあとは、第2章（火山をクリアしてから）→ 季節の話4つ → きょうの目標・やりこみ（コワイノの目標はのぞく）。どれも、依頼の会話 → その話を受けてからした行動 → お礼の会話。話すのは、はじめの2人（`FA`・`FB`）だけで、いないせいれいの行ははぶき、`FA` がいなければはじめない。
- 季節の話は、フリーモードだけのあつまり：春 花見（野の花のむれ）・夏 夕すずみ（池）・秋 どんぐりひろい（木立）・冬 丘の星見。場所は物ではなく谷の所（`EVNEED` の `at`）。
- 交換は、旅のお客さん（3日に1回、朝に来てつぎの朝に帰る。タップでお店）。火山をクリアすると、火山のお客さんもふえる。
- くらしのしくみ（手紙・ゆめ・こまりごと・設計図・もりのこだま・流れ星・おでかけ・けんかと仲なおり・村の記録・図鑑の節目・おくりもの・宝の地図）は、フリーモードでも動く。新しいしくみを `S.free` で止めない（草原・火山のお話にかかわる物だけ止める）。
- たしかめは `tools/tests/free-mode.cjs`。
