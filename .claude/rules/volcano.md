# 火山のステージ

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。

## 火山らしさ
- 温泉のまん中の場所（`HSPC`）はマスのまん中にそろっていない。そこをめざして歩かせると、立つ所が見つからずに歩かない。水べへ歩かせるときは `volSpringEdge`（水のマスの左右となり）を使う。
- 冷たい温泉を調べよう（`coldSpring`）は、入口の温泉にはホムラが着いてからの会話でさわるので、西と奥の2つを調べる。
- 奥の装置のまわりの大岩は、たたいてもくだけない。まもりの光で熱すると赤くなり（時計の2時間）、水のせいれい（いなければ、だれでも）が水をかけるとわれる。水路の大岩は、いままでどおり、たたいてくだく。
- 火山の噴火は、もうある（5日に1回、朝に村の外へ岩が3〜5こ）。「ない」と言わない。
- たけのこをタップすると「とる・そだてる」をえらべる。そだてる印のたけのこは、せいれいがとらない。竹になった数は、サブクエスト「竹をそだてる」で数える。
- 火山のサブクエスト：あたたかい畑・湯めぐり・竹をそだてる。前の石の塀10・行燈・ししおどしのサブクエストはなくした。
- 守護の台座（火山）は、建てただけでは山の影は来ない。昼に「しらべる」で台座をタップ → ホムラ（いればシズクも）が台座の前へ → 話す → 守り神の出番「火入れ」（おして火を大きく・はなして小さく、うごく帯の中に合計8秒）→ 火がともる → 話す。火を入れたことにするのは、さいごの会話のあと。その夜に来る。3回しっぱいで、つぎの日。止まるわけは目標の進みぐあいに出す。火山の出番は `VOL_PLAY` に足す（`FIELD_PLAY` は草原の4つだけ）。たしかめは `tools/tests/altar-light.cjs`。
- 火山の木：自然の木も植えた木も、とんがりの木（杉の絵。`tools/art/furn3d/items/nat_cedar.py`・`nat_cedar2.py`。名前は `STAGEN`）。カミサマのお店は、火山でも木の苗を「とんがりの木の苗」として売る。
- カミサマのお店の花のたね・りんごの苗は草原だけ。火山では、温泉宿のお客さん（ゲストの会話のあと、3日に1回、朝に来てつぎの朝に帰る。夜は出ない）が売る。
- ようがん台は、はじめからおぼえていない。見張りのおねがいか熱をひくお話の会話でおぼえる。
- 火山の柵は御簾垣（`misugaki`、`STAGEONLY`。板の柵は草原だけ）。となりが御簾垣の柵のドアは御簾垣の戸。
- 依頼ボードと「建てる」は、ふだん「この土地」の物だけ出す（この土地のお話・村レベル・思いつきでおぼえる物は、この土地の物）。「ぜんぶ」で、ほかの土地でおぼえた物も出す。

## 火山の竹
- 竹は素材の1つ（木材・石材とおなじ箱にしまう）。画面の上の竹の数は、火山か、竹を持っているときだけ出す。
- 火山には、枯れ木と竹（自然物）が生える。竹を切ると竹（きこりは+1）。せいれいは、木材と竹の、すくないほうを先に切る。伐採場は木材のまま。
- たけのこ：火山の朝、竹1本ごとに、となりの空いた草地に生える。火山にベリーの茂みはない。せいれいがとると食べ物「たけのこ」×2になって、なくなる。とらずに3日たつと竹になる。
- 竹の柵は火山で村レベル4から。竹のベンチ・竹あかり・ししおどしは、はじめて竹を手に入れたときに思いつく（火山のレシピ。`STAGEONLY`）。
- 火山で素材がかわる物は、`BL` に `mat1`（火山での素材。実数）を書く（いま：いす・スツール・ブランコ・たいまつ）。
- 竹のベンチは、ふつうのベンチと同じく休める（ベンチかどうかは `BENCHES.has` で見る）。
