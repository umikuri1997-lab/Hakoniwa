# 火山のステージ

`CLAUDE.md` の決まりのつづき（この話題の作業をするときに読む）。ぶつかったら `CLAUDE.md` が先。

## 火山らしさ
- 温泉のまん中の場所（`HSPC`）はマスのまん中にそろっていない。そこをめざして歩かせると、立つ所が見つからずに歩かない（`volWalk` の `side`）。水べへ歩かせるときは `volSpringEdge`（水のマスの左右となり）を使う。
- 冷たい温泉を調べよう（`coldSpring`）は、入口の温泉にはホムラが着いてからの会話でさわる（`vol:touchA`）ので、西と奥の2つを調べる（`sprLookTap`・`sprLookN`。前のセーブの `true` は、調べおわったことにする）。
- 火山の出番（`sacred-play.js` の `VOL_PLAY`、絵は `VOLTYPES` で灰まじりの土）：火入れ `towerLight`・かじとり `heatCrank`（手前の熱の装置を、はじめて西へむけるとき。ハンドルを円をえがいて3回転。`S.st2.crank`。2回めからは、ボタン）・湯もみ `yumomi`（シズクのおねがい `shizukuRest`：依頼を聞いたあと、昼に入口の温泉をタップ `yumomiTap`。左右に12回。`S.st2.yumomi`、しっぱい3回でつぎの日 `yuRetry`）。出番の操作は、草原の4つとも、たがいにも、ちがう物にする。
- 奥の装置のまわりの大岩（`BVOL`、`rockHard`）は、たたいてもくだけない。まもりの光で熱すると赤くなり（`rockHeat`・`S.st2.hot`、時計の2時間 `ROCKHOT`）、水のせいれい（いなければ、だれでも）が水をかけるとわれる（`goQuench`・`quench`・`rockCrack`）。水路の大岩（`S.st2.bw`）は、いままでどおり、たたいてくだく。
- 火山の噴火は、もうある（`eruptMorning`：5日に1回、朝に村の外へ岩が3〜5こ）。「ない」と言わない。
- ゆでかご（`yudekago`、火山。`STAGEONLY`・`RLOCK`）：あたたかい温泉の、岸のすぐそばの水のマスに置く料理の家具（`canPlace1`。水の上に置ける物は、ハス・橋・ゆでかご。描くのは `draw-world.js` の水のマスの例外）。湯がぬるいと作れない（`hotW`）。料理は表のさいごに足した「ゆでたけのこ」「おんせんたまご」（`cook_table.py` の `Y`。作るのは水のせいれい）。ホムラのおねがい（`yatai`）は、ゆでかごの料理を2こ（`S.st2.yude`）。絵は3D（`tools/art/furn3d/items/yudekago.py`。水面から上だけ。あみかけは設計図の `DITHER` で最小限）。料理の家具を数える所は `COOKST` を使い、名前をならべない（ゆでかごだけの村で、料理をはじめなかった）。
- たけのこをタップすると「とる・そだてる」をえらべる（`takenokoPop`）。そだてる印（`S.dyn[j].keep`）のたけのこは `g` を0にして、せいれいがとらない。竹になった数は `S.st2.tkGrew`（サブクエスト `takegrow`）。
- 火山のサブクエスト：あたたかい畑（`warmfarm`：`S.st2.warmH`）・湯めぐり（`yumeguri`：`S.st2.yuS`）・竹をそだてる（`takegrow`）。前の石の塀10・行燈・ししおどしのサブクエストは `migrateVolSub`（`S.flags.volSub1`）でけす。
- たしかめは `tools/tests/volcano-plays.cjs`。
- 守護の台座（火山）は、建てただけでは山の影は来ない。昼に「しらべる」で台座をタップ → ホムラ（いればシズクも）が台座の前へ → 話す → 守り神の出番「火入れ」（`VOL_PLAY` の `towerLight`、`bellows`：おして火を大きく・はなして小さく、うごく帯の中に合計8秒）→ 火がともる → 話す。火を入れたことにする（`S.st2.lit`・`altarLit`）のは、さいごの会話のあと。その夜に来る（`S.finalNight`）。3回しっぱいで、つぎの日（`S.st2.litRetry`）。止まるわけは目標の進みぐあいに出す（`altarWhy`・`altarProg`）。古いセーブは `S.flags.altarLit1`。火山の出番は `VOL_PLAY` に足す（`FIELD_PLAY` は草原の4つだけ）。たしかめは `tools/tests/altar-light.cjs`。
- 火山の木：自然の木（`deadtree`）も植えた木（`tree`）も、とんがりの木（杉の絵。チップ `deadtree~v`・`tree~v`、`tools/art/furn3d/items/nat_cedar.py`・`nat_cedar2.py`。名前は `STAGEN`）。カミサマのお店は、火山でも木の苗を「とんがりの木の苗」として売る。
- カミサマのお店の花のたね・りんごの苗は草原だけ。火山では、温泉宿のお客さん（`VISITORS`、ゲストの会話 `guestDone` のあと、3日に1回、朝に来てつぎの朝に帰る `visitMorning`。夜は出ない）が売る（`vshop`）。
- ようがん台は、はじめからおぼえていない。見張りのおねがい（`yogan1`）か熱をひくお話（`fire3`）の会話でおぼえる。古いセーブで使っていなければわすれる（`S.flags.yogan2`）。
- 火山の柵は御簾垣（`misugaki`、`STAGEONLY`。板の柵は草原だけ）。となりが御簾垣の柵のドアは御簾垣の戸（`misugaki.gate#h0〜3`）。
- よみがえった温泉の水べには石組み（`drawOnsenRim`・`rimStones`）：水のマスの形を、角を丸めたなめらかな形（あけしめ、半径 `RIMR`）にして、そのふちに石（`rim:c0〜3`）を1こずつならべる。石が水のマスの角をかくして、丸い温泉に見える。温泉の水・よみがえりがかわったときだけ作りなおす。湯のわき岩は石組みになじむ絵。
- 温泉の効き目は温泉ごと（`SPR_EFF`・説明 `SPR_TXT`）：入口はつかれ、西はたのしさ、奥はおなか。せいれいは、いちばん要る効き目の温泉へ行く（`goBathe`）。熱の道は夜ほんのり光る（`heatGlow`）。熱の道のそばの畑は、もとから「あたたかい畑」（`warmSet`）。
- 依頼ボードと「建てる」は、ふだん「この土地」の物だけ出す（`otherLand`・`nativeSet`：この土地のお話・村レベル・思いつきでおぼえる物は、この土地の物）。「ぜんぶ」で、ほかの土地でおぼえた物も出す（`RECALL`）。
- 火山の物語の山場（`kagari.js`）：おまつりのあとの「かえり道のあかり」（`kagari`）。村の南の入り口のあかり（`kaeribi`、こわせない・うつせない、`S.st2.lamp`）を、カガリが帰るまでホムラがまいばん夕方にともす（`goVigil`・`ACT.vigil`、ともした夜だけ光る `kgrLit`）。依頼を聞いたつぎの夕方、カガリ（`KAGARI`、火・あねごの型）が南の道から自分で歩いて帰ってくる（「！」の呼び出しは使わない。`kgrReturn`。会話をさいごまで見てから `S.flags.kagariCame`、とちゅうでとじたら、つぎの夕方にはじめから）。カガリの行は、カガリがいない村ではぶく（`ideaDialogue`）。幕間「影のがわ」（会話のない場面3つ、夜20時から1晩に1つ・村の時間を止める `kgrIvPlay`・`S.flags.kgrIv`）と、クリアのあとのさいごのうずみ火（`kgrEndGather`・`S.flags.kgrEnd`。そのあいだクリアのあとの依頼を出さない）。前のセーブの番号は `migrateKagariIns`（`S.flags.kgIns1`）。たしかめは `tools/tests/kagari.cjs`。

## 火山の竹
- 竹（`S.mat.bamboo`）は素材の1つ（木材・石材とおなじ箱にしまう）。画面の上の竹の数は、火山か、竹を持っているときだけ出す（`bambooOn`）。
- 火山には、枯れ木と竹（`bamboo`、自然物）が生える。竹を切ると竹（きこりは+1）。せいれいは、木材と竹の、すくないほうを先に切る。伐採場は木材のまま。
- たけのこ（`takenoko`）：火山の朝、竹1本ごとに12%で、となりの空いた草地に生える（マップに24本まで）。火山にベリーの茂みはない（古いセーブは `S.flags.noBerry1` でけす）。せいれいがとると食べ物「たけのこ」×2になって、なくなる。とらずに3日たつと竹になる。
- 竹の柵（`bamboofence`）は火山で村レベル4から。竹のベンチ・竹あかり・ししおどしは、はじめて竹を手に入れたときに思いつく（火山のレシピ。`STAGEONLY`）。
- 火山で素材がかわる物は、`BL` に `mat1`（火山での素材。実数）を書く（いま：いす・スツール・ブランコ・たいまつ）。
- 竹のベンチは、ふつうのベンチと同じく休める（ベンチかどうかは `BENCHES.has` で見る）。
