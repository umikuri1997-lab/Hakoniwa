# ゲームを3Dにする（持ち主がたのんだ・ボタンでえらんだ）

## きまったこと
- ぜんぶを3Dに（すべてのステージ・物・エフェクト）。2Dの描き方は、すぐにやめて3Dだけにする（2Dにもどす設定は作らない）。
- 見え方は、試作（proto3d）と同じ：遠近のあるカメラ・上と下のぼかし（ミニチュア）・トゥーンのかげ2だん・見え方 B（ひかえめ）。タップでマスをえらぶしくみは、このカメラに合わせて作りなおす。
- すすめ方は、土台から順に（持ち主がえらんだ）：
  1. 土台：ゲームの中に3Dの描き方（地形・カメラ・タップ・せいれい）を作り、草原から動かす。
  2. furn3d などの設計図（`tools/art/furn3d/items/*.py` 717こ・`oblique3d.py` の `scene_tris`・`to_mesh`）を glb に書き出す道具を作り、物をまとめて入れる。
  3. 設計図のない物を作る（料理の絵 約150・花と雑草・生き物・洞窟・水・土の物など。植物はスキル realistic-plant-3d で写真から）。
  4. ほかのステージ。
- 3Dの形がまだない物は、そのあいだ、いまのドット絵を立てた板（ビルボード）で出す。
- 持ち主は「ほとんど3Dからドット絵で作ったので、3Dの元があるはず」と言っている。名前で合わせただけだと、ゲームの絵 約490しゅるいのうち、furn3d と名前が合う物 約130・ほかの3Dの道具 約15・合わない物 約350（ちがう名前で設計図がある物もあるはず。対応表は2で作る）。

## わかっていること（しらべた）
- ゲームの描き方：Canvas2D（`js/draw-ground.js:4`）。ループ `js/main.js` の `frame`→`render`（`js/draw-world.js:179`。奥行き順の配列で、せいれい・物を描く）。物 `drawObj`（`js/draw-objects.js`）・せいれい `drawSpirit`（`js/draw-spirits.js`）。
- マップ 108×108（`js/core.js` W・H・TS=32）。段差 `S.hi`。マスの番号 y*W+x。草原 `KUSA=0`。
- 画面→マス `s2w`（`js/iso.js`）・`toWorld`・`tapW`（`js/input.js`）・`pickCell`（`js/build.js`）。カメラ `camAt`・`camShift`。
- UI は canvas に重ねた DOM（`#topUI`・`#botUI`・`#dialog`）。
- three.js はゲームにはない（`proto3d/vendor/three.module.min.js` だけ）。試作の描き方は `proto3d/main.js`（重さの直し：せいれいはしゅるいごとにまとめて描く・角度でスムーズ60度 `creaseSmooth`）。

## 1 土台のはじめのPRの作り（持ち主がボタンでえらんだ）
- three.js は importmap で読む（ビルドの道具はふやさない）。3Dの部分だけモジュール（`js/3d/`）にして、`window.R3D` から今のプログラムがよぶ。公開の道具（`tools/jsver.cjs`・`tools/minify.cjs`）と `sw.js` の保存に、モジュールのファイルと three.js を足す。
- 試作のコード（見え方の数字・シェーダー・地形・せいれいの描き方）は `js/3d/` の部品に分けてゲームへうつす。proto3d はそのままのこし、もう直さない（くらべる見本）。
- タップ：地面は、指の所からカメラの光線を出し、段差の高さの表（`S.hi`）とあたる所を計算する。物・せいれいは、3Dの足もと〜頭の箱を画面へ写し、指に近い物をえらぶ。どれをえらぶかの判定は今のまま使い、位置のもとめ方（`s2w`・`tapAt`・`tapPt` など）だけかえる。
- はじめのPRから3Dだけ：地形・カメラ・タップ・せいれい（3D）と、ほかの物ぜんぶ（ドット絵の板）を3Dで出し、2Dの地面・物の描き方は使わない。草原いがいのステージも、地形は3D・物は板で出す。置ける所の色・わくなど、重ねる表示も3Dで作りなおす。

## 1 土台のはじめのPR（作っている。ブランチ 3d-base）
- できた：`js/3d/`（`r3d.js` カメラ・しあげ・window.R3D／`terrain.js` 地形・水・地面にはる絵／`spirits.js` せいれい／`sprites.js` 板／`mats.js`・`look.js` 見え方）、three.js は `js/3d/vendor`。せいれいの形は `tools/3d/bake-spirits.cjs` → `assets/3d/sp-*.bin`、地面の絵は `tools/3d/copy-tex.cjs`。
- つなぎ（`js/draw-3d.js`・`js/iso.js` の G3）：render の地面の上の物は地面の絵（3Dの地形にはる）、立てる物は ctx.drawImage をうけとめてチップの絵の板に（コードで描く物は毎コマ描く絵のページへ）、せいれいの体は3D（ふきだし・持ち物は #cv に3Dのカメラで写した所へ）。画面⇔せかい（s2w・w2s・camAt・camShift・tapAt・standS・isoView）は3Dのカメラ。
- まだ：洞窟は2Dのまま（cv3 をかくす）。せいれいの姿勢（すわる・寝る・作業）・時間の色（dcGround）・HD-2D の仕上げ（hdPost）・写真（phTick）は3Dでは、まだ。道・床の色は仮（G3FCOL）。テストの直し・スマホでの重さは見ていない。
