# reference/

Frozen material from deleted work. Nothing here is imported, built, or tested.
`build.mjs` bundles `src/main.js` only, so nothing in this directory can reach
`dist/frostwood.html`.

This is not an archive of everything that was removed. Git history holds that.
It holds the two things worth reading again before drawing a human.

| File | What |
|---|---|
| [v1-figure.md](v1-figure.md) | The V1 proportion, garment and gait tables, with why a 3.71-head figure read better than an anatomical one |
| [v1-figure.txt](v1-figure.txt) | V1 traveller pixel dumps, three facings, walk and idle, materials and values |
| [merchant-load.md](merchant-load.md) | The merchant's pack: the world-anchor trick, and what a future figure owes it |
| [merchant-load.js](merchant-load.js) | The pack outlines and feature recipes, rig-free |
| [merchant-load.txt](merchant-load.txt) | Merchant pixel dumps, three facings, every walk frame |
| [captures/v1-cast.png](captures/v1-cast.png) | Real GPU frame, V1 cast |
| [captures/retro-cast.png](captures/retro-cast.png) | Real GPU frame, retro cast, merchant third from left |

Everything else about the human figure was deleted on purpose. Three rig
generations accumulated because each was kept alive as a comparison for the
next. Do not restore one to compare against.
