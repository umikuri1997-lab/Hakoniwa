# ゲームの地面・床・道の絵（3Dの道具・GPT 用の写し）

ゲームのマップチップ（`assets/chips` のアトラス）と洞窟の水から書き出した物。作りなおすときは `python3 tools/art/textures/game_export.py`（チップの絵がかわったら動かす）。ここの絵をかえても、ゲームの絵はかわらない（ゲームの絵をかえるのは `tools/chips.py`）。

細かさ：地面・床・道は、ゲームの地面の下絵と同じ1マス32ドット（`tex-*` だけ大きい1まい）。洞窟の水は1マス64ドット。

## くりかえしてつながる面
- `tex-grass.png`・`tex-dry.png`：草原の草地・あれ地（224×224、どちらもそのままくりかえしてつながる。あれ地は左右・上下の反転でもつながる）。
- `tex-planks.png`（木の板）・`tex-granite.png`（みかげ石）・`tex-water.png`（水）：128×128、くりかえしてつながる。
- `ground_0〜7`：草原の地面のばらつき。`groundr_0〜7`：火山の灰まじりの地面。1マスずつ。
- `path_0〜3`（あぜ道）・`gravel_0〜3`（砂利道）：どの順にならべてもつながる4しゅるい。
- `stone_2x2`（石畳・石の床の道）・`brick_2x2`（レンガ道・レンガの床）・`floor_2x2`（フローリング）・`herrfloor_2x2`（ヘリンボーンの床）：2×2マスでつながる1まい。
- `stonefloor_4x4`：石の床。4×4マスでつながる1まい。
- `cave-water_1`：洞窟の地底の水の、まわりも水のまん中の1マス（64×64）。`cave-water_3x3`・`cave-water_pool5x4`：岸のふち・丸い角のついた水たまりの見本。
- `carpet`（じゅうたん）・`farm`（畑の土）・`rug1`・`rug2`・`hoshirug`（ラグ）：1まいの絵。

## edge（つなぎ方の部品）
- `stone-0〜14`・`brick-0〜14`：道のへり（つながりの番号ごと）、`-c0〜3` は内がわの角。
- `farm-0〜15`・`farmw-0〜15`：畑・ぬれた畑の、上下左右のつながり16とおり。
- `fringeg-U/D/L/R/c0〜3`：草地のふち。`carpet-U/D/L/R`：じゅうたんのふち。
