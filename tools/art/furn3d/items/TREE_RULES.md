# 木を作るルール（持ち主の指示をまとめたもの。木を作る・直すときは、作る前と写したあとに、毎回これと絵を見くらべる）

## 骨格（幹・枝・根）
- 根もと → 幹 → 主枝 → 側枝 → 小枝 → 細枝 → 葉、の順につながる1本の木。葉をとっても、自然な広葉樹の骨格として成り立つ。
- 幹は根もとが太く、上へなめらかに細くなる。完全な円柱にしない（少しいびつ・ゆるい曲がり）。
- 根は幹の下がそのまま、ひくく・なだらか・不規則に広がる。板・三角・台座・独立した突起にしない。継ぎ目を作らない。
- 主枝は3〜5本。ななめ上へ（横へ長くのばさない）。左右非対称、長さ・向きはまちまち。主枝どうしを交差させない。
- 分かれ方は段階的（Y字が基本）。1か所から大量に出さない。分かれた子は親より細い。子の長さ・角度に差をつける。分かれる位置の間かくは、まちまち。
- 枝は直線の棒にしない。ゆるい曲線。太い枝はゆるく上へ、細い枝の先は葉の重みで少し下がる。U字・フック・急な折れ曲がりにしない。
- 枝の太さは、つけ根から先へ、なめらかに細くなる。つけ根にえり（ふくらみ）。太い枝を急に終わらせない（切断面にしない）。先は葉群につながる。
- トゲ・槍のような細枝、葉のない尖った枝先、枝の途中の短い突起を大量に作らない。枝が面にそってはう・鳥かごのような形にしない。
- 葉の有無で、幹・枝の骨格をかえない（骨格は1回作って tree_skel.json に固定し、葉つきは読んで葉をたすだけ）。

## 葉
- もらった葉1まいのモデル（tripo/kit_leaf.glb）を使う。形はかえてよい（しなり・葉柄の立ち上がりの修正など）。大きさは1つ。
- 葉の表は上・外がわ。裏が上を向かない。上下さかさ・極端なねじれは禁止。回転は葉柄を基点に。
- 葉柄のはしは枝につく。葉を空中にうかせない。
- 葉は小枝・細枝にそって、互い違いに。1点から放射状・花束・ロゼットにしない。枝先だけに集中させすぎない。
- 葉どうしを交差させない。かわらのように重ねる（上の葉が下の葉のつけ根にかさなる）。
- 葉の向きは枝の向きと重力が基本。ばらばらになりすぎない。

## 樹冠
- 樹冠の形を先にきめ、枝はその中。葉は外へはみ出さない（外がわはなめらか、小さな凹凸）。
- お手本（ビルダーズの木）：横に広いドーム・かさ。ふちはたれる。葉は大きめで、外・下へ向いてかわらのように重なる。枝は樹冠の下に少し見えるだけ。
- 1つにつながった樹冠。丸い葉の塊をブドウの房のように分離させない。完全な球にしない。大きな空洞を作らない。中央・下部にも葉。
- 幹はやや短め・太め。かわいいデフォルメ。

## 進め方
- 写したら、まず骨格だけの絵で、上の骨格のルールを1つずつたしかめる。おかしければ葉をつける前に直す。
- 葉つきは、お手本とならべて、ちがう所を自分で見つけて直してから見せる。
- 見せる絵：リアルなレンダリング（tools/art/realrender）。骨格だけ・葉つき・低いカメラ。
