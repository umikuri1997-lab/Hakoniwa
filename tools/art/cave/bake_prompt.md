# 洞窟のバケモノ：トリポ（Tripo）にたのむプロンプト（1つにまとめる）

1つのモデルに9こをならべてたのむ。もらったら `tools/art/models/tripo/tripo_split.py` で切りわけ、`tools/art/models/tripo/cave_bake.glb` に入れる。
左から：1 くいのホムンクルス・2 光すい・3 夜の水のかたまり・4 ためしのからだ・5 組みかけのほね・6 炉にくべられたもの・7 ゆりかごのみはり・8 えさ（正体）・9 ほりつづける手。
声のこだまは姿がない・見はりの目は目だけなので、モデルはいらない。えさの化けたすがたは、村の小さな生き物の絵を使う。
