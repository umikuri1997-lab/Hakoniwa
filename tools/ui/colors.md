# UIの色の役目

画面（UI）の色を、役目ごとにまとめた表。色を足す・かえるときは、まずこの表の色をつかう。
新しい役目の色がいるときは、この表にも足す（色だけ足して、役目を書かないままにしない）。

- わくの絵（パネル・ボタンの9スライス）は `index.html` の「わくの絵の色ごとの絵」と、`tools/ui/paper_ui.py`（`paper-ui:begin`〜`end`）。
- 木目・紙のこさのちがい（木目の4つのこさ・紙のでこぼこ）は、わざと色が多い。ここには、もとの色だけ書く。
- 草原（`body.wd0`）は木の板、ほかのステージは紙。
