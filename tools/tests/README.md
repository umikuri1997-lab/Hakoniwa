# テストと実験の道具

どれも、ブラウザ（Playwright）でゲームそのものを動かしてたしかめる。

## テストをまとめて動かす
```
node tools/tests/run-all.cjs            # ぜんぶ
node tools/tests/run-all.cjs fog story  # 名前に fog か story が入るテストだけ
```
- サーバーは自分で立てる（`GAME_URL` があれば、それを使う）。
- ブラウザは `CHROME_PATH`（なければ `/opt/pw-browsers/chromium`）。
- 落ちたテストは、1本だけでもう1回動かす。それで通れば「2回めで通った」と出る。
- さいごに、通った数と、落ちたテストのさいごの数行を出す。

1本だけ動かすときは、サーバーを立ててから：
```
python3 -m http.server 8000 --bind 127.0.0.1 --directory . &
CHROME_PATH=/opt/pw-browsers/chromium node tools/tests/fog.cjs
```

## テストを書くとき
- `tools/sim/boot.cjs` を使うと、ゲームを開いて新しい草原をはじめる所までやってくれる（`cam-done.cjs` が例）。`run(コード)` で、ゲームの中のコードを動かせる。
- 知らせの画面（うけとった・霧が晴れた・レベルアップ）は、時間を止める。テストの中でとじること。
- しくみをかえたら、それをたしかめているテストも同じPRで直す（古いテストをのこさない）。

## 自動プレイ（`tools/sim/autoplay.cjs`）
はじめから、メインクエストを順に進める。バランスを見るときと、物語が最後まで進むかを見るときに使う。
```
node tools/sim/autoplay.cjs out.json 60            # 60分（実時間）動かす。ふつうに遊ぶ
node tools/sim/autoplay.cjs out.json 120 --supply  # パワー・食べ物・花のたねを補給し、やられないようにして、物語の進行だけを見る
```
- 20倍速で、1日が約30秒〜1分。2つ同時に動かすと、そのぶんおそくなる。
- 出力の `days` は、1日ごとの `[日, 村Lv, 合計パワー, パワー, 食料, 人数, やられた数, たのしさ平均, おなか%平均, クエスト, 畑, 夜の回数, 光の回数, みどり]`。
- 守り神の出番（ミニゲーム）は、成功あつかいで進める。
- 村づくりは上手ではない（柵でかこまない・畑は店が出るまでふやさない）。数字は「このくらいの遊び方で」の目安。
- クエストを足した・進め方をかえたら、`tools/sim/autoplay-bot.js` の `H.<クエストの名前>` も直す。

## 夜の実験（`tools/sim/night.cjs`）
4人の村（火のせいれいLv1が1人）で、1晩だけを何回も動かす。夜のバランスの数字をかえる前とあとに使う。
```
node tools/sim/night.cjs 1 4   # 守りの光あり・4晩
node tools/sim/night.cjs 0 4   # 守りの光なし・4晩
```
出力は、1晩ごとの、夜の結果・火のせいれいが生きのこったか・おなかの動き（時刻:おなか/敵の数）。
