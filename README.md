## セーブデータの引き継ぎ

セーブはブラウザごと・サイトのURLごとに保存されます。旧サイトから移る場合は、旧サイトのゲーム内メニューで「セーブの書き出し」→「書き出す」を行い、新サイトで「読みこむ」からそのJSONファイルを選んでください。旧サイトは引き続き利用できます。
